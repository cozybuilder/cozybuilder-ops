# 사례 003 — 피터 레벨스 1인 글로벌 SaaS 포트폴리오

> 피터 레벨스가 여러 소규모 웹서비스를 빠르게 출시하고, 반응이 확인된 일부 제품을 구독·회원권·기업 결제로 확장한 방식을 CozyBuilder 제품 아이디어에 재사용하기 위한 사례 문서.

- **조사 대상:** 피터 레벨스의 공개 프로젝트 목록과 주요 수익형 서비스
- **조사일:** 2026-07-11
- **운영 주체:** Pieter Levels
- **주요 고객:** 디지털 노마드, 원격근무 구직자·채용기업, AI 사진·인테리어 생성 이용자, 1인 창업가

## 확인된 프로젝트 운영 패턴

피터 레벨스가 공개한 프로젝트 목록 기준으로 100개가 넘는 프로젝트를 만들었지만, 장기간 의미 있는 수익을 만든 제품은 일부에 집중되어 있다. 모든 프로젝트가 수익형 스타트업은 아니며 무료 실험·비영리·개인 프로젝트도 포함된다.

```text
작은 문제 발견
→ 핵심 기능만 빠르게 제작
→ 즉시 공개
→ 방문·사용·결제 반응 확인
→ 반응이 없으면 중단
→ 결제가 확인된 제품만 장기간 확장
```

핵심은 많은 제품을 무작정 만드는 것이 아니라 **작게 검증하고 성공한 소수에 집중하는 포트폴리오 방식**이다.

## 주요 수익형 제품

### 1. Nomads.com

- 도시별 생활비, 인터넷, 날씨, 안전도, 원격근무 환경 등의 정보를 제공
- 무료 도시 정보로 검색 방문자를 모음
- 전체 데이터와 커뮤니티 접근을 회원권으로 판매
- 오랫동안 축적된 데이터·검색 노출·커뮤니티가 진입장벽으로 작동

```text
무료 도시 데이터
→ 검색 방문자 축적
→ 전체 데이터·커뮤니티 회원권 판매
```

### 2. Remote OK

- 원격근무 채용공고를 구직자에게 무료 제공
- 돈을 내는 고객은 구직자가 아니라 채용기업
- 채용공고 등록비, 상위 노출, 공고 묶음, 채용 관련 기능으로 매출 발생

```text
구직자 무료 이용
→ 구직자 트래픽과 인재 풀 확보
→ 채용기업이 공고 등록비 결제
```

이 구조는 지불 능력이 있는 기업 고객이 비용을 부담하고, 무료 이용자를 많이 모을수록 기업 상품의 가치가 높아진다.

### 3. Photo AI

- 이용자가 자기 사진으로 AI 인물 모델을 만들고 사진·영상 콘텐츠를 생성
- 생성량, 품질, 처리 속도, 모델 수와 상업 이용 범위에 따라 요금제 차등
- 월 구독과 연간 선결제로 반복 매출 확보
- 외부 AI·GPU 서비스를 특정 목적에 맞는 쉬운 제품으로 포장

```text
무료 결과 예시·SNS 콘텐츠
→ 사진 업로드
→ AI 모델 생성
→ 사용량별 월 구독
→ 상위 요금제·연간 결제 전환
```

### 4. Interior AI

- 방 사진을 업로드하면 인테리어 변경, 가상 홈스테이징과 영상을 생성
- 기반 AI 기술은 Photo AI와 유사하지만 고객 문제와 브랜드를 분리
- 부동산·인테리어 고객의 실제 촬영·시공·홈스테이징 비용을 절약하므로 높은 가격을 받을 수 있음

### 5. MAKE 및 콘텐츠 상품

- 직접 제품을 만들며 얻은 경험을 전자책으로 판매
- 사업 과정 공개가 개인 브랜드와 팔로워를 만들고, 책과 기존 제품으로 다시 유입

```text
제품 제작 과정 공개
→ 팔로워·신뢰 축적
→ 전자책 판매
→ 다른 서비스로 교차 유입
```

## 전체 수익 구조

```text
무료 데이터·도구·콘텐츠 공개
→ 검색·SNS 방문자 확보
→ 목적별 독립 제품으로 전환
→ 회원권·월 구독·연간 결제·기업 등록비 판매
→ 성공 제품 간 교차 유입
→ 경험을 전자책·콘텐츠로 다시 판매
```

## 반복 매출 구조

- AI SaaS의 월간·연간 구독
- 채용기업의 반복 공고 등록
- 데이터·커뮤니티 회원권
- 상위 요금제와 사용량 확장
- 여러 독립 제품 사이의 교차판매
- 사업 경험을 활용한 전자책·콘텐츠 판매

## 제품 포트폴리오 원칙

### 독립 제품

각 서비스는 하나의 거대한 홈페이지 안에 기능을 계속 붙이기보다, 고객 문제별 독립 도메인과 독립 제품으로 운영한다.

```text
한 회사
├─ 디지털 노마드 제품
├─ 원격 채용 제품
├─ AI 인물 사진 제품
└─ AI 인테리어 제품
```

### 공통 기술 재사용

같은 기술을 만능 앱 하나에 넣지 않고 고객과 목적별로 다시 포장한다.

```text
공통 AI 생성 기술
├─ 인물 사진
├─ 인테리어
├─ 부동산 홈스테이징
└─ AI 영상
```

### 조기 결제 검증

방문자 수만 보지 않고 초기부터 회원권·구독·크레딧·등록비를 붙여 실제 결제 의사를 확인한다.

## 기술 운영 방식

- 제품별 독립 웹앱·독립 도메인
- VPS, Linux, Nginx 중심의 저비용 직접 운영
- PHP 중심의 단순한 모놀리식 구조
- 복잡한 마이크로서비스보다 한 사람이 이해하고 즉시 수정할 수 있는 구조 선호
- Stripe 등 외부 결제 서비스 사용
- AI 생성은 외부 GPU·모델 API 연결
- cron·작업 스크립트로 데이터 갱신, 백업, 반복 업무 자동화
- 검증된 코드를 여러 프로젝트에서 재사용
- 서버와 인프라 고정비를 매출에 비해 매우 낮게 유지

## 배워야 할 부분과 따라 하면 안 되는 부분

### 배워야 할 부분

1. 작은 범위로 출시하고 결제로 검증
2. 제품별 독립 브랜드와 독립 시장
3. 검증된 공통 기술·인증·결제 구조 재사용
4. 무료 도구와 콘텐츠를 유료 제품 유입구로 사용
5. 월 구독과 연간 선결제를 함께 제공
6. 운영비가 매출보다 훨씬 작도록 설계
7. 국내에서 검증한 뒤 언어·결제·정책을 정비해 해외 확장

### 그대로 따라 하면 안 되는 부분

- 수만 줄짜리 단일 파일 구조
- 운영 서버 직접 수정
- 테스트·검수 없이 즉시 배포
- 백업과 보안이 불충분한 초간단 데이터 저장
- 제품 본진을 자주 중단하고 실험만 늘리는 방식

피터 개인에게 가능한 과격한 운영법과, CozyBuilder가 장기적으로 유지해야 하는 안전한 제품 운영 표준은 구분한다.

## CozyBuilder 적용 방향

```text
코지임대 = 한국 시장에서 깊게 완성할 본진 제품
전자책 제작 프로그램 = 처음부터 글로벌 확장을 고려할 SaaS 후보
작은 무료 웹도구 = 검색 유입과 시장 반응 검증
검증된 도구 = 독립 월 구독 제품으로 확장
여러 제품 = 장기적으로 CozyBuilder 통합 패스 연결
```

### 한국 경험형 제품

- 임대관리
- 퇴실정산·월세 일할 계산
- 건물 시설·수선 관리
- 소규모 사업자 업무관리

한국의 법률·계약·운영 관행이 들어가는 제품은 국내 시장에서 먼저 검증한다.

### 글로벌 확장형 제품

- 전자책·PDF·EPUB 제작
- 콘텐츠 조립·편집
- 영상·이미지 소재 관리
- 템플릿 생성
- AI 결과물을 실제 상품으로 만드는 제작 워크플로

국가 제도에 덜 종속되는 제품은 초기부터 다국어, 해외 결제, 국제 날짜·통화, 영문 약관과 데이터 구조를 고려한다.

## 파생 가능한 제품 아이디어

- 무료 월세 일할계산기 → 코지임대 구독
- 무료 퇴실정산 계산기 → 코지임대 구독
- 임대수익률 계산기 → 건물주 잠재고객 확보
- 전자책 샘플 생성기 → 전자책 제작 SaaS 구독
- PDF·EPUB 변환 미니도구 → 글로벌 검색 유입
- 업종별 체크리스트·문서 생성기 → 전문 SaaS 확장
- 제품별 개별 구독 + CozyBuilder 통합 구독 패스

## CozyBuilder 적용 결론

```text
많이 만드는 것이 목표가 아니다.
작게 출시하고 실제 결제를 확인한다.
반응 없는 실험은 중단한다.
결제되는 제품은 오래 유지하고 확장한다.
무료 도구와 콘텐츠는 본진 제품의 유입 자산으로 연결한다.
공통 기술은 재사용하되 고객 문제별 제품은 독립시킨다.
한국에서 검증한 뒤 글로벌 시장으로 확장한다.
```
