# 수익모델 라이브러리

> 다른 사업자·서비스가 고객을 모으고 결제와 반복 매출을 만드는 방식을 조사해, CozyBuilder의 신규 제품·마케팅 아이디어에 재사용하기 위한 문서.

## 운영 원칙

- 사례별로 **유입 → 무료 제공 → 결제 → 반복 매출** 흐름을 기록한다.
- 홍보 문구와 확인된 사실을 구분한다.
- 수익 인증은 전체 고객의 평균 성과로 간주하지 않는다.
- CozyBuilder에 적용할 때는 개발비·광고비·API·서버·운영시간 등 실제 투입비용을 함께 검토한다.
- 새로운 제품 아이디어를 검토할 때 이 문서를 먼저 참고한다.

## 사례 001 — 프레스런·로알남 구글 부업 강의

- **조사 대상:** 프레스런 무료 특강 및 로알남 올인원 강의
- **조사일:** 2026-07-11
- **운영 주체:** 프레스런 강의 판매 페이지 기준 주식회사 나랑해, 호스팅서비스 제공자 표기 주식회사 로워드
- **주요 고객:** 온라인 부업, 블로그 수익, 애드센스 수익을 원하는 초보자

### 고객 유입 경로

```text
유튜브 콘텐츠·광고
→ 무료 특강 신청 페이지
→ 성공 사례·수익 가능성 제시
→ 유료 올인원 강의 판매
```

### 무료 진입 상품

- 구글 부업·애드센스 수익화를 설명하는 무료 온라인 특강
- 초보 가능, 하루 1시간, 월 100만 원 등의 강한 후킹 문구로 신청자를 모집

### 실제 판매 상품

- 워드프레스 구축, SEO 글쓰기, 키워드 조사, 애드센스, 외부 유입, 제휴마케팅 등을 묶은 고가 온라인 강의
- 학습 기간 종료 후 복습 연장권 등 후속 판매 가능
- 강의 안에서 호스팅, 키워드 분석, 플러그인, 테마 등 연관 서비스와 연결

### 핵심 수익 구조

```text
무료 강의로 잠재고객 확보
→ 고가 강의 판매
→ 호스팅·분석 도구·플러그인 연결
→ 연장권·심화 상품으로 추가 매출
```

### 반복 매출 구조

- 호스팅과 분석 도구가 월·연 단위 구독이면 반복 매출로 연결 가능
- 강의 복습 연장권, 심화 강의, 컨설팅, 커뮤니티가 후속 상품이 될 수 있음
- 운영사별 정확한 수익 배분 관계는 공개 페이지만으로 확정하지 않음

### 수강생이 돈을 버는 방식

```text
검색 수요가 있는 키워드 발굴
→ 워드프레스·블로그에 정보성 글 작성
→ 구글·네이버·다음·SNS 등에서 방문자 유입
→ 구글 애드센스 광고 수익
→ 쿠팡파트너스 등 제휴마케팅 추가
```

### 초기 비용·준비물

- 도메인과 워드프레스 호스팅
- 애드센스 승인용 콘텐츠와 사이트 운영 시간
- 키워드·SEO 도구 비용 가능성
- 유료 강의 구매 시 높은 초기 교육비

### 운영 난이도

- 사이트 구축뿐 아니라 지속적인 키워드 조사와 글 작성이 필요
- 검색 노출까지 시간이 걸릴 수 있음
- 기존 글 수정, 외부 유입, 정책 준수와 무효 트래픽 관리가 필요
- 단순 버튼 한 번으로 방문자와 수익이 자동 발생하는 구조는 아님

### 홍보 문구와 확인된 사실의 차이

- **홍보:** 초보, 하루 1시간, 버튼 하나, 월 100만 원 가능
- **실제 구조:** 다수의 콘텐츠 축적, SEO 경쟁, 외부 유입, 수개월 운영, 애드센스 정책 관리가 필요
- 성공 사례는 존재할 수 있으나 전체 구매자의 평균·중앙 수익과 성공률은 별도 확인이 필요

### 위험 요소

- AI로 유사한 글을 대량 발행하면 검색 노출과 애드센스 승인·유지에 불리할 수 있음
- 광고 클릭 유도, 자기 클릭, 링크 도배는 계정·게시물 제재 위험이 있음
- 정부지원·건강·금융 등 민감한 정보는 정확성 책임이 큼
- 수익 인증이 매출인지 순이익인지, 다른 제휴수익을 포함했는지 구분이 필요
- 고가 강의 결제 전 전체 수강생 성과와 실제 순이익 자료 확인 필요

### CozyBuilder 적용 가능 요소

1. **무료 진입 콘텐츠 → 유료 상품** 퍼널
   - 임대관리 체크리스트, 건물주용 무료 자료, 무료 체험판으로 잠재고객 확보
   - 이후 코지임대 구독이나 관련 디지털 상품으로 연결

2. **교육 + 도구 결합**
   - 단순 앱 판매보다 사용법, 실전 템플릿, 운영 가이드까지 묶어 고객의 실행을 돕기

3. **일회성 판매 + 반복 매출**
   - 전자책·강의는 일회성 판매
   - 앱 구독, 유지관리, 데이터 백업, 추가 기능은 반복 매출

4. **실제 경험 기반 콘텐츠**
   - 임대관리, 건설, ERP 개발, 46세 AI 창업 경험을 활용해 복제형 AI 글과 차별화

### 파생 가능한 제품 아이디어

- 건물주용 임대관리 무료 진단표 → 코지임대 구독 전환
- 임대관리 실전 전자책 + 코지임대 앱 번들
- 초보 건물주용 계약·입금·퇴실 체크리스트 생성기
- 임대관리 블로그 콘텐츠를 앱 기능과 직접 연결하는 검색 유입 구조
- 업종별 업무 템플릿을 무료 제공하고 전용 프로그램으로 전환하는 CozyBuilder 공통 퍼널

## 사례 002 — GamsGo 구독 공유·재판매 플랫폼

- **조사 대상:** GamsGo 웹사이트와 외부 이용 후기
- **조사일:** 2026-07-11
- **운영 주체:** GamsGo
- **주요 고객:** 넷플릭스·유튜브 프리미엄 등 디지털 구독료를 정가보다 낮게 이용하려는 글로벌 사용자

### 고객 유입 경로

```text
검색·가격 비교·SNS·추천인 홍보
→ 정가보다 저렴한 구독 상품 제시
→ 기간 단위 선결제
→ 계정·프로필·가족그룹 또는 이용권 제공
→ 만료 전 갱신 유도
```

### 무료 진입 상품

- 별도 무료 서비스보다 할인 가격, 쿠폰, 추천인 코드와 짧은 이용기간이 진입 장벽을 낮추는 역할
- 이용자가 직접 여러 사람을 모집하지 않아도 플랫폼이 구독 좌석을 배정해주는 편의 제공

### 실제 판매 상품

- 영상·음악·교육·생산성 등 디지털 구독 서비스의 공유 좌석 또는 이용권
- 1개월보다 장기 기간을 미리 결제하도록 구성해 현금을 선확보할 수 있는 구조
- 문제가 생겼을 때 계정 교체, 재초대, 이용기간 보상 등을 제공하는 고객지원 서비스

### 핵심 수익 구조

```text
가족·그룹·다인용 구독 또는 저가 조달 경로 확보
→ 하나의 구독 권한을 여러 좌석으로 분할
→ 각 좌석을 개별 사용자에게 재판매
→ 조달원가와 판매총액의 차액 확보
→ 장기 선결제·갱신으로 반복 매출 생성
```

- 정확한 계정 조달 방식과 서비스별 원가·마진은 공개 정보만으로 확정할 수 없음
- 다인용 요금제의 좌석 분할, 국가별 가격 차이, 대량 구매·제휴 조건 등이 원가 우위의 후보이나 이는 서비스별로 다를 수 있음

### 반복 매출 구조

- 영상·음악 구독은 계속 사용하는 고객이 많아 갱신 매출이 발생하기 쉬움
- 여러 서비스를 한 사이트에 모아 교차판매 가능
- 추천인·제휴 마케팅으로 신규 고객 획득비를 성과형 수수료로 전환 가능
- 장기 선결제를 받으면 현금흐름은 좋아지지만, 중간 장애와 환불·보상 의무가 함께 누적됨

### 고객이 구매하는 실제 가치

- 단순히 계정을 사는 것이 아니라 다음 편의를 구매함
  - 함께 결제할 사람을 직접 찾지 않아도 됨
  - 정가보다 낮은 비용
  - 결제·갱신을 한 곳에서 처리
  - 계정이나 가족그룹이 중단됐을 때 교체·복구를 요청할 창구

### 운영 난이도

- 서비스마다 가입·가족그룹·동일 가구·국가·결제수단 정책이 달라 자동화가 어려움
- 계정 중단, 비밀번호 변경, 가족그룹 해제, 지역 인증 문제에 대한 상시 고객지원 필요
- 조달 계정과 사용자 좌석의 만료일·잔여기간·장애·보상을 정확히 관리해야 함
- 원 서비스의 정책 변경 한 번으로 특정 상품의 수익성과 운영 가능성이 크게 바뀔 수 있음

### 홍보 문구와 확인된 사실의 차이

- **홍보:** 프리미엄 구독을 간단하고 저렴하게 이용
- **확인된 가치:** 가격 절감과 공유 상대 모집·문제 대응을 플랫폼이 대신함
- **숨은 운영비:** 계정 장애, 재배정, 환불, 고객지원, 결제 분쟁, 제휴 수수료
- 할인율 전체가 이익은 아니며 구독 조달비, 결제 수수료, 마케팅비, 장애 보상비를 빼야 실제 이익이 됨

### 위험 요소

- 넷플릭스는 계정 공유를 같은 Household 중심으로 제한하며, 가구 밖 사용자는 별도 계정을 요구함
- Spotify Family는 가족 구성원이 플랜 관리자와 함께 거주하는지 주소 확인을 요구함
- 서비스별 가족·가구·국가 제한과 충돌하는 공유 방식은 중단·재인증·접근 차단 위험이 큼
- 외부 후기에는 저렴한 가격과 빠른 지원에 대한 긍정 평가와 함께, 갑작스러운 중단·잘못된 요금제·환불·고객지원 문제도 함께 나타남
- 추천인 수수료 미지급을 주장하는 최근 후기들이 있어 제휴 프로그램 정산도 별도 검증 필요
- 사용자가 공유 계정에 개인정보나 중요한 작업물을 저장하면 계정 통제권과 데이터 안전 문제가 생길 수 있음

### CozyBuilder 적용 가능 요소

1. **비싼 자원을 잘게 나눠 판매**
   - 하나의 고가 자산이나 전문 기능을 여러 고객이 필요한 만큼만 이용하게 만들어 단가를 낮춤
   - 단, 타사 약관에 기대지 않고 CozyBuilder가 직접 권리를 가진 자원에만 적용

2. **상품보다 운영 편의를 판매**
   - 고객은 직접 사람을 모집하고 정산하는 번거로움을 피하기 위해 플랫폼에 비용을 지불함
   - CozyBuilder도 복잡한 임대관리·문서작성·콘텐츠 제작 절차를 대신 정리하는 방식으로 적용 가능

3. **장기 선결제 + 갱신**
   - 월 구독 외에 6개월·12개월 선결제 할인으로 현금흐름을 확보
   - 중도 해지·환불·서비스 종료 시 책임 범위를 먼저 설계해야 함

4. **장애 대응 자체가 제품 가치**
   - 자동 기능만 파는 것이 아니라 백업, 복구, 데이터 이전, 고객지원까지 신뢰 상품으로 구성

5. **다상품 교차판매**
   - 한 고객이 한 제품을 구매하면 관련 전자책·템플릿·앱·유지관리 상품을 함께 제안

### 파생 가능한 제품 아이디어

- 건물주가 혼자 고용하기 어려운 서비스를 월 구독으로 묶는 임대관리 지원 패키지
- 계약·입금·퇴실·시설관리 템플릿을 필요한 기능별로 나눠 판매하는 모듈형 CozyRent 요금제
- 전자책 제작 도구 + 템플릿 + 저장·백업 + 출판지원의 기간제 번들
