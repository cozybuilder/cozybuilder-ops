# ENVIRONMENT_VERIFICATION — 개발환경 확인

> 읽는 시점: 장비·경로·도구·콘솔·도메인·빌드·서명 정보가 필요한 작업.
> 환경 SSOT: [DEVELOPMENT_ENVIRONMENT.md](../operations/DEVELOPMENT_ENVIRONMENT.md).

1. 환경 SSOT를 먼저 확인한다.
2. 확인된 값을 코지에게 다시 묻지 않는다.
3. 변경 가능성이 있으면 로컬 명령·콘솔·API·git으로 자체 확인한다.
4. 자체 확인이 불가능하고 작업에 반드시 필요할 때만 이유를 밝히고 묻는다.
5. 확인된 새 정보는 작업 종료 전에 환경 SSOT에 반영한다.
6. secret은 값이 아니라 보관 위치·갱신일·담당만 기록한다.
