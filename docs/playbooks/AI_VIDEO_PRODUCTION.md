# AI_VIDEO_PRODUCTION — 영상 작업 진입

> 읽는 시점: AI 영상 기획·시나리오·Scene Brief·제작·검수.

1. `GLOBAL.md → PLAYBOOK.md → PROJECTS.md`를 확인한다.
2. `ai-video-production` 저장소에 진입한다.
3. 그 저장소가 지정한 Production Brief → 운영 철학 → 운영 규칙 → STATUS → 현재 프로젝트
   문서 순서를 따른다.
4. Production Brief를 확인하지 않고 기획·시나리오·Scene Brief를 만들지 않는다.

영상 제작의 상세 SSOT는 `ai-video-production` 저장소만 소유한다. 이 저장소에는 진입 경로만 둔다.
