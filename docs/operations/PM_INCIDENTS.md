## INC-1. CozyRent Google 로그인 진단 지연

- **영향**: 단편 가설을 근본 원인으로 조기 확정하고 반복 배포해 시간·사용자 작업·검증 비용이 증가했다.
- **핵심 원인**:
  - 기준값의 전체 생성·파생·런타임 계보를 먼저 만들지 않음
  - 중간 결함 발견을 최종 원인 확정으로 승격
  - 배포 없는 읽기 전용 검증을 소진하기 전에 새 빌드를 반복
- **교정**: 외부 연동 장애는 기준값 원본 → 계보 → 파생 위치 전수 대조 → 로그 실패 경계 →
  가설·반증 → 승인된 단일 실험 → 성공 종단점 순서로 진단한다.

  [EXTERNAL_INTEGRATION_DIAGNOSTICS.md](../playbooks/EXTERNAL_INTEGRATION_DIAGNOSTICS.md)
