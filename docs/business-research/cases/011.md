# 11차 수집 — 사례 89~98

> 반려동물·수면·습관·옷장·집 관리처럼 생활 상태를 계속 측정하고 다음 행동을 알려주는 상용 서비스를 중심으로 정리한다. 가격은 2026-07-13 기준이며 국가·플랫폼·프로모션에 따라 달라질 수 있다.

## 89. Dogo

- 서비스: 반려견 훈련 프로그램, 행동 교정, 클릭커·휘슬, 진도 기록과 전문가 피드백
- 운영 형태: 상용 모바일 구독 서비스
- 아이디어 구조: 반려견 문제 행동이 생기면 보호자는 검색 영상마다 다른 방법을 따라 하거나 비싼 오프라인 훈련을 예약한다. Dogo는 개의 나이·문제·목표에 따라 짧은 일일 훈련 과정을 배정하고 성공 여부를 기록하게 한다.
- 기존 방식: 문제 행동 검색 → 여러 영상 비교 → 훈련 순서 직접 결정 → 효과가 없으면 다른 방법 시도 → 필요 시 전문가 예약
- 바꾼 방식: 반려견 프로필·목표 입력 → 단계별 훈련 자동 배정 → 타이머·클릭커로 실행 → 진도와 행동 변화 기록 → 필요 시 영상 피드백
- 바로 결제하는 이유: 오프라인 훈련보다 낮은 비용으로 매일 해야 할 행동을 구체적으로 안내받고 가족이 같은 방식으로 훈련할 수 있음
- 가격: 일부 무료 체험과 Premium 구독. 정확한 최신 월·연 금액은 국가별 앱스토어 결제 화면 재확인 필요
- 자동 제공 구조: 개 정보 입력 → 맞춤 프로그램 생성 → 일일 과제·알림 → 진도·결과 기록
- 확인 근거: https://dogo.app/
- 파생 아이디어: 전문가가 한 번에 해결하던 행동 교정 업무를 짧은 일일 과제와 결과 기록으로 분해해 원격 셀프서비스로 제공

## 90. Tractive

- 서비스: 반려동물 GPS 위치·가상 울타리·탈출 알림·활동·수면·건강 변화 감시
- 운영 형태: 하드웨어와 필수 구독을 결합한 상용 서비스
- 아이디어 구조: 반려동물은 아픈지, 평소보다 덜 움직이는지, 집을 벗어났는지 말할 수 없다. Tractive는 목걸이 센서와 위치 데이터를 지속 수집해 평소 패턴에서 벗어난 사건만 보호자에게 알려준다.
- 기존 방식: 보호자가 직접 위치 확인 → 활동량을 감으로 판단 → 이상 행동이 눈에 보인 뒤 병원 방문 → 실종 시 주변 수색
- 바꾼 방식: 기기 착용 → 위치·수면·활동·심박 등 자동 기록 → 개인 기준선 생성 → 탈출·건강 변화 감지 시 알림
- 바로 결제하는 이유: 실종이나 질병을 조금이라도 빨리 발견하면 기기·구독료보다 큰 비용과 불안을 줄일 수 있음
- 가격: 기기 약 $69~$89 수준. Basic $108/년 또는 2년 $144, Premium $120/년·2년 $168·5년 $300 수준
- 자동 제공 구조: 기기·앱 연결 → 센서·GPS 데이터 지속 수집 → 기준선 비교 → 예외 알림·이력 제공
- 확인 근거: https://tractive.com/
- 파생 아이디어: 말을 할 수 없는 대상의 평소 행동 기준선을 만들고 이상 변화만 보호자에게 알려주는 돌봄 서비스

## 91. SnoreLab

- 서비스: 스마트폰 마이크로 코골이 녹음·점수화·구간 재생·생활 요인 비교
- 운영 형태: 무료와 Premium 구독을 제공하는 소비자 건강 앱
- 아이디어 구조: 사용자는 자는 동안 자신의 코골이 강도와 원인을 알 수 없고 병원에서도 기억에 의존해 설명한다. SnoreLab은 밤새 소리를 기록해 코골이 구간과 강도를 계산하고 음주·운동·수면 자세 같은 요인과 비교한다.
- 기존 방식: 동거인의 설명에 의존 → 원인 추측 → 생활 습관을 바꿔도 효과를 객관적으로 비교하지 못함
- 바꾼 방식: 잠들기 전 녹음 시작 → 코골이 자동 탐지·점수화 → 심한 구간만 재생 → 요인·대책별 변화 비교
- 바로 결제하는 이유: 병원 방문 전에도 자신의 상태와 유발 요인을 파악하고 개선 시도의 효과를 데이터로 확인할 수 있음
- 가격: 기본 무료. Premium은 7일 체험 후 약 £5.99/월 또는 £29.99/년 수준이며 지역별 차이 가능
- 자동 제공 구조: 야간 음성 수집 → 코골이 분류·점수화 → 추세·요인 비교
- 확인 근거: https://www.snorelab.com/
- 파생 아이디어: 사용자가 의식하지 못하는 수면·생활 행동을 수동 기록 없이 감지해 원인과 개선 효과를 보여주는 서비스

## 92. Routinery

- 서비스: 아침·저녁·공부·운동 루틴을 순서와 타이머로 실행시키는 습관 앱
- 운영 형태: 무료와 Premium 구독형 모바일 서비스
- 아이디어 구조: 할 일을 아는 것과 실제 순서대로 시작하는 것은 다르다. 사용자는 매 단계마다 다음 행동을 다시 결정하다가 미루거나 빠뜨린다. Routinery는 루틴을 작은 행동과 시간으로 나눠 한 단계씩 자동 진행한다.
- 기존 방식: 할 일 목록 확인 → 무엇부터 할지 결정 → 시간 초과 → 다음 행동을 잊음 → 루틴 중단
- 바꾼 방식: 행동 순서·시간 설정 → 시작 버튼 → 현재 행동과 남은 시간 표시 → 다음 단계 자동 전환 → 완료 기록
- 바로 결제하는 이유: 의지나 기억에 의존하지 않고 정해진 순서에 따라 몸을 움직이게 해 반복되는 시작 부담을 줄임
- 가격: 기본 무료. Premium 월·연 구독과 평생 구매가 제공될 수 있으며 정확한 최신 금액은 앱스토어 재확인 필요
- 자동 제공 구조: 루틴 생성 → 단계별 타이머 실행 → 다음 행동 안내 → 완료·통계 제공
- 확인 근거: https://routinery.app/
- 파생 아이디어: 복잡한 생활 과정을 한 번에 보여주지 않고 현재 해야 할 한 행동만 제시해 실행률을 높이는 서비스

## 93. Stylebook

- 서비스: 보유 의류·코디·착용 기록·가격·포장 목록을 관리하는 디지털 옷장
- 운영 형태: iOS 일회성 구매 앱
- 아이디어 구조: 사람은 옷이 많아도 무엇을 보유했는지, 실제로 자주 입는지, 비슷한 옷을 또 사는지 기억하지 못한다. Stylebook은 옷을 사진 데이터로 만들어 착용 빈도와 구매가격을 연결한다.
- 기존 방식: 옷장을 직접 확인 → 머릿속으로 코디 조합 → 여행 전 짐 목록 작성 → 사용하지 않는 옷을 모른 채 추가 구매
- 바꾼 방식: 의류 사진 등록 → 코디 조합·캘린더 기록 → 착용 횟수와 cost-per-wear 계산 → 여행 포장 목록 생성
- 바로 결제하는 이유: 적은 앱 가격으로 중복 구매와 옷 선택 시간을 줄이고 이미 산 옷의 활용률을 높일 수 있음
- 가격: 일회성 앱 구매. 과거 공개 가격 $3.99였으며 최신 국가별 앱스토어 가격 재확인 필요
- 자동 제공 구조: 의류 등록 → 착용·코디 기록 → 활용도·비용 통계 → 추천과 목록 제공
- 확인 근거: https://www.stylebookapp.com/
- 파생 아이디어: 사용자가 이미 소유한 물건을 데이터화해 추가 구매보다 기존 자산의 활용률을 높여주는 서비스

## 94. Whering

- 서비스: 디지털 옷장, 날씨·일정 기반 코디 추천, 착용 기록과 의류 순환 관리
- 운영 형태: 무료와 Premium 구독을 제공하는 소비자 패션 앱
- 아이디어 구조: 디지털 옷장에 물건을 저장하는 것만으로는 매일 무엇을 입을지 결정하는 부담이 사라지지 않는다. Whering은 보유 옷·날씨·일정·과거 착용을 결합해 오늘의 선택을 추천한다.
- 기존 방식: 날씨 확인 → 옷장 탐색 → 최근 입은 옷 기억 → 코디 결정 → 사용하지 않는 옷은 계속 방치
- 바꾼 방식: 의류 등록 → 날씨·일정·착용 이력 결합 → 코디 제안 → 착용 기록과 옷별 활용도 갱신
- 바로 결제하는 이유: 새 옷을 사지 않고도 매일의 선택 피로를 줄이고 보유 의류를 더 다양하게 활용할 수 있음
- 가격: 핵심 기능 무료. Premium 가격은 국가·앱스토어별 결제 화면 재확인 필요
- 자동 제공 구조: 옷장 데이터·날씨·일정 입력 → 코디 추천 → 착용·활용도 학습
- 확인 근거: https://whering.co.uk/
- 파생 아이디어: 보유 자산·외부 환경·사용 이력을 결합해 오늘 가장 적절한 선택을 자동 추천

## 95. Sortly

- 서비스: 가정·소규모 사업의 물건·수량·위치·사진·영수증·보증서를 관리하는 재고 서비스
- 운영 형태: 무료와 단계별 구독을 제공하는 SaaS
- 아이디어 구조: 사람은 물건이 어디 있는지, 몇 개 남았는지, 언제 샀는지 기억하지 못해 다시 찾거나 중복 구매한다. Sortly는 사진 중심 카탈로그와 QR·바코드로 물건의 위치와 수량 변화를 기록한다.
- 기존 방식: 방·창고를 직접 탐색 → 스프레드시트에 수동 기록 → 영수증·보증서를 별도 보관 → 물건 이동 시 기록 누락
- 바꾼 방식: 사진·QR로 등록 → 위치·수량·문서 연결 → 이동·사용 시 스캔 → 부족·보증·점검 알림
- 바로 결제하는 이유: 분실·중복 구매·재고 부족과 보증서 탐색 시간을 줄일 수 있음
- 가격: Free 플랜 제공. 유료는 사용자·항목·기능에 따라 단계별 과금하며 정확한 최신 시작 가격은 공식 결제 화면 재확인 필요
- 자동 제공 구조: 물건 등록 → 위치·수량·문서 연결 → 스캔 기반 변경 → 알림·보고서
- 확인 근거: https://www.sortly.com/pricing/
- 파생 아이디어: 집이나 사업장에 흩어진 물리 자산을 사진·위치·문서·상태와 연결해 검색 가능한 디지털 자산으로 전환

## 96. HomeZada

- 서비스: 주택 자산 목록·유지보수 일정·리모델링 예산·문서·주택 가치 관리
- 운영 형태: 주택 소유자 대상 구독형 서비스
- 아이디어 구조: 집은 정기적으로 점검·교체해야 할 설비가 많지만 소유자는 시기와 과거 수리 내용을 기억하지 못한다. HomeZada는 집 전체를 하나의 장기 자산으로 보고 물건·설비·정비·프로젝트·비용을 연결한다.
- 기존 방식: 고장 후 수리업체 검색 → 영수증과 설명서를 서랍에 보관 → 필터·보일러·지붕 점검 시기를 기억에 의존 → 리모델링 비용 엑셀 관리
- 바꾼 방식: 주택·설비 등록 → 유지보수 일정 자동 생성 → 비용·문서·사진 기록 → 향후 교체·프로젝트 예산 관리
- 바로 결제하는 이유: 작은 정기 점검을 놓쳐 발생하는 큰 수리비와 집 관련 정보 탐색을 줄임
- 가격: 무료 또는 체험형 진입과 Premium 구독을 제공하며 정확한 최신 플랜 가격은 공식 결제 화면 재확인 필요
- 자동 제공 구조: 주택 정보 입력 → 설비별 점검 일정 → 알림·비용·문서 이력 축적
- 확인 근거: https://www.homezada.com/
- 파생 아이디어: 고장 후 대응하던 물리 자산을 예상 수명·점검 주기·과거 이력에 따라 선제 관리하는 서비스

## 97. one sec

- 서비스: SNS·쇼핑·게임 등 습관성 앱을 열기 전에 의도 확인과 짧은 대기 시간을 넣는 행동 교정 앱
- 운영 형태: 1인 개발자로 시작한 무료·Pro 구독 서비스
- 아이디어 구조: 화면시간 제한은 사용자가 무시 버튼을 누르면 끝난다. one sec은 금지보다 앱을 여는 순간에 짧은 호흡과 목적 질문을 넣어 자동 행동을 의식적인 선택으로 바꾼다.
- 기존 방식: 앱 사용시간 제한 설정 → 습관적으로 앱 실행 → 제한 무시 → 후회 → 다시 제한 설정
- 바꾼 방식: 대상 앱 실행 감지 → 10초 안팎의 지연·호흡 → 사용 목적 선택 → 계속할지 포기할지 결정 → 시도 횟수 기록
- 바로 결제하는 이유: 강제 차단 없이도 무의식적 실행을 줄이고 회복한 시간을 즉시 체감할 수 있음
- 가격: 기본 한 개 앱은 무료. Pro는 과거 공개 기준 약 $10/년이었으며 현재 정확한 가격은 앱스토어 재확인 필요
- 자동 제공 구조: 앱 실행 감지 → 개입 화면 → 의도 입력·지연 → 행동 통계
- 확인 근거: https://one-sec.app/
- 파생 아이디어: 나쁜 행동을 완전히 막지 않고 행동 직전의 마찰과 질문만 설계해 사용자가 스스로 취소하게 만드는 서비스

## 98. Sleep Cycle

- 서비스: 휴대폰 센서·마이크로 수면 패턴을 추정하고 얕은 수면 구간에 깨우는 스마트 알람
- 운영 형태: 무료와 Premium 구독을 제공하는 소비자 수면 서비스
- 아이디어 구조: 고정 시각 알람은 깊은 수면 중에도 울려 사용자가 더 피곤하게 느낄 수 있다. Sleep Cycle은 움직임·소리를 분석해 사용자가 설정한 범위 안에서 비교적 얕은 수면 시점을 골라 깨운다.
- 기존 방식: 고정 알람 설정 → 어떤 수면 단계인지와 관계없이 기상 → 피로 원인을 감으로 추측
- 바꾼 방식: 기상 범위 설정 → 밤새 소리·움직임 분석 → 수면 단계 추정 → 최적 구간 알람 → 수면 추세·코골이·환경 비교
- 바로 결제하는 이유: 매일 반복되는 기상 경험을 개선하고 수면 습관과 환경이 피로에 미치는 영향을 확인할 수 있음
- 가격: 기본 무료. Premium 월·연 구독은 국가·플랫폼별 결제 화면 재확인 필요
- 자동 제공 구조: 야간 센서 데이터 수집 → 수면 패턴 추정 → 스마트 알람·추세 보고
- 확인 근거: https://www.sleepcycle.com/
- 파생 아이디어: 고정 시간에 실행하던 생활 행동을 사용자의 현재 생체·상태 데이터에 맞춰 가장 적절한 순간에 실행
