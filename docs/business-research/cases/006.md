# 6차 수집 — 사례 39~48

## 39. Plausible Analytics

- 서비스: 개인정보 친화적인 웹 분석 도구
- 운영 형태: 독립·부트스트랩 팀. 공식 사이트 기준 10명 규모
- 아이디어 구조: Google Analytics는 무료지만 복잡하고 느리며 쿠키 동의와 개인정보 규제 부담이 크다. Plausible은 사이트 운영자가 실제로 자주 보는 방문·유입·전환 지표를 한 화면에 단순화하고 쿠키 없는 분석으로 재구성했다.
- 기존 방식: 복잡한 태그 설정 → 여러 보고서 메뉴 학습 → 쿠키 배너·동의 관리 → 필요한 숫자를 다시 정리
- 바꾼 방식: 추적 코드 설치 → 필수 지표 자동 수집 → 한 화면에서 방문·캠페인·전환 확인
- 바로 결제하는 이유: 무료 도구를 대신해도 분석 시간과 규제·설정 부담을 줄이고 빠르게 핵심 숫자를 확인할 수 있음
- 가격: 30일 무료 체험. 월간 페이지뷰 1만 기준 Starter $9/월, Growth $14/월, Business $19/월부터
- 자동 제공 구조: 가입·결제 → 코드 설치 → 데이터 자동 수집·대시보드 제공
- 확인 근거: https://plausible.io/
- 파생 아이디어: 무료지만 복잡한 범용 도구를 핵심 지표와 안전한 운영 방식만 남긴 유료 대안으로 전환

## 40. Fathom Analytics

- 서비스: 쿠키 없는 개인정보 중심 웹 분석
- 운영 형태: 100% 독립 소유라고 공식 사이트에 명시. 현재 인원 미확인
- 아이디어 구조: 사이트 운영자가 광고 추적용 분석 시스템까지 필요하지 않은데도 복잡한 설정과 개인정보 책임을 떠안는 문제를 해결한다. 필요한 지표, 전환, 캠페인 분석을 단순한 화면으로 제공하고 사이트 수를 넉넉하게 포함했다.
- 기존 방식: 무료 분석 도구 설정 → 쿠키 동의 관리 → 보고서 구성 → 여러 사이트를 따로 확인
- 바꾼 방식: 코드 한 번 설치 → 여러 사이트 데이터 자동 수집 → 단순 대시보드·이메일 보고서로 확인
- 바로 결제하는 이유: 개인정보를 판매하지 않는 서비스에 비용을 지불하고 복잡성·규제 위험·사이트별 관리 시간을 줄임
- 가격: 7일 무료 체험. 페이지뷰 기준 변동형이며 공식 가격 화면에서 최대 50만 페이지뷰 플랜 $45/월 표시, 연 결제 시 2개월 무료
- 자동 제공 구조: 가입 → 코드 설치 → 방문·이벤트 자동 수집 → 대시보드·보고서 제공
- 확인 근거: https://usefathom.com/pricing
- 파생 아이디어: 고객의 민감한 데이터를 수익화하지 않는 대신 명확한 구독료를 받는 신뢰 기반 대안

## 41. Pirsch Analytics

- 서비스: 개인정보 친화적 웹 분석·세션 분석·URL 단축
- 운영 형태: 소규모 서비스로 보이나 현재 인원 미확인
- 아이디어 구조: 분석, 전환 목표, 세션 확인, 캠페인 링크 관리가 서로 다른 도구에 나뉘는 문제를 하나의 개인정보 친화적 분석 제품으로 묶었다.
- 기존 방식: 분석 코드 설치 → 별도 URL 단축기 사용 → 목표·세션·캠페인 데이터를 여러 화면에서 비교
- 바꾼 방식: 하나의 분석 도구에서 방문·목표·세션·단축 링크·A/B 테스트까지 연결
- 바로 결제하는 이유: 작은 사이트도 낮은 진입 가격으로 여러 분석 도구를 통합하고 쿠키 부담을 줄일 수 있음
- 가격: 30일 무료 체험. 1만 페이지뷰 기준 Standard $6/월, Plus $12/월, Enterprise 별도 견적
- 자동 제공 구조: 코드·서버 연동 → 데이터 자동 수집 → 분석·보고·알림 제공
- 확인 근거: https://pirsch.io/pricing
- 파생 아이디어: 인접한 작은 도구들을 하나의 핵심 데이터 기준으로 묶어 저가형 통합 상품으로 제공

## 42. Transistor

- 서비스: 팟캐스트 호스팅·배포·분석·웹사이트·비공개 팟캐스트
- 운영 형태: 부트스트랩으로 시작한 소규모 SaaS. 현재 인원 미확인
- 아이디어 구조: 팟캐스트를 운영하려면 파일 호스팅, RSS 생성, 플랫폼별 배포, 분석, 웹사이트와 팀 권한을 각각 관리해야 한다. Transistor는 한 계정에서 여러 팟캐스트를 만들고 배포와 분석까지 자동화했다.
- 기존 방식: 오디오 저장 → RSS 설정 → 각 플랫폼 등록 → 별도 웹사이트 제작 → 다운로드 수 집계
- 바꾼 방식: 에피소드 업로드 → RSS·웹사이트 자동 생성 → 여러 플랫폼 배포 → 다운로드·청취 분석
- 바로 결제하는 이유: 기술적인 배포 인프라를 직접 운영하지 않고 여러 쇼와 팀을 한 계정에서 관리할 수 있음
- 가격: 14일 무료 체험. Starter $19/월, Professional $49/월, Business $99/월, Enterprise $199+/월. 연 결제는 10개월 가격으로 12개월 사용
- 자동 제공 구조: 가입·결제 → 오디오 업로드 → RSS·웹사이트·분석 자동 제공
- 확인 근거: https://transistor.fm/pricing/
- 파생 아이디어: 콘텐츠 제작자가 어려워하는 배포 규격·호스팅·통계 기반 시설을 한 번에 제공

## 43. Tolt

- 서비스: SaaS용 제휴·추천 프로그램, 전환 추적과 파트너 지급 관리
- 운영 형태: 초기 스타트업·인디 SaaS를 주요 고객으로 하는 상용 서비스. 현재 인원 미확인
- 아이디어 구조: 추천 프로그램을 운영하려면 파트너 링크, 매출 귀속, 수수료 계산, 환불 반영, 지급과 세금 문서를 스프레드시트로 관리해야 한다. Tolt는 Stripe·Paddle 결제와 연결해 이 전체 흐름을 자동화했다.
- 기존 방식: 추천 링크 발급 → 주문과 추천인 수동 대조 → 수수료 계산 → 환불 수정 → 파트너별 송금
- 바꾼 방식: 결제 시스템 연결 → 추천 링크·전환 자동 추적 → 수수료 계산 → 자동 또는 수동 지급
- 바로 결제하는 이유: 제휴 매출이 커질수록 정산 실수와 관리 시간이 늘기 때문에 성장과 직접 연결된 운영 업무를 줄임
- 가격: 14일 무료 체험. Basic $69/월, Growth $99/월, Pro $199/월, Enterprise 별도 견적. 자동 지급에는 처리 수수료가 추가될 수 있음
- 자동 제공 구조: 결제 시스템 연동 → 추천 프로그램 개설 → 전환·환불·수수료 자동 반영 → 지급 관리
- 확인 근거: https://tolt.com/pricing
- 파생 아이디어: 매출을 만드는 외부 참여자와의 추적·정산·증빙을 결제 데이터에 연결해 자동화

## 44. LogSnag

- 서비스: 제품 이벤트·매출·사용자 행동을 실시간 피드와 알림으로 보여주는 모니터링 도구
- 운영 형태: 현재 인원 미확인
- 아이디어 구조: 작은 SaaS 운영자는 회원가입·결제·해지·오류 같은 중요한 사건을 DB나 여러 관리 화면에서 찾아야 한다. LogSnag은 제품이 보내는 이벤트를 한 피드로 모으고 중요한 변화가 생길 때 알린다.
- 기존 방식: 데이터베이스 조회 → 결제 화면 확인 → 로그 검색 → 중요한 사건을 수동 정리
- 바꾼 방식: 앱에서 이벤트 전송 → 사용자·채널별 자동 정리 → 웹·모바일에서 실시간 확인·알림
- 바로 결제하는 이유: 고객 행동과 매출 사건을 즉시 발견해 문제 대응과 사용자 이해 시간을 줄임
- 가격: 무료 플랜 월 2,500 이벤트. 연 결제 환산 Sprout $16/월, Seedling $33/월, Timber $66/월, Enterprise 별도 견적
- 자동 제공 구조: API·연동 설정 → 이벤트 자동 수집 → 피드·대시보드·알림 제공
- 확인 근거: https://logsnag.com/pricing
- 파생 아이디어: 운영자가 여러 시스템을 확인하지 않고 핵심 사업 사건만 하나의 실시간 피드로 받게 함

## 45. Papermark

- 서비스: 문서 공유, 페이지별 열람 분석, 보안 링크와 투자·거래용 데이터룸
- 운영 형태: 오픈소스 기반으로 성장한 상용 서비스. 현재 인원 미확인
- 아이디어 구조: 제안서·투자자료·계약자료를 이메일 첨부로 보내면 누가 어느 페이지를 읽었는지 알 수 없고 파일 통제도 어렵다. Papermark는 문서를 추적 가능한 링크로 바꾸고 열람·보안·권한을 함께 제공한다.
- 기존 방식: 파일 첨부 발송 → 상대방 반응 대기 → 열람 여부를 다시 질문 → 새 버전 재발송 → 권한 수동 관리
- 바꾼 방식: 파일 업로드 → 보안 링크 생성 → 페이지별 열람 자동 기록 → 필요 시 NDA·워터마크·데이터룸 적용
- 바로 결제하는 이유: 투자·영업·거래처럼 문서 열람 반응이 매출과 의사결정에 직접 연결되는 상황에서 후속 행동 시점을 알 수 있음
- 가격: Free €0, Pro €24/월, Business €59/월, Data Rooms €99/월부터. 팀원 추가 비용 별도 가능
- 자동 제공 구조: 문서 업로드 → 공유 링크·권한 설정 → 열람 데이터 자동 수집 → 알림·분석 제공
- 확인 근거: https://www.papermark.com/pricing
- 파생 아이디어: 정적인 파일을 반응과 진행 상태를 측정할 수 있는 거래 도구로 전환

## 46. Tella

- 서비스: 화면·카메라 녹화, 자동 편집, 자막, 영상 호스팅과 시청 분석
- 운영 형태: 현재 인원 미확인
- 아이디어 구조: 제품 설명·교육·영업 영상을 만들려면 녹화, 편집, 자막, 공유 페이지와 시청 분석을 여러 도구에서 처리해야 한다. Tella는 짧은 클립을 녹화해 자동 레이아웃과 줌을 적용하고 링크 공유와 분석까지 연결한다.
- 기존 방식: 화면 녹화 → 편집기로 이동 → 자막·레이아웃 수정 → 영상 업로드 → 별도 분석 도구 확인
- 바꾼 방식: 클립 녹화 → 자동 편집·자막 → 링크 호스팅·CTA 추가 → 시청·전환 분석
- 바로 결제하는 이유: 전문 편집 없이 판매·교육용 영상을 반복 제작하고 누가 얼마나 봤는지 확인할 수 있음
- 가격: 무료 플랜 제공. Pro $13/사용자/월, Premium $19/사용자/월, Enterprise 별도 견적. 연 결제 할인 표시
- 자동 제공 구조: 가입·결제 → 녹화 → 자동 편집·호스팅 → 링크 공유·분석
- 확인 근거: https://www.tella.com/pricing
- 파생 아이디어: 결과물 제작과 배포 후 성과 측정을 같은 서비스에 연결

## 47. Userlist

- 서비스: SaaS 고객 온보딩·라이프사이클 이메일·앱 내 메시지 자동화
- 운영 형태: 소규모 SaaS 전문 서비스로 시작. 현재 인원 미확인
- 아이디어 구조: 일반 이메일 마케팅 도구는 개인 이메일 주소 중심이라 회사 계정 안에 여러 사용자가 있는 SaaS 구조를 잘 표현하지 못한다. Userlist는 사용자 행동과 소속 회사를 함께 추적해 가입·활성화·이탈 상황별 메시지를 자동 발송한다.
- 기존 방식: 고객 데이터 내보내기 → 태그 수동 관리 → 이메일 캠페인 설정 → 회사와 사용자 관계를 스프레드시트로 보완
- 바꾼 방식: 제품 이벤트·사용자·회사 데이터를 연결 → 행동 조건별 워크플로 → 이메일·앱 내 메시지 자동 실행
- 바로 결제하는 이유: 신규 고객 활성화와 이탈 방지처럼 반복 매출에 직접 영향을 주는 고객 커뮤니케이션을 자동화
- 가격: 14일 무료 체험. 사용자 수에 따른 동적 가격이며 Basic·Professional 플랜과 Enterprise 별도 견적. 공식 표에서 추가 사용자 1,000명당 Basic $10/월, Professional $12/월 표시
- 자동 제공 구조: 제품 데이터 연동 → 세그먼트·워크플로 설정 → 메시지 자동 발송 → 전환 측정
- 확인 근거: https://userlist.com/pricing/
- 파생 아이디어: 범용 마케팅 도구가 표현하지 못하는 특정 업종의 데이터 관계를 중심으로 자동화 도구를 재설계

## 48. Shipixen
