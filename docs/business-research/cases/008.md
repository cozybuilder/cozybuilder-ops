# 8차 수집 — 사례 59~68

> 업무 생산성 도구 비중을 줄이고 개인 생활·여행·건강·가계·취미 분야의 상용 서비스를 중심으로 정리한다. 가격은 2026-07-13 기준이며 국가·플랫폼·프로모션에 따라 달라질 수 있다.

## 59. Flighty

- 서비스: 항공편 지연·취소·탑승구·항공기 이동과 연결편 상태를 실시간 추적하는 개인 여행 앱
- 운영 형태: 창업자 Ryan Jones와 소규모 팀이 운영하는 상용 앱. 공개 보도 기준 7명 규모
- 아이디어 구조: 항공사 앱은 자사 운항 정보만 늦게 알려주거나 지연 이유와 앞선 항공기 위치를 충분히 보여주지 않는다. Flighty는 여러 항공·공항·기상 데이터를 모아 사용자의 한 항공편을 중심으로 필요한 정보를 먼저 정리해 알려준다.
- 기존 방식: 항공사 앱 확인 → 공항 전광판 확인 → 앞선 항공기 위치 검색 → 지연·연결편 가능성 스스로 판단
- 바꾼 방식: 항공편 등록 → 관련 데이터를 자동 결합 → 지연 가능성·이유·항공기 위치·연결편 상태를 실시간 알림
- 바로 결제하는 이유: 한 번의 큰 지연만 미리 알아도 공항 대기, 이동과 일정 변경에 드는 시간·비용·스트레스를 줄일 수 있음
- 가격: 제한적 무료 사용. Flighty Pro는 $5/주, $59.99/년, 평생 $299.99 수준으로 공개되어 있으며 지역별 앱스토어 가격은 다를 수 있음
- 자동 제공 구조: 항공편·캘린더·이메일 연결 → 운항 데이터 지속 수집 → 변화 감지 → 알림·여행 기록 자동 제공
- 확인 근거: https://www.flighty.com/
- 파생 아이디어: 큰 불확실성이 있는 개인 일정에서 여러 원천 데이터를 결합해 사용자가 행동을 바꿔야 할 시점을 먼저 알려주는 서비스

## 60. Seats.aero

- 서비스: 항공사 마일리지로 예약 가능한 보너스 항공권 좌석 검색·알림
- 운영 형태: 보안 연구자 Ian Carroll이 시작한 상용 서비스. 현재 팀 규모 미확인
- 아이디어 구조: 마일리지 좌석은 항공사마다 검색 방식과 제휴 관계가 다르고 날짜를 하루씩 바꾸며 확인해야 한다. Seats.aero는 여러 프로그램의 좌석 정보를 지속 수집해 출발지·지역·좌석 등급 기준으로 한 번에 탐색하게 한다.
- 기존 방식: 항공사 사이트별 로그인 → 날짜·노선 반복 검색 → 카드 포인트 전환 가능 여부 확인 → 좌석이 생길 때까지 재검색
- 바꾼 방식: 원하는 지역·기간·등급 설정 → 여러 프로그램의 좌석 재고 통합 검색 → 새 좌석 발견 시 알림 → 항공사 사이트에서 예약
- 바로 결제하는 이유: 어렵게 모은 포인트를 고가 항공권으로 바꾸는 기회를 빠르게 찾으면 구독료보다 훨씬 큰 금전 가치를 얻을 수 있음
- 가격: 60일 이내 검색은 무료. Pro는 $9.99/월 또는 $99.99/년 수준으로 1년 범위 검색과 고급 알림 제공
- 자동 제공 구조: 항공사·보상 프로그램 데이터 수집 → 좌석 색인 → 사용자 조건 검색·알림
- 확인 근거: https://seats.aero/
- 파생 아이디어: 가격 차이가 크고 재고가 순간적으로 열리는 시장을 지속 감시해 가치가 높은 기회만 알려주는 소비자 구독 서비스

## 61. Wanderlog

- 서비스: 여행 일정·지도·예약·메모·비용·동행자 협업을 한곳에 모으는 여행 계획 서비스
- 운영 형태: Travelchime Inc.가 운영하는 상용 서비스. 현재 팀 규모 미확인
- 아이디어 구조: 여행을 준비할 때 지도 저장, 항공·숙소 예약, 일정표, 맛집 목록과 공동 비용이 여러 앱에 흩어진다. Wanderlog는 여행 하나를 중심으로 장소·이동·예약·비용과 동행자 편집을 묶었다.
- 기존 방식: 지도에 장소 저장 → 메신저로 의견 수집 → 스프레드시트 일정 작성 → 예약 이메일 검색 → 비용 별도 기록
- 바꾼 방식: 여행 생성 → 장소와 예약 자동·수동 추가 → 지도 위 일정 최적화 → 동행자 공동 편집·비용 관리
- 바로 결제하는 이유: 여행 중 인터넷이 없거나 계획이 자주 바뀌는 상황에서도 모든 정보를 한곳에서 확인하고 재정리 시간을 줄일 수 있음
- 가격: 핵심 기능 무료. Pro는 약 $39.99/년이며 오프라인 사용, Gmail 예약 자동 가져오기, 지도 내보내기 등 제공
- 자동 제공 구조: 예약 이메일·지도·사용자 입력 통합 → 날짜별 일정·경로·예산 자동 정리
- 확인 근거: https://wanderlog.com/
- 파생 아이디어: 특정 사건이나 프로젝트를 중심으로 여러 앱에 흩어진 개인 정보를 하나의 실행 가능한 계획으로 결합

## 62. Splitwise

- 서비스: 여행·모임·동거·커플의 공동 지출과 개인별 채무를 계산하는 서비스
- 운영 형태: 상용 핀테크 서비스. 현재는 조직형 기업
- 아이디어 구조: 여러 사람이 번갈아 결제하면 영수증과 메모만으로 누가 누구에게 얼마를 갚아야 하는지 계산하기 어렵고 돈 이야기가 관계 갈등으로 이어진다. Splitwise는 지출만 입력하면 최소 정산 횟수로 채무 관계를 계산한다.
- 기존 방식: 영수증 보관 → 사람별 사용 금액 계산 → 스프레드시트 작성 → 각자에게 송금 금액 설명
- 바꾼 방식: 그룹 생성 → 결제자·참여자·분할 방식 입력 → 개인별 잔액 자동 계산 → 알림·정산 기록
- 바로 결제하는 이유: 복잡한 해외여행·공동생활에서 계산 시간과 돈 문제로 생기는 실수·갈등을 줄일 수 있음
- 가격: 기본 무료. Splitwise Pro는 약 $4.99/월 또는 $39.99/년이며 지역별 가격 차이 가능
- 자동 제공 구조: 지출 입력·영수증 스캔 → 분할 계산 → 채무 단순화 → 정산 알림
- 확인 근거: https://www.splitwise.com/
- 파생 아이디어: 민감한 인간관계 문제를 객관적인 계산·기록·알림으로 대신 처리해 대화 부담을 줄이는 서비스

## 63. YNAB

- 서비스: 은행 거래를 연결해 모든 돈에 사용 목적을 배정하는 가계 예산 관리 서비스
- 운영 형태: 개인용 스프레드시트에서 시작해 성장한 비공개 상용 기업
- 아이디어 구조: 일반 가계부는 돈을 쓴 뒤 분류하는 기록 도구에 머물지만, YNAB은 현재 가진 돈을 앞으로 필요한 항목에 미리 배정하게 해 소비 결정을 바꾸도록 설계했다.
- 기존 방식: 카드·은행 내역 확인 → 지출 분류 → 월말에 초과 지출 확인 → 다음 달 다시 같은 문제 반복
- 바꾼 방식: 계좌 연결 → 현재 자금을 목적별 배정 → 지출 발생 시 예산 자동 차감 → 초과 항목 재조정
- 바로 결제하는 이유: 구독료보다 큰 불필요 지출과 현금 부족을 줄이고 돈에 대한 불안을 낮추는 결과를 기대할 수 있음
- 가격: 34일 무료 체험. $14.99/월 또는 $109/년 수준
- 자동 제공 구조: 계좌 거래 가져오기 → 예산 항목 매칭 → 사용 가능 금액·목표·보고서 갱신
- 확인 근거: https://www.ynab.com/pricing
- 파생 아이디어: 과거 기록을 보여주는 도구를 미래 행동을 제한·안내하는 의사결정 시스템으로 전환

## 64. AllTrails

- 서비스: 등산·걷기·자전거 등 야외 활동 경로 검색·리뷰·내비게이션·안전 기능
- 운영 형태: 대규모 상용 소비자 서비스
- 아이디어 구조: 처음 가는 야외 코스는 난이도, 현재 상태, 길 찾기와 안전 정보를 여러 블로그와 지도에서 확인해야 한다. AllTrails는 실제 이용자 경로·후기·사진을 검색 가능한 코스 데이터로 만들고 현장 내비게이션까지 연결했다.
- 기존 방식: 블로그에서 코스 검색 → 지도 파일 확보 → 날씨·후기 확인 → 현장에서 길을 잃으면 다시 검색
- 바꾼 방식: 조건별 코스 검색 → 사용자 후기·상태 확인 → 오프라인 지도 저장 → 이탈 알림·위치 공유
- 바로 결제하는 이유: 통신이 안 되는 야외에서 길을 잃는 위험과 잘못된 코스 선택의 시간·안전 손해를 줄임
- 가격: 기본 무료. Plus 약 $35.99/년, Peak 약 $79.99/년이며 지역별 가격 차이 가능
- 자동 제공 구조: 사용자 경로·리뷰 수집 → 코스 데이터 정리 → 위치 기반 탐색·내비게이션·안전 알림
- 확인 근거: https://www.alltrails.com/
- 파생 아이디어: 사용자들이 반복해서 남기는 경험 기록을 검증·정리해 다음 사용자의 현장 의사결정을 돕는 데이터 서비스

## 65. MyFitnessPal

- 서비스: 음식·칼로리·영양소·체중·운동 기록과 식단·건강 목표 관리
- 운영 형태: 대규모 상용 건강 서비스
- 아이디어 구조: 체중 관리자는 매끼 음식의 영양 정보를 찾아 계산해야 하고 실제 섭취량을 감으로 판단한다. MyFitnessPal은 대규모 음식 데이터베이스와 바코드·사진 입력으로 기록 과정을 단순화하고 하루 목표와 연결했다.
- 기존 방식: 식품 라벨·검색으로 칼로리 확인 → 계산기 사용 → 노트에 기록 → 하루 합계와 목표 직접 비교
- 바꾼 방식: 음식 검색·바코드·사진 입력 → 섭취량과 영양소 자동 합산 → 목표 대비 남은 양과 추세 표시
- 바로 결제하는 이유: 건강·체중이라는 개인적으로 중요한 결과를 위해 매일 반복되는 계산과 기록 부담을 줄일 수 있음
- 가격: 기본 무료. Premium은 $24.99/월 또는 $99.99/년 수준이며 지역별 가격 차이 가능
- 자동 제공 구조: 음식·운동 입력·연동 → 영양 데이터 계산 → 목표·추세·추천 제공
- 확인 근거: https://www.myfitnesspal.com/premium
- 파생 아이디어: 전문 지식이 필요한 일상 선택을 대규모 기준 데이터와 간단한 입력으로 즉시 계산해 주는 서비스

## 66. AnyList

- 서비스: 가족·커플의 공동 장보기 목록, 레시피 저장과 식단 계획
- 운영 형태: 소규모 독립 앱으로 시작한 상용 서비스. 현재 팀 규모 미확인
- 아이디어 구조: 가족의 장보기 요청은 메신저·종이·각자의 메모에 흩어지고 이미 산 물건도 중복 구매한다. AnyList는 실시간 공동 목록과 레시피 재료 추가를 결합해 장보기 전후의 반복 입력을 줄인다.
- 기존 방식: 가족에게 필요한 물건 질문 → 메신저 내용 복사 → 매장에서 항목 확인 → 레시피 재료를 따로 입력
- 바꾼 방식: 공동 목록 실시간 공유 → 품목 자동 분류 → 레시피에서 재료 일괄 추가 → 구매 즉시 동기화
- 바로 결제하는 이유: 매주 반복되는 장보기에서 누락·중복 구매와 가족 간 확인 메시지를 지속적으로 줄임
- 가격: 기본 목록 기능 무료. AnyList Complete는 개인 약 $9.99/년, 가족 약 $14.99/년 수준
- 자동 제공 구조: 목록·레시피 공유 → 실시간 동기화 → 재료·분류·식단 연결
- 확인 근거: https://www.anylist.com/
- 파생 아이디어: 가족 구성원이 반복해서 주고받는 작은 요청을 공동 상태판과 실시간 완료 처리로 전환

## 67. MacroFactor

- 서비스: 섭취량과 체중 변화로 개인의 실제 에너지 소비량을 추정해 칼로리·영양 목표를 조정하는 앱
- 운영 형태: Stronger By Science 팀이 운영하는 상용 건강 앱
- 아이디어 구조: 일반 칼로리 계산기는 사용자의 실제 대사량 변화와 기록 오차를 반영하지 않아 목표가 맞지 않을 수 있다. MacroFactor는 섭취 기록과 체중 추세를 비교해 개인별 소비 칼로리를 계속 재추정한다.
- 기존 방식: 온라인 계산기로 목표 설정 → 체중 변화가 예상과 다르면 사용자가 감으로 칼로리 조정
- 바꾼 방식: 음식·체중 기록 → 추세 알고리즘이 실제 소비량 추정 → 목표에 맞춰 주간 섭취 권장량 자동 조정

## 68. Paprika Recipe Manager

- 서비스: 웹 레시피 저장·정리, 분량 변환, 식단 계획과 장보기 목록 생성
- 운영 형태: Hindsight Labs가 운영하는 독립 상용 앱
- 아이디어 구조: 사람들은 레시피를 여러 블로그·영상·북마크에 저장하지만 요리할 때 광고와 긴 글을 다시 보고 재료를 장보기 목록으로 옮겨야 한다. Paprika는 웹페이지에서 조리법과 재료만 추출해 개인 레시피 데이터베이스로 만든다.
- 기존 방식: 레시피 링크 저장 → 요리할 때 웹페이지 재검색 → 재료를 메모로 복사 → 인원수에 맞춰 수량 직접 계산
- 바꾼 방식: 웹에서 레시피 가져오기 → 재료·단계 자동 정리 → 분량 조절 → 식단에 배치 → 장보기 목록 생성
- 바로 결제하는 이유: 자주 요리하는 가정은 광고 없는 개인 레시피 보관함과 장보기 자동화를 장기간 사용할 수 있음
- 가격: 구독 없이 플랫폼별 일회성 구매. 정확한 가격은 iOS·Android·macOS·Windows 스토어별로 다르므로 구매 시 재확인 필요
- 자동 제공 구조: 레시피 URL 가져오기 → 구조화·저장 → 식단·재료·장보기 목록 연결

- 파생 아이디어: 웹에 흩어진 비정형 정보를 개인이 반복 사용하는 깨끗한 데이터와 실행 목록으로 변환하는 일회성 구매형 서비스

## 이번 배치의 아이디어 패턴

1. 업무 시간뿐 아니라 여행 불안·건강 고민·가족 갈등처럼 감정적 비용도 결제 이유가 된다.

3. 여러 사이트를 반복 검색하는 행동을 지속 수집·통합 검색·조건 알림으로 바꿀 수 있다.

7. 반복 사용이 아니라 장기간 소유 가치가 큰 도구는 구독 대신 플랫폼별 일회성 구매도 가능하다.
