# 9차 수집 — 사례 69~78

> 개인 재무·가족·기억·식사·생활 판단 서비스를 중심으로 정리한다. 가격은 2026-07-13 기준이며 국가·플랫폼·프로모션에 따라 달라질 수 있다.

## 69. Monarch Money

- 서비스: 개인·부부·가족의 계좌·카드·투자·예산·순자산·목표를 한곳에서 관리하는 재무 서비스
- 운영 형태: 상용 구독 서비스
- 아이디어 구조: 금융 정보가 은행·카드·투자앱에 흩어져 있으면 현재 자산과 앞으로 쓸 수 있는 돈을 정확히 판단하기 어렵다. Monarch는 모든 계정을 연결하고 거래를 자동 분류해 가계 전체의 현황과 목표를 공동으로 보게 한다.
- 기존 방식: 금융앱별 확인 → 거래내역 수동 합산 → 부부가 서로 지출 질문 → 스프레드시트로 예산·순자산 정리
- 바꾼 방식: 계정 연결 → 거래·자산 자동 통합 → 검토가 필요한 내역을 가족에게 지정 → 예산·목표·순자산 공동 확인
- 바로 결제하는 이유: 광고나 금융상품 판매보다 사용자의 구독료로 운영되어 민감한 금융 데이터에 대한 신뢰를 주고, 돈 문제를 추측이 아닌 공동 데이터로 이야기할 수 있음
- 가격: 공식 페이지에서 연 $99 수준의 사용자 후기가 표시되며 신규 사용자는 첫해 할인 프로모션이 있을 수 있음. 정확한 최신 플랜별 금액은 결제 화면 재확인 필요
- 자동 제공 구조: 금융계정 연결 → 거래·잔액 자동 수집 → 분류·예산·목표·보고서 자동 갱신
- 확인 근거: https://www.monarch.com/pricing
- 파생 아이디어: 가족의 민감한 문제를 공동 현황·담당 지정·검토 요청 구조로 바꿔 감정적 대화를 줄이는 서비스

## 70. Quicken Simplifi

- 서비스: 지출·구독·목표·투자·현금흐름·은퇴 전망을 제공하는 개인 재무 서비스
- 운영 형태: Quicken의 상용 구독 서비스
- 아이디어 구조: 일반 가계부는 이미 쓴 돈을 보여주지만 사용자가 궁금한 것은 이번 달 남은 돈과 앞으로 잔액이 어떻게 변하는지다. Simplifi는 수입에서 청구서·구독·저축 목표·예정 지출을 빼 매일 쓸 수 있는 금액과 미래 잔액을 자동 계산한다.
- 기존 방식: 월급 확인 → 고정비·카드 결제 예정액 계산 → 저축액 제외 → 남은 돈을 머릿속이나 엑셀로 계산
- 바꾼 방식: 계좌 연결 → 반복 청구·수입 자동 인식 → 남은 소비 가능 금액과 미래 현금흐름 자동 표시 → 조건을 바꾼 시나리오 비교
- 바로 결제하는 이유: “이번 달 얼마를 써도 되는가”와 “이대로 살면 미래에 얼마가 남는가”를 매번 직접 계산하지 않아도 됨
- 가격: 현재 공식 페이지 프로모션은 연 결제 환산 $2.99/월, 정상 표시 가격 $5.99/월. 첫해 프로모션 후 갱신가는 달라질 수 있음
- 자동 제공 구조: 계좌 연결 → 거래·청구서·수입 분석 → 소비 가능 금액·현금흐름·은퇴 전망 자동 갱신
- 확인 근거: https://www.quicken.com/products/simplifi/
- 파생 아이디어: 사용자의 현재 자산·나이·예상수명·수입·지출을 이용해 오늘 안전하게 쓸 수 있는 금액을 지속 계산하는 생활비 의사결정 서비스

## 71. Quicken LifeHub

- 서비스: 가족의 금융·보험·건강·법률·계정·중요 문서와 비상 정보를 보관·공유하는 생활 정보 금고
- 운영 형태: Quicken의 상용 서비스
- 아이디어 구조: 가족의 중요한 정보는 서류함·이메일·휴대폰·클라우드·개인의 기억에 흩어져 있고, 사고나 사망 시 남은 가족이 어디에 무엇이 있는지 찾지 못한다. LifeHub는 인생의 핵심 정보를 가족 단위로 정리하고 필요한 사람에게 권한을 나눈다.
- 기존 방식: 보험증권·계약서·계좌·비밀번호 위치를 가족에게 말로 설명 → 변경 때마다 다시 알림 → 비상시에 서류와 계정 탐색
- 바꾼 방식: 중요 정보·문서 입력 → 범주별 정리 → 가족·신뢰할 사람에게 권한 부여 → 변경·비상 시 한곳에서 확인
- 바로 결제하는 이유: 평소에는 적게 쓰더라도 사고·질병·상속 상황에서 생기는 큰 탐색 시간과 가족 혼란을 줄임
- 가격: 공식 제품 페이지에서 구독형 상품임은 확인되나 공개 시작 가격은 결제 화면 재확인 필요
- 자동 제공 구조: 문서·정보 등록 → 범주화·검색 → 권한별 공유·갱신
- 확인 근거: https://www.quicken.com/products/lifehub/
- 파생 아이디어: 특정 사건이 발생했을 때 가족이 반드시 찾아야 할 정보를 평상시에 조금씩 쌓아 두는 비상 대비형 구독 서비스

## 72. Cozi

- 서비스: 가족 공동 캘린더·장보기·할 일·레시피·식단 관리
- 운영 형태: 광고 기반 무료 플랜과 유료 Gold 플랜
- 아이디어 구조: 가족 일정과 요청이 개인 캘린더·메신저·종이 메모에 흩어지면 누가 언제 무엇을 해야 하는지 계속 묻게 된다. Cozi는 가족 전체가 같은 일정·목록·식단을 보게 하는 공동 생활 현황판을 만들었다.
- 기존 방식: 가족마다 일정 확인 → 메신저로 반복 질문 → 장보기·할 일을 개인 메모에 기록 → 변경 사항 재전달
- 바꾼 방식: 가족 계정 공유 → 일정·목록·식단을 한곳에 입력 → 변경 시 전원 알림 → 각자 완료 상태 확인
- 바로 결제하는 이유: 광고 제거뿐 아니라 월간 보기·검색·여러 알림·변경 알림처럼 가족 누락을 막는 기능에 비용을 지불
- 가격: 기본 무료. Cozi Gold는 웹 또는 인앱 구매 기준 $39로 표시되며 적용 기간은 결제 화면 확인 필요
- 자동 제공 구조: 가족 구성원 연결 → 일정·목록 공동 저장 → 변경 알림·검색·리마인더 제공
- 확인 근거: https://www.cozi.com/cozi-gold/
- 파생 아이디어: 가족 구성원별로 일정·돈·건강·물건·요청 상태를 한눈에 보여주는 가족 운영 현황판

## 73. Storyworth

- 서비스: 가족에게 매주 질문을 보내고 답변·음성·사진을 모아 회고록 책으로 제작
- 운영 형태: 가족 선물형 상용 서비스
- 아이디어 구조: 부모·조부모의 인생 이야기를 듣고 싶어도 무엇을 물어야 할지 모르고, 대화를 녹음해도 정리하지 못한 채 사라진다. Storyworth는 매주 한 질문이라는 작은 행동을 반복시켜 1년 뒤 가족의 삶을 책이라는 완성품으로 만든다.
- 기존 방식: 특별한 날 인터뷰 시도 → 질문 준비 → 녹음·사진 수집 → 글 정리·교정 → 인쇄 업체에 책 제작 의뢰
- 바꾼 방식: 질문 자동 발송 → 이메일·웹·전화로 답변 → 이야기·사진 누적 → 교정·편집 → 하드커버 책 제작
- 바로 결제하는 이유: 단순 기록앱이 아니라 사라질 가족 기억을 실제로 전달 가능한 물리적 유산으로 만들어 줌
- 가격: $59부터. 모든 기본 플랜에 주간 질문, 이야기·사진, 하드커버 책이 포함되며 추가 기능·책에 따라 상승
- 자동 제공 구조: 질문 발송 → 답변·음성 수집 → 교정·배치 → 인쇄 주문
- 확인 근거: https://welcome.storyworth.com/
- 파생 아이디어: 큰 결과물을 한 번에 요구하지 않고 매주 5분짜리 작은 입력을 받아 1년 뒤 가치 있는 자산으로 완성하는 서비스

## 74. Life360

- 운영 형태: 무료와 유료 멤버십을 제공하는 상용 서비스
- 아이디어 구조: 가족은 서로 어디 있는지, 안전하게 도착했는지 반복해서 연락하지만 매번 전화·메시지를 보내는 것은 번거롭고 감시처럼 느껴질 수 있다. Life360은 위치와 이동 상태를 공동 상태로 만들고 위험 신호가 있을 때만 적극 알린다.
- 기존 방식: 출발·도착 때마다 연락 → 답이 없으면 재연락 → 사고 여부 추측 → 분실물은 별도 앱에서 찾기
- 바꾼 방식: 가족 원 연결 → 위치·도착·운전 상태 자동 공유 → 충돌·SOS·이탈 상황만 알림 → 사람과 물건을 한 앱에서 확인
- 바로 결제하는 이유: 자녀·부모·운전 가족의 안전 불안을 줄이고 사고 때 대응 시간을 단축
- 가격: 무료 플랜이 있으며 최근 공개 정보 기준 Silver 약 $7.99/월, Gold 약 $14.99/월 수준. 국가·시점별 가격 재확인 필요
- 자동 제공 구조: 위치·센서·운전 데이터 수집 → 상태 판단 → 가족 알림·이력 제공
- 확인 근거: https://www.life360.com/
- 파생 아이디어: 평소에는 조용히 상태만 공유하고 위험·이탈·미응답 같은 예외가 생길 때만 가족에게 알리는 생활 안전 서비스

- 가격: 무료 플랜과 Premium이 있으나 국가·앱스토어별 가격 차이가 커 정확한 현재 시작 가격은 결제 화면 확인 필요
- 자동 제공 구조: 가족 구성원 초대 → 데이터 입력·연동 → 공동 현황·알림·권한 관리
- 확인 근거: https://www.familywall.com/

## 77. Day One

- 운영 형태: 무료와 Premium 구독 서비스

## 이번 배치에서 얻은 패턴

1. 가족 갈등은 대화를 더 많이 시키기보다 공동 데이터·규칙·상태로 객관화해 줄일 수 있다.
2. 재무 서비스는 과거 지출 분류보다 오늘 안전하게 쓸 수 있는 돈과 미래 결과를 알려줄 때 가치가 커진다.
3. 가족 현황판은 일정뿐 아니라 위치·돈·문서·건강·물건·요청까지 확장할 수 있다.
4. 매주 작은 질문이나 입력을 받으면 사용자가 혼자 완성하기 어려운 가족사·회고록·인생 기록을 장기 자산으로 만들 수 있다.

6. 부모의 잔소리·확인·용돈 계산은 규칙·한도·자동 보상으로 대체할 수 있다.
7. 메뉴·장보기처럼 매일 반복되는 결정 피로는 추천만 하지 말고 실제 실행 목록까지 만들어야 결제 가치가 생긴다.
