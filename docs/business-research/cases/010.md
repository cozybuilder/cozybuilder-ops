# 10차 수집 — 사례 79~88

> 개인 돈관리·관계·집안일·식물·건강처럼 생활 속 반복 판단을 대신해 주는 상용 서비스를 중심으로 정리한다. 가격은 2026-07-13 기준이며 국가·플랫폼·프로모션에 따라 달라질 수 있다.

## 79. Rocket Money

- 서비스: 구독 탐지·해지, 지출 분석, 예산, 순자산, 자동 저축과 요금 협상
- 운영 형태: 대규모 상용 개인 재무 서비스
- 아이디어 구조: 사용자는 자동결제로 빠져나가는 구독과 인상된 청구서를 모두 기억하지 못한다. Rocket Money는 금융 계정을 읽어 반복 결제를 자동 탐지하고, 사용자가 원하면 해지와 요금 협상까지 대신한다.
- 기존 방식: 카드 명세서 확인 → 반복 결제 찾기 → 서비스별 로그인 → 해지 메뉴 탐색 → 통신·보험사에 직접 협상
- 바꾼 방식: 금융 계정 연결 → 구독·청구 변화 자동 탐지 → 해지 요청·요금 협상 → 절감액과 지출 현황 통합 표시
- 바로 결제하는 이유: 사용자가 이미 잃고 있는 돈을 찾아주고 실제 해지·협상 행동까지 대신해 구독료보다 큰 절감을 기대할 수 있음
- 가격: 기본 기능 무료. Premium은 선택형 월 구독으로 운영되며 공식 공개 페이지에서 정확한 금액은 가입 화면 확인 필요. 외부 공개 정보상 대체로 월 $6~$12 범위가 알려져 있으나 재검증 필요
- 자동 제공 구조: 금융계정 연결 → 반복 결제·이상 청구 탐지 → 알림·해지·협상·자동저축
- 확인 근거: https://www.rocketmoney.com/
- 파생 아이디어: 고객이 이미 지불 중이지만 가치가 낮아진 비용을 자동 탐지하고 취소·재협상까지 실행하는 절감 성과형 서비스

## 80. Copilot Money

- 서비스: 계좌·카드·투자·지출·순자산 자동 통합과 개인화된 재무 분석
- 운영 형태: 상용 구독 개인 재무 서비스
- 아이디어 구조: 기존 가계부는 사용자가 거래를 계속 분류해야 해서 오래 쓰기 어렵다. Copilot은 사용자의 수정 행동을 학습해 거래 분류를 개인화하고, 흩어진 금융 정보를 시각적으로 이해하기 쉽게 만든다.
- 기존 방식: 금융앱별 확인 → 거래 수동 분류 → 투자와 현금 자산 별도 계산 → 월말 보고서 작성
- 바꾼 방식: 계정 연결 → 거래 자동 분류 → 사용자의 수정 패턴 학습 → 지출·예산·투자·순자산 자동 갱신
- 바로 결제하는 이유: 기록 노동을 줄이면서 자신의 소비 습관과 전체 자산을 매일 쉽게 파악할 수 있음
- 가격: 공식 사이트에 유료 구독과 무료 체험이 제공되나 현재 공개 페이지에서 정확한 금액은 결제 화면 확인 필요
- 자동 제공 구조: 계정 연결 → 거래·잔액 수집 → 자동 분류·개인화 → 재무 현황·추천 제공
- 확인 근거: https://www.copilot.money/
- 파생 아이디어: 사용자가 수정한 기록을 학습해 시간이 갈수록 분류와 판단이 개인화되는 생활 관리 서비스

## 81. Paired

- 서비스: 연인을 위한 매일 질문·퀴즈·대화·전문가 콘텐츠와 관계 습관 관리
- 운영 형태: 상용 소비자 구독 서비스
- 아이디어 구조: 연인은 관계를 개선하고 싶어도 무슨 이야기를 해야 할지 모르거나 문제가 생겼을 때만 대화한다. Paired는 매일 짧은 질문과 퀴즈를 각자 답하게 하고 서로의 답을 공개해 자연스럽게 대화를 시작하게 한다.
- 기존 방식: 갈등 발생 → 감정적으로 대화 → 관계 조언 검색 → 한쪽만 콘텐츠 소비 → 실천 중단
- 바꾼 방식: 두 사람 계정 연결 → 매일 짧은 질문·퀴즈 답변 → 서로의 답 공개 → 전문가 가이드와 대화 습관 누적
- 바로 결제하는 이유: 상담보다 가볍고 저렴하게 관계 대화를 정기적으로 만들고 서로를 이해하는 계기를 제공
- 가격: 일부 무료 사용과 Premium 구독. 국가·플랫폼별 가격 차이가 커 정확한 최신 월·연 가격은 결제 화면 확인 필요
- 자동 제공 구조: 커플 연결 → 질문·콘텐츠 자동 배정 → 각자 답변 → 상대 답변 공개·기록
- 확인 근거: https://www.paired.com/
- 파생 아이디어: 민감한 대화를 직접 시작하게 하지 않고 양쪽이 따로 입력한 답을 중립적인 시스템이 공개해 대화 계기를 만드는 서비스

## 82. Sweepy

- 서비스: 집안 청소 상태·우선순위·자동 일정·가족 분담과 게임화
- 운영 형태: 상용 모바일 앱
- 아이디어 구조: 집안일은 해야 할 목록보다 무엇부터 해야 하는지 판단하고 가족에게 분담시키는 정신적 부담이 더 크다. Sweepy는 공간별 청결 상태와 사용자의 오늘 가능한 노력량을 이용해 자동 청소 목록을 만든다.
- 기존 방식: 집 전체를 둘러봄 → 더러운 곳 판단 → 청소 목록 작성 → 가족에게 부탁 → 완료 여부 재확인
- 바꾼 방식: 공간·작업 등록 → 청결도와 난이도 표시 → 오늘 가능한 노력량 선택 → 자동 일정 생성 → 가족 점수·승인
- 바로 결제하는 이유: 청소 자체보다 매일 무엇을 할지 결정하고 가족에게 나누는 정신적 부담을 줄임
- 가격: 기본 작업 등록은 무료. 자동 일일 일정과 가족 공유는 Premium 기능이며 정확한 가격은 앱스토어 지역별 결제 화면 확인 필요
- 자동 제공 구조: 공간·작업 설정 → 상태·난이도 계산 → 일일 목록 자동 생성 → 구성원 배정·점수화
- 확인 근거: https://sweepy.com/
- 파생 아이디어: 해야 할 일이 많은 생활 영역에서 현재 상태와 사용자의 오늘 여력을 결합해 가장 효율적인 행동만 자동 배정

## 83. Tody

- 서비스: 집안 청소 주기·우선순위·가족 할당·게임화 관리
- 운영 형태: 상용 모바일 앱
- 아이디어 구조: 청소는 정해진 요일보다 실제로 얼마나 더러워졌는지가 중요하다. Tody는 각 작업의 청소 주기와 마지막 완료 시점을 기준으로 현재 필요한 일을 우선순위화하고 최소 노력으로 집 상태를 개선하도록 안내한다.
- 기존 방식: 정기 청소표 작성 → 요일이 되면 필요 여부와 상관없이 수행 → 누락 작업은 기억에 의존 → 가족 분담 갈등
- 바꾼 방식: 작업별 주기 설정 → 시간 경과에 따라 필요도 증가 → 우선순위 목록 자동 생성 → 가족 순환 배정과 게임화
- 바로 결제하는 이유: 불필요한 청소는 줄이고 꼭 필요한 곳부터 처리하며 가족의 보이지 않는 가사 노동을 명확히 분담
- 가격: 앱 다운로드와 일부 기능 제공. Premium·가족 기능 가격은 iOS·Android 결제 화면에서 재확인 필요
- 자동 제공 구조: 작업·주기 설정 → 필요도 자동 계산 → 우선순위 목록 → 할당·완료 기록
- 확인 근거: https://todyapp.com/
- 파생 아이디어: 달력 기준 반복 작업을 실제 상태 악화 정도에 따라 수행하는 상태 기반 유지관리 서비스

## 84. Planta

- 서비스: 식물 종류·환경·계절에 맞춘 물주기·비료·분갈이·빛 관리와 진단
- 운영 형태: 상용 소비자 구독 앱
- 아이디어 구조: 식물 초보자는 모든 화분에 같은 주기로 물을 주거나 인터넷에서 식물별 관리법을 반복 검색한다. Planta는 식물 종류와 위치·채광·계절을 입력받아 각 화분마다 다른 관리 일정을 만든다.
- 기존 방식: 식물 이름 검색 → 블로그 관리법 확인 → 물 준 날짜 기억 → 상태가 나빠지면 원인 추측
- 바꾼 방식: 식물 등록·환경 입력 → 개별 관리 일정 자동 계산 → 물·비료·분갈이 알림 → 사진 기반 상태 진단
- 바로 결제하는 이유: 식물을 죽여 다시 사는 비용과 죄책감을 줄이고 초보자도 전문가처럼 관리할 수 있음
- 가격: 기본 무료 기능과 Premium 구독. 정확한 월·연 가격은 국가·앱스토어 결제 화면 확인 필요
- 자동 제공 구조: 식물·환경 입력 → 관리 규칙 계산 → 맞춤 일정·알림 → 상태 진단
- 확인 근거: https://planta.app/
- 파생 아이디어: 같은 종류의 대상이라도 위치·환경·계절에 따라 달라지는 유지관리 기준을 개별 일정으로 자동 생성

## 85. PictureThis

- 서비스: 사진으로 식물 식별, 병충해 진단, 관리법과 독성 정보 제공
- 운영 형태: 상용 AI 소비자 앱
- 아이디어 구조: 이름을 모르는 식물이나 잎의 이상 증상은 검색어 자체를 만들기 어렵다. PictureThis는 사진을 입력값으로 바꿔 식물 이름·문제 원인·관리 행동을 바로 제시한다.
- 기존 방식: 식물 특징을 문장으로 검색 → 비슷한 사진 비교 → 병충해 원인 추측 → 여러 글의 관리법 조합
- 바꾼 방식: 사진 촬영 → 식물·증상 자동 인식 → 관리법·치료 행동·안전 정보 제공
- 바로 결제하는 이유: 검색할 단어를 몰라도 즉시 답을 얻고 고가 식물의 손상을 빠르게 막을 수 있음
- 가격: 제한적 무료 사용과 Premium 구독. 지역·플랫폼별 가격 차이가 있어 정확한 최신 금액은 결제 화면 확인 필요
- 자동 제공 구조: 사진 입력 → 이미지 분석 → 식별·진단 → 관리 행동 추천
- 확인 근거: https://www.picturethisai.com/
- 파생 아이디어: 사용자가 문제 이름을 몰라 검색하지 못하는 영역을 사진·음성·센서 입력으로 진단하고 다음 행동까지 제시

## 86. Structured

- 서비스: 일정·할 일·루틴을 하나의 시각적 하루 타임라인으로 통합
- 운영 형태: 상용 개인 생산성 앱
- 아이디어 구조: 일정은 캘린더에 있고 할 일은 목록에 있어 사용자가 실제 하루에 언제 수행할지 다시 판단해야 한다. Structured는 할 일을 시간 블록으로 배치해 하루 흐름을 한 줄의 타임라인으로 보여준다.
- 기존 방식: 캘린더 확인 → 할 일 목록 확인 → 빈 시간 계산 → 머릿속으로 순서 정리 → 미완료 일정 재배치
- 바꾼 방식: 일정·할 일 입력 또는 연동 → 하루 타임라인 통합 → 시간 알림 → 미완료 작업 재배치
- 바로 결제하는 이유: 해야 할 일을 아는 것보다 언제 실행할지 결정하기 어려운 사용자의 계획 피로를 줄임
- 가격: 무료 플랜과 Pro 월·연·평생 구매 옵션. 정확한 최신 금액은 플랫폼별 결제 화면 확인 필요
- 자동 제공 구조: 일정·작업 수집 → 시간순 타임라인 → 알림·재배치·반복 루틴
- 확인 근거: https://structured.app/
- 파생 아이디어: 서로 다른 목록을 실제 하루의 시간축에 배치해 실행 가능한 행동 순서로 변환

## 87. Happy Scale

- 서비스: 체중의 일별 변동을 부드러운 추세와 작은 목표로 재해석하는 체중 관리 앱
- 운영 형태: 상용 소비자 앱
- 아이디어 구조: 체중은 수분·식사·염분 때문에 매일 크게 흔들려 사용자가 실제 감량 추세를 오해하고 포기한다. Happy Scale은 여러 측정값을 평활화해 장기 추세를 보여주고 큰 목표를 작은 구간으로 나눈다.
- 기존 방식: 매일 체중 확인 → 전날보다 증가하면 실패로 판단 → 주간 평균 직접 계산 → 목표까지 거리가 멀어 포기
- 바꾼 방식: 체중 입력·연동 → 변동 노이즈 제거 → 이동 평균·추세 표시 → 작은 중간 목표와 예상 도달일 제공
- 바로 결제하는 이유: 같은 데이터라도 실패처럼 보이는 감정적 해석을 줄이고 장기 행동을 유지하게 함
- 가격: 기본 무료 기능과 Premium 구독·평생 구매 옵션이 있으며 정확한 최신 금액은 앱스토어 결제 화면 확인 필요
- 자동 제공 구조: 체중 기록 → 추세 계산 → 중간 목표·예측·리포트 제공
- 확인 근거: https://happyscale.com/
- 파생 아이디어: 변동이 심한 생활 데이터를 그대로 보여주지 않고 의미 있는 추세와 다음 목표로 재해석해 행동 중단을 방지

## 88. WaterMinder

- 서비스: 개인별 수분 목표·음료 기록·스마트 알림·위젯·웨어러블 연동
- 운영 형태: Funn Media가 운영하는 상용 앱
- 아이디어 구조: 물 마시기는 간단하지만 바쁜 사용자는 시간을 잊고, 기록 과정이 번거로우면 앱 사용을 중단한다. WaterMinder는 손목·위젯·Siri에서 한 번의 입력으로 기록하고 일정·활동·날씨에 맞춰 알림을 조정한다.
- 기존 방식: 하루 목표를 기억 → 물을 마신 횟수 머릿속 계산 → 부족한지 늦게 확인
- 바꾼 방식: 개인 목표 설정 → 적절한 시점에 알림 → 위젯·시계에서 즉시 기록 → 진행률·연속 기록 제공
- 바로 결제하는 이유: 건강 행동 자체는 단순하지만 기억과 기록 마찰을 최소화해 실제 습관으로 유지할 수 있음
- 가격: 플랫폼별 유료 앱·인앱 구매 구조로 정확한 최신 금액은 앱스토어 결제 화면 확인 필요
- 자동 제공 구조: 체중·활동·환경 기반 목표 → 맞춤 알림 → 초간단 기록 → 진행률·습관 데이터
- 확인 근거: https://waterminder.com/
- 파생 아이디어: 자주 해야 하지만 매번 기록하기 귀찮은 행동을 위젯·웨어러블·음성으로 1초 안에 입력하게 만들어 습관화
