# 1인기업 비즈니스 리서치

> 다른 1인기업과 SaaS의 실제 수익 구조를 조사·분석하고, 검증된 성공 구조에서 벤치마킹 요소를 추출해 더 경쟁력 있는 서비스 아이디어를 만들며, 사업성과 실행 가능성을 기준으로 개발 우선순위를 관리한다.

## 운영 흐름

1. 실제로 돈을 버는 1인기업·서비스를 조사한다.
2. 확인된 사실과 추정을 구분해 수익 구조를 분석한다.
3. 그대로 복제하지 않고, 부족한 점과 개선 기회를 찾는다.
4. CozyBuilder가 더 잘 만들 수 있는 서비스 아이디어로 전환한다.
5. 사업성과 실행 가능성을 평가해 검증·개발 순위를 정한다.
6. 실제 프로젝트 착수가 확정되면 `PROJECTS.md` 등록 절차를 따른다.

## 문서 구성

- [BUSINESS_CASES.md](BUSINESS_CASES.md): 1인기업·서비스의 수익 구조 분석
- [OPPORTUNITIES.md](OPPORTUNITIES.md): 분석에서 파생된 사업·서비스 아이디어
- [PRIORITY_ROADMAP.md](PRIORITY_ROADMAP.md): 검증 및 개발 우선순위

## 기본 원칙

- 아이디어보다 실제 수익 구조 분석을 먼저 한다.
- 매출·가격·고객·운영 방식은 출처로 확인된 내용만 사실로 기록한다.
- 확인할 수 없는 비용·매출·전환율은 `추정`으로 표시한다.
- 벤치마킹은 구조를 배우는 것이며, 브랜드·콘텐츠·기능을 그대로 복제하지 않는다.
- 최신 AI나 기존 SaaS로 이미 해결 가능한 문제인지 먼저 확인한다.
- 개발 전 가장 작은 비용으로 수요를 검증한다.
- 조사 중인 후보는 `PROJECTS.md`에 등록하지 않는다. 실제 착수가 확정된 경우에만 프로젝트로 승격한다.
