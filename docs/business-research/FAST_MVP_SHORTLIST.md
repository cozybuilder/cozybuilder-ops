# 1~2일 개발 가능한 초소형 SaaS 후보

> 최초 수집한 98개 사례를 기준으로, 원본 서비스 전체가 아니라 핵심 가치 하나만 잘라 1~2일 안에 MVP를 만들 수 있는 후보를 추렸다. 조사일: 2026-07-14.

## 엄격한 선정 기준

- 로그인·기본 CRUD·결과 화면까지 1~2일 안에 구현 가능
- 외부 데이터 대량 수집, 하드웨어, 복잡한 OAuth, 마켓플레이스 불필요
- AI는 기존 API 호출만 사용하고 별도 모델 학습 없음
- 운영자가 결과를 수동 제작하지 않음
- 사용자가 입력하면 즉시 결과가 나오는 셀프서브 구조
- 결제는 초기 MVP에서 랜딩·대기명단 또는 단순 사용량 제한으로 대체 가능

## 최종 후보 10개

### 1. 특정 직업용 음성 메모 정리기

- 원본 사례: AudioPen
- MVP: 음성 녹음·파일 업로드 → 전사 → 선택한 형식으로 정리
- 처음에는 한 분야만 선택: 현장 작업일지, 상담 메모, 임대 민원 기록, 회의 결과
- 화면: 녹음/업로드, 결과 형식 선택, 결과 복사·다운로드, 최근 기록
- 제외: 팀 협업, 다국어 고도화, 모바일 네이티브 앱, 자체 음성모델
- 예상 개발: 1일
- 결제 가능성: 중간~높음
- 위험: 일반 ChatGPT 음성 기능과 차별화가 약하므로 특정 직업 양식이 필수

### 2. 고객 후기 수집 링크 + 후기 벽

- 원본 사례: Testimonial
- MVP: 사업자가 질문과 로고 설정 → 후기 제출 링크 생성 → 고객이 텍스트 후기 작성 → 승인 후기 공개 페이지 제공
- 처음에는 텍스트 후기만 지원
- 화면: 수집 페이지 생성, 후기 목록, 승인/숨김, 공개 Wall URL
- 제외: 영상 후기, 자동 전사, 외부 리뷰 가져오기, 임베드 스크립트 고도화
- 예상 개발: 1~2일
- 결제 가능성: 중간
- 위험: 범용 시장은 경쟁이 강함. 미용실·헬스장·공사업체 등 업종 특화 필요

### 3. 사진 중심 물품·재고 위치 기록기

- 원본 사례: Sortly
- MVP: 물건 사진, 이름, 수량, 보관 위치, 메모 등록 → 검색·수량 수정
- 타깃 예시: 소형 공사업체 공구, 에어비앤비 비품, 행사 장비, 임대 소모품
- 화면: 물품 목록, 등록, 위치 필터, 부족 수량 표시
- 제외: QR·바코드 생성, 구매발주, 다중 창고, 회계 연동
- 예상 개발: 1~2일
- 결제 가능성: 높음
- 위험: 범용 재고앱으로 만들면 약함. 한 업종의 실제 필드만 남겨야 함

### 4. 상태 기반 반복관리 알림기

- 원본 사례: Tody, Sweepy, Planta
- MVP: 관리 대상 등록 → 마지막 처리일과 반복 주기 입력 → 오늘 필요한 작업 자동 정렬 → 완료 처리
- 타깃 예시: 건물 점검, 공구 정비, 소방시설 확인, 에어컨 필터, 반려동물 관리
- 화면: 대상 등록, 오늘 할 일, 지연 작업, 완료 기록
- 제외: AI 진단, 가족 게임화, 센서 연동, 복잡한 캘린더
- 예상 개발: 1일
- 결제 가능성: 중간~높음
- 위험: 단순 할 일 앱처럼 보이지 않도록 업종별 점검 템플릿과 손실 방지 메시지가 필요

### 5. 단계별 루틴 실행 타이머

- 원본 사례: Routinery
- MVP: 루틴 이름, 단계, 소요시간 등록 → 시작하면 현재 행동 하나와 타이머 표시 → 다음 단계 자동 전환
- 타깃 예시: 헬스장 오픈·마감, 숙박 청소, 현장 안전점검, ADHD 아침 루틴
- 화면: 루틴 편집, 실행 모드, 완료 기록
- 제외: 커뮤니티, 코칭, 웨어러블, 복잡한 통계
- 예상 개발: 1일
- 결제 가능성: 낮음~중간
- 위험: 개인 습관앱은 가격 저항이 큼. 사업장 체크리스트로 좁히면 유리

### 6. 특정 문서용 AI 추출기

- 원본 사례: PDF.ai, Formula Bot
- MVP: 한 종류의 PDF·문서 업로드 → 미리 정한 핵심 항목 추출 → 표와 요약 제공
- 타깃 예시: 임대차계약서, 공사 견적서, 보험 증권, 세금계산서, 입찰공고
- 화면: 업로드, 추출 결과, 원문 근거, CSV 다운로드
- 제외: 모든 PDF와 자유대화, 다중 문서 지식베이스, OCR 고도화
- 예상 개발: 1~2일
- 결제 가능성: 높음
- 위험: 문서 종류를 넓히면 정확도와 책임 문제가 급증. 한 양식만 선택해야 함

### 7. 화면 작업 설명서 초안 생성기

- 원본 사례: Scribe
- MVP: 사용자가 화면 캡처 여러 장 업로드 → 순서 변경 → AI가 단계 제목과 설명 생성 → 링크 또는 PDF 출력
- 화면: 이미지 업로드, 단계 편집, 설명 생성, 공유
- 제외: 브라우저 확장 자동 녹화, 클릭 자동 인식, 팀 문서관리
- 예상 개발: 1~2일
- 결제 가능성: 중간
- 위험: 자동 캡처까지 구현하면 기간 초과. 업로드 방식으로만 시작

### 8. 공동비용 최소 정산 계산기

- 원본 사례: Splitwise
- MVP: 그룹·사람 등록 → 누가 얼마를 냈고 누구 몫인지 입력 → 최종 송금 관계 최소화
- 타깃 예시: 여행, 동호회, 공동현장 식비, 소규모 행사
- 화면: 그룹 생성, 지출 입력, 정산 결과, 공유 링크
- 제외: 은행 송금, 영수증 OCR, 환율 자동화, 장기간 가계부
- 예상 개발: 반나절~1일
- 결제 가능성: 낮음
- 위험: 무료 대안이 많아 독립 SaaS 수익성은 약함. 특정 업종 부가기능으로 적합

### 9. 간단 웹사이트 상태 감시기

- 원본 사례: UptimeRobot
- MVP: URL 등록 → 5분 또는 10분 간격 HTTP 확인 → 실패 시 이메일 알림 → 최근 상태 기록
- 화면: URL 목록, 현재 상태, 장애 이력
- 제외: 전 세계 리전, SMS·전화, SSL 고급 분석, 공개 상태페이지
- 예상 개발: 1~2일
- 결제 가능성: 중간
- 위험: 지속 실행 인프라와 오탐 대응 필요. 개발은 쉽지만 장기 운영 책임이 생김

### 10. 특정 목적 글 변환기

- 원본 사례: Podsqueeze, AudioPen
- MVP: 원문 또는 음성 입력 → 업종별 결과 묶음 생성
- 한 가지 결과 묶음 예시: 현장 메모 → 작업일보 + 고객 보고 문자 + 자재 목록
- 화면: 입력, 결과 3종, 복사·다운로드, 기록
- 제외: 범용 SNS 콘텐츠 생성, 예약 게시, 대규모 파일 처리
- 예상 개발: 1일
- 결제 가능성: 높음
- 위험: 단순 프롬프트 포장으로 보일 수 있으므로 입력폼·고정 양식·업무 저장 흐름이 차별점이어야 함

## 가장 먼저 검토할 3개

### A. 현장 음성보고 변환기

`현장에서 말로 기록 → 작업일보 + 고객보고 문자 + 자재·추가작업 목록 자동 생성`

- 창업자 적합성이 가장 높음: 건설 현장 13년 + ERP 개발 8년 경험 활용
- AI API와 간단한 저장 기능만으로 MVP 가능
- 일반 음성메모가 아니라 현장 결과물 3종을 동시에 만드는 것이 차별점

### B. 견적서·계약서 핵심 추출기

`PDF 업로드 → 금액·기간·특약·누락·주의 항목을 고정 양식으로 추출`

- 사용자가 읽는 시간을 즉시 줄임
- 특정 문서 하나만 선택하면 개발 범위가 작음
- 정확도와 법적 책임 문구가 필요

### C. 공구·자재 위치 기록기

`사진 촬영 → 공구·자재 이름·수량·보관 위치 저장 → 부족·분실 확인`

- AI 없이도 완성 가능
- 소형 공사업체·현장팀의 실제 반복 문제와 연결
- 이후 QR, 대여자, 반납, 점검 기능으로 확장 가능

## 제외 판정

다음은 1~2일 데모는 가능해도 실제 SaaS MVP로는 제외한다.

- Photo AI·Cleanup.pictures: 이미지 생성·편집 품질과 GPU/API 비용 경쟁
- SnoreLab·PictureThis: 분류 정확도와 건강·진단 책임
- Flighty·Seats.aero: 외부 실시간 데이터 확보가 핵심
- Leave Me Alone: 이메일 OAuth·보안·구독해지 처리 복잡성
- Screen Studio·Compresto: 데스크톱 앱·미디어 처리 범위
- Carrd·Tally·Cal.com: 원본 범용 제품을 2일 안에 경쟁력 있게 복제 불가
- 마켓플레이스·채용·여행 데이터베이스: 초기 데이터와 양면시장 필요

## 다음 단계
