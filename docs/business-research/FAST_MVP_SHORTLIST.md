# AI 핵심형 1~7일 MVP 재분류

> 최초 수집한 98개 사례를 기준으로, `AI를 붙일 수 있는가`가 아니라 `AI가 없으면 핵심 가치가 성립하지 않는가`를 기준으로 다시 분류한다. 조사일: 2026-07-14.

## 고정 기준

- AI가 입력을 해석·분류·추출·생성·진단·변환해야 핵심 결과가 나온다.
- 단순 CRUD, 알림, 폼, 타이머, 재고, 캘린더, 계산기는 제외한다.
- 외부 AI API 사용은 허용하고 자체 모델 학습은 하지 않는다.
- 피터 레벨스식 MVP 기준으로 로그인·완벽한 결제·관리자·예외처리는 최소화한다.
- 핵심 입력 → AI 처리 → 결과 확인·복사·다운로드가 작동하면 출시 가능으로 본다.
- 범용 ChatGPT보다 특정 직업·문서·입력 형식·결과 양식이 명확해야 한다.

## 전체 판정 요약

- `A — 1일 MVP`: 12개
- `B — 2일 MVP`: 13개
- `C — 3~7일 확장형`: 15개
- `제외`: 58개

제외된 58개는 서비스 자체가 나쁜 것이 아니라, AI가 핵심이 아니거나 데이터·플랫폼·하드웨어·복잡한 연동이 먼저 필요한 사례다.

## A — 1일 MVP 가능

### 1. AudioPen형 직업별 음성 정리기

- 입력: 음성 녹음 또는 파일
- AI 핵심: 전사 후 업종별 문서로 재구성
- 결과 예시: 현장일보, 고객문자, 자재목록, 추가작업 목록
- 바로 결제 이유: 말만 하면 사무실 문서가 완성됨

### 2. Podsqueeze형 원본 콘텐츠 재가공기

- 입력: 영상·오디오·자막
- AI 핵심: 요약·제목·쇼노트·블로그·SNS 글 생성
- MVP 제한: 결과 형식 3개만 제공
- 바로 결제 이유: 한 원본을 여러 채널에 재사용

### 3. Formula Bot형 업종별 계산식 생성기

- 입력: 자연어 업무 설명
- AI 핵심: 엑셀 공식·계산식·정리 규칙 생성
- MVP 제한: 한 업종, 한 시트 구조
- 바로 결제 이유: 공식 검색과 오류 수정 시간을 줄임

### 4. PDF.ai형 특정 문서 요약기

- 입력: PDF 1개
- AI 핵심: 핵심 항목 추출·요약·질문 답변
- MVP 제한: 문서 유형 하나
- 바로 결제 이유: 전체 문서를 읽지 않고 필요한 답을 얻음

### 5. 특정 문서 위험·누락 추출기

- 입력: 임대차계약서, 공사 견적서, 보험증권 중 하나
- AI 핵심: 금액·기간·특약·누락·주의사항 추출
- MVP 제한: 법률 판단이 아니라 확인 보조
- 바로 결제 이유: 실수로 인한 금전 손실 방지

### 6. AudioPen형 상담 결과 변환기

- 입력: 상담 녹음 또는 메모
- AI 핵심: 상담 요약, 고객 답장, 후속 할 일 생성
- 고객: 부동산, 공사업체, 코치, 상담사
- 바로 결제 이유: 상담 뒤 반복 문서작업 제거

### 7. Storyworth형 가족 이야기 정리기

- 입력: 음성·텍스트 답변
- AI 핵심: 구어체를 읽기 좋은 회고록 문장으로 편집
- MVP 제한: 질문 발송과 PDF 출력만
- 바로 결제 이유: 가족 기억을 완성된 결과물로 보존

### 8. Typefully형 소셜 글 변환기

- 입력: 긴 메모 또는 원문
- AI 핵심: 플랫폼별 길이·형식·말투로 재작성
- MVP 제한: 한 플랫폼 또는 한 업종
- 바로 결제 이유: 복사·편집·줄바꿈 반복 제거

### 9. HelpKit형 문서 FAQ 생성기

- 입력: 기존 문서·매뉴얼
- AI 핵심: 질문·답변·카테고리·검색 키워드 자동 생성
- MVP 제한: 정적 공개 페이지
- 바로 결제 이유: 기존 문서를 고객지원 자산으로 즉시 전환

### 10. LogSnag형 AI 사건 요약 피드

- 입력: 앱 이벤트 또는 CSV
- AI 핵심: 중요한 변화만 설명하고 우선순위 분류
- MVP 제한: 실시간 연동 없이 파일 업로드 가능
- 바로 결제 이유: 많은 이벤트 중 봐야 할 것만 확인

### 11. 후기 AI 정리기

- 입력: 고객 후기 여러 개
- AI 핵심: 핵심 문장 추출, 주제 분류, 대표 후기 생성
- MVP 제한: 후기 수집 기능 없이 붙여넣기·CSV 업로드
- 바로 결제 이유: 흩어진 칭찬을 판매 문구로 전환

### 12. 광고·랜딩 문구 생성기

- 입력: 상품 정보와 고객 정보
- AI 핵심: 헤드라인, CTA, 광고문구, FAQ 생성
- MVP 제한: 특정 업종 템플릿
- 바로 결제 이유: 판매 페이지 초안을 즉시 확보

## B — 2일 MVP 가능

### 13. Photo AI형 특정 목적 이미지 생성기

- 입력: 사용자 사진
- AI 핵심: 특정 직업·상황의 이미지 생성
- MVP 제한: 한 콘셉트, 외부 이미지 API, 비동기 결과
- 예시: 건설업 프로필, 부동산 중개사 프로필, 제품 착용컷

### 14. Cleanup.pictures형 단일 이미지 수정기

- 입력: 이미지
- AI 핵심: 물체 제거·배경 정리·결함 복원 중 하나
- MVP 제한: 한 기능만
- 바로 결제 이유: 포토샵 없이 즉시 수정

### 15. Bannerbear형 AI 템플릿 이미지 생성기

- 입력: 문구·사진·가격
- AI 핵심: 문구 요약·배치용 카피 생성 후 템플릿 합성
- MVP 제한: 템플릿 3종
- 바로 결제 이유: 반복 마케팅 이미지 제작 자동화

### 16. Scribe형 화면 캡처 매뉴얼 생성기

- 입력: 화면 캡처 여러 장
- AI 핵심: 단계 제목·설명·주의사항 생성
- MVP 제한: 자동 녹화 제외, 업로드 방식
- 바로 결제 이유: 매뉴얼 작성 시간을 크게 줄임

### 17. PictureThis형 제한된 사진 진단기

- 입력: 특정 대상 사진
- AI 핵심: 상태 분류·가능 원인·다음 행동 제시
- MVP 제한: 식물 전체가 아니라 한 업종 대상
- 예시: 건물 하자, 곰팡이, 창호 손상, 공구 마모

### 18. 건설 하자 사진 보고서 생성기

- 입력: 사진 + 간단 메모
- AI 핵심: 하자 유형, 심각도, 조치 초안, 고객보고 문장 생성
- MVP 제한: 법적 판정·정밀 견적 제외
- 바로 결제 이유: 현장 사진을 즉시 보고서로 전환

### 19. Stylebook형 AI 코디 추천기

- 입력: 보유 옷 사진과 상황
- AI 핵심: 조합 추천과 이유 생성
- MVP 제한: 자동 배경제거·날씨 연동 제외
- 바로 결제 이유: 보유 자산 활용과 선택 피로 감소

### 20. Whering형 일정별 선택 추천기

- 입력: 보유 자산 목록 + 목적·상황
- AI 핵심: 오늘의 최적 조합 추천
- 파생 분야: 공구 세트, 촬영 장비, 여행 준비물
- 바로 결제 이유: 무엇을 가져갈지 결정 시간 절감

### 21. Dogo형 맞춤 일일 훈련 생성기

- 입력: 반려동물 문제·나이·환경
- AI 핵심: 단계별 훈련 계획과 매일 과제 생성
- MVP 제한: 전문가 영상 피드백 제외
- 바로 결제 이유: 검색 영상보다 개인화된 순서 제공

### 22. Planta형 맞춤 관리 계획 생성기

- 입력: 대상 종류·환경·현재 상태
- AI 핵심: 관리 일정·주의사항·다음 행동 생성
- 파생 분야: 식물, 장비, 건물 시설, 반려동물
- 바로 결제 이유: 매번 관리법을 검색하지 않아도 됨

### 23. SnoreLab형 음성 패턴 분석기

- 입력: 수면 음성 또는 특정 업무 음성
- AI 핵심: 구간 탐지·분류·점수화
- MVP 제한: 의료 진단 제외, 짧은 녹음 분석
- 바로 결제 이유: 사람이 전체 녹음을 듣지 않아도 됨

### 24. Paired형 AI 대화 중재기

- 입력: 두 사람의 별도 답변
- AI 핵심: 공통점·차이·대화 질문 생성
- MVP 제한: 치료·상담 판단 제외
- 바로 결제 이유: 민감한 대화의 시작 부담을 줄임

### 25. 영수증·견적서 비교기

- 입력: 문서 2~5개
- AI 핵심: 항목 정규화·차이·누락·가격 변동 설명
- MVP 제한: 한 문서 포맷 또는 한 업종
- 바로 결제 이유: 수작업 비교와 계산 제거

## C — 3~7일 확장형

### 26. TypingMind형 업종 전용 AI 작업공간

- 여러 모델·대화·프롬프트를 통합하면 3~7일 필요
- 범용 제품은 경쟁이 강하므로 건설·임대·피트니스처럼 한 업종만 가능

### 27. Photo AI 다중 콘셉트 버전

- 사용자별 기록, 크레딧, 비동기 작업, 갤러리, 실패 재처리 필요

### 28. PDF 다중 문서 비교·지식베이스

- 문서 저장, 검색 인덱스, 근거 표시, 권한 관리가 추가됨

### 29. Screen Studio형 AI 영상 자동 편집

- 화면 녹화, 자막, 자동 줌, 커서 추적, 출력 처리 때문에 3~7일 이상
- 최초 MVP는 자막·요약·하이라이트만 가능

### 30. Podscan형 특정 음성 채널 모니터링

- 지속 수집·전사·색인·알림이 필요
- 최초에는 사용자가 업로드한 파일 묶음 검색으로 축소 가능

### 31. Reclaim형 AI 일정 재배치

- 캘린더 OAuth·충돌 처리·반복 일정·시간대 예외가 필요
- 최초에는 일정 붙여넣기 후 하루 계획 생성으로 축소

### 32. Featurebase형 AI 고객문의 분류기

- 이메일·채팅 연동, 티켓 상태, 답변 승인 흐름이 필요
- 최초에는 CSV 업로드 후 주제·우선순위 분석 가능

### 33. Reform형 AI 리드 선별기

- 폼·조건분기·CRM 전송까지 포함하면 3~7일
- 최초에는 제출 내용을 AI가 점수화하는 기능만 가능

### 34. Papermark형 AI 문서 열람·반응 분석

- 공유 링크·열람 이벤트·페이지 분석과 AI 요약이 필요

### 35. Monarch/Copilot형 AI 지출 분류기

- 금융 연결 없이 CSV 업로드로는 가능
- 실제 서비스 수준은 금융 API와 보안 때문에 장기화

### 36. Rocket Money형 구독 탐지기

- 카드내역 CSV에서 반복 결제를 AI·규칙으로 탐지하는 MVP 가능
- 실제 해지 대행과 금융 연동은 제외

### 37. YNAB형 AI 예산 코치

- 거래 CSV 업로드 → 분류 → 위험 지출·다음 행동 제안
- 개인화와 장기 추적까지 가면 3~7일 이상

### 38. Storyworth 장기 자동 출판형

- 질문 예약, 가족 초대, 사진·음성 관리, 책 레이아웃·인쇄 연동 필요

### 39. Sweepy/Tody형 AI 상태 판단 관리기

- 단순 주기 알림은 AI가 아니므로 제외
- 사진·메모로 현재 상태를 판단하고 우선순위를 추천할 때 AI 핵심형이 됨

### 40. Flighty형 특정 일정 위험 예측기

- 외부 실시간 데이터가 필요
- 항공 전체는 어려우나 특정 공사 일정·배송·예약 지연 위험으로 좁히면 가능

## 제외 — 58개

### AI가 없어도 핵심 가치가 성립

- Carrd, Tally, Cal.com, Splitwise, Cozi, Routinery
- UptimeRobot, Plausible, Fathom, Pirsch
- Testimonial의 단순 후기 수집 기능
- Sortly의 단순 재고·위치 기록
- Sweepy·Tody의 단순 주기·할 일 기능
- Documenso, Frill, Nolt, Dub, Tolt
- HelpKit·Potion의 단순 게시·동기화 기능

### 데이터·플랫폼·네트워크가 핵심

- Nomads.com, Remote OK, Seats.aero, AllTrails
- Flighty 원본 전체, Life360, Tractive
- Pallyy, Typefully의 전체 예약게시 플랫폼
- Transistor, Podscan 원본 전체

### 하드웨어·센서·금융·의료 책임이 먼저 필요

- Tractive, Life360, SnoreLab 의료 진단형
- Rocket Money 해지·협상 전체
- Monarch, Simplifi, Copilot의 실제 금융계정 연결형

### 단순 계산·기록·게임화 중심

- Splitwise, Habitica, Forest, StepBet
- Routinery, Sweepy, Tody의 비AI 버전
- ClassPass·Audible 같은 크레딧 운영 구조

## 현재 P0 3개

### P0-1. 현장 음성보고 AI

`현장에서 말하기 → 작업일보 + 고객보고 문자 + 자재·추가작업 목록`

- 개발: 1일 MVP
- 외부 API: 음성 전사 + LLM
- 차별화: 건설 현장 필드와 문서 양식
- 첫 고객 접근성: 지인·현장 네트워크 활용 가능

### P0-2. 공사문서 AI 검토기

`견적서·계약서 업로드 → 금액·기간·누락·주의사항·비교표`

- 개발: 1~2일 MVP
- 외부 API: PDF 텍스트 추출 + LLM
- 차별화: 공사·임대 문서에 한정
- 주의: 법률 판단이 아닌 검토 보조로 명확히 표시

### P0-3. 하자사진 AI 보고서

`사진 업로드 → 하자 분류 + 심각도 + 조치 초안 + 고객보고 문장`

- 개발: 2일 MVP
- 외부 API: 비전 LLM
- 차별화: 실제 현장 용어·조치 순서·보고 양식
- 주의: 구조 안전 판정이나 확정 견적은 제외

## 결론

98개 전체를 AI 핵심성으로 다시 보면, 단순히 빠르게 만들 수 있는 서비스는 많지만 AI 때문에 돈을 내는 후보는 약 40개다. 그중 피터 레벨스식으로 1~2일 안에 출시 가능한 것은 25개이며, CozyBuilder가 실제로 유리한 것은 건설·임대·현장 문서와 사진·음성 입력을 다루는 상위 3개다.
