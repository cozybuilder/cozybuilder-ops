# FieldNote AI / 말해짠AI — AI 협업·테스트 데이터 운영 기준

> 기준일: 2026-07-14  
> 내부 프로젝트명: `fieldnote-ai`  
> 서비스 브랜드명: `말해짠AI`  
> 발음·별칭: `말해짜나`

## 1. 목적

건설·인테리어 현장 음성 AI를 빠르게 검증·개발하기 위해 코비, 클로, 제미나이의 역할을 강점에 맞게 분리한다. 모든 AI에게 중요한 판단을 중복 위임하지 않고, 수집·분석·구현·판정을 구분한다.

## 2. 역할 분담

### 코지

- 최종 제품·사업 결정
- 우선순위 승인
- 현장 경험을 바탕으로 용어·업무 적합성 최종 확인

### 코비

- 제품 방향과 MVP 범위 결정
- 클로·제미나이 작업지시 작성
- 조사 결과 교차검증
- 기술·사업·비용 결과 최종 판정
- 출처·저작권·법적 위험 확인
- SSOT 기록 및 진행 관리

### 클로

- 저장소·코드·인프라 작업
- STT·LLM·화자분리·큐·스토리지 기술 검증
- `yt-dlp`, FFmpeg, STT 등을 이용한 테스트 데이터 처리 파이프라인 구현
- 모델별 정확도·처리시간·비용 비교
- 빌드·테스트·배포
- 기술 문서 작성과 commit/push

### 제미나이

제미나이는 대량의 텍스트·자막·전사문을 빠르게 훑고 초벌 분류하는 보조 분석 담당으로 사용한다.

적합한 작업:

- 확보된 긴 자막·전사문 대량 분석
- 현장용어·은어·자재명·규격 후보 추출
- 회의·협의·분쟁·작업 설명 구간 1차 분류
- 금액·일정·변경·결정·책임 관련 발언 후보 추출
- 타임스탬프 기반 중요 구간 추천
- 메타데이터 JSON·CSV 초안 생성
- 많은 자료를 동일 기준으로 초벌 정리

맡기지 않는 작업:

- 제품 핵심 기능 최종 결정
- 기술 아키텍처 최종 선택
- 사업성·가격·손익 최종 판정
- 현장용어의 정답 확정
- 법률·저작권·보안 결론
- 저장소 직접 수정·배포 기준 결정
- 정확도 검증 없이 결과를 사실로 확정

## 3. 제미나이 능력·한계 확인 결과

### 단독으로 가능한 범위

- 제공받은 텍스트·자막·전사문 분석
- 현장용어 및 숫자·금액·일정 후보 추출
- 문맥 기반 구간 분류
- 데이터 구조와 자동화 코드 초안 작성
- JSON·CSV 형태의 메타데이터 생성

### 외부 도구와 결합해야 가능한 범위

- 유튜브 검색 자동화: YouTube Data API 또는 검색 스크립트
- 자막 추출: `yt-dlp` 등
- 음원 추출·구간 자르기·형식 변환: `yt-dlp` + FFmpeg
- 자막 없는 음성 전사: Whisper 계열 또는 외부 STT API
- 화자분리: 별도 diarization 모델/API
- 로컬 폴더·파일 저장: 실행 가능한 Python/Node 스크립트

### 단독 수행이 불가능한 범위

- 유튜브 영상을 직접 재생해 청취·시청
- 현장소음 수준을 귀로 판정
- 유튜브 음원 직접 다운로드
- 코지 로컬 프로젝트 폴더 직접 제어
- 오디오 파일을 직접 변환·편집·저장

## 4. 제미나이 보고서 교정 기준

다음 표현은 그대로 사실로 사용하지 않는다.

- `전문용어·숫자를 완벽 추출한다` → 완벽을 전제하지 않고 정답지 기반 정확도 평가
- `내부 테스트·파인튜닝이면 안전하다` → 비공개 사용도 저작권·서비스 약관 검토 필요
- `음성을 변조하면 데모에 사용 가능하다` → 변조가 이용 권한을 만들지 않음
- `Spleeter·Demucs로 현장소음 제거 가능` → 음악 소스 분리 도구이며 현장음 정제의 보장된 해법이 아님
- `자막만으로 화자 수·소음 수준을 정확히 판정` → 자막만으로는 정확한 판정 불가

제미나이 결과는 항상 `후보·추정·초벌 분류`로 취급하고 사람이 검수한다.

## 5. 유튜브·공개 영상 테스트 데이터 운영

### 목적

- 범용 STT의 현장용어 인식률 확인
- 소음·겹침 발화·빠른 말투 성능 비교
- 회의에서 결정·금액·일정·변경·미확정 항목 추출 가능성 검증
- 현장용어 사전 적용 전후 성능 비교

### 수집 우선순위

1. 실제 여러 사람이 대화하는 공사현장 영상
2. 현장소음이 포함된 영상
3. 공정·추가공사·하자·금액·일정 협의 영상
4. 금속·잡철·목공·창호·타일·전기·설비 등 전문용어가 많은 영상
5. 공식·자동 자막 또는 대본이 있어 정답 비교가 가능한 영상

### 메타데이터

- 원본 URL
- 영상 제목·채널·업로드 날짜
- 공종
- 대화 유형
- 예상 화자 수
- 구간 시작·종료 시간
- 소음 수준(실제 청취 후 사람이 기록)
- 자막 존재 여부
- 테스트 목적
- 저작권·이용 조건 메모

### 사용 원칙

- 공개 영상의 추출 음원은 내부 기술평가 목적으로 제한한다.
- 원본 음원을 제품·데모·홍보에 공개하거나 재배포하지 않는다.
- 모델 학습·파인튜닝 사용 가능 여부는 출처별 권리와 약관을 별도 확인한다.
- 공개 데모와 제품 예시는 직접 제작하거나 사용 허가를 확보한 음성을 사용한다.
- 출처 URL과 이용 목적을 반드시 남긴다.

## 6. 권장 테스트 파이프라인

```text
영상 후보 검색
→ URL·메타데이터 수집
→ 클로가 자막·음원 추출 파이프라인 실행
→ STT 전사 및 타임스탬프 생성
→ 제미나이가 전사문 초벌 분석
→ 현장용어·결정·금액·일정·변경 후보 추출
→ 코비·코지가 정답지와 비교 검수
→ 정확도·비용·제품 가치 판정
```

폴더 예시:

```text
fieldnote-ai/
  research/
    audio-test-data/
      metal/
      carpentry/
      windows/
      electrical/
      plumbing/
      tile/
      meetings/
      disputes/
```

## 8. 고정 결론

- 제미나이는 중요한 최종 판단자가 아니라 대량 자료의 초벌 분석 보조자다.
- 유튜브 음원 추출·STT·파일 저장은 클로가 구현한 외부 파이프라인에서 수행한다.
- 제미나이는 확보된 자막·전사문을 분석해 현장용어와 중요 발언 후보를 추출한다.
- 정확도·저작권·기술·제품 판단은 코비가 교차검증하고 코지가 최종 결정한다.
- 각 AI는 강점에 맞는 일만 맡기며, 사용할 일이 있다는 이유로 무조건 투입하지 않는다.
