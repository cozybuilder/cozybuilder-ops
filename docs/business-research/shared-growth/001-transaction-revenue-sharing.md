# 공동성장 모델 1 — 거래 수익 공유형 10개

> 사용자가 제휴 링크·오퍼·결제수단을 통해 거래하면 브랜드·판매자가 성과 수수료를 지급하고, 플랫폼이 그 수익 일부를 사용자에게 캐시백·포인트·청구서 차감·대출 상환 형태로 돌려주는 구조다. 조사일: 2026-07-13.

## 공통 구조

`사용자 거래 → 제휴처 성과 수수료 → 플랫폼 수익 인식 → 일부 사용자 환원`

핵심은 회사 내부 이익을 임의로 깎는 것이 아니라, 원래 브랜드가 광고·유입에 쓰던 비용을 실제 거래를 만든 사용자와 공유하는 것이다.

## 금전 구조 기록 기준

- 사용자 비용: 가입비·구독료·연회비·출금 수수료
- 플랫폼 수익: 제휴수수료·판매 성과비·유료 멤버십·금융·광고 수익
- 사용자 환원: 현금·포인트·기프트카드·생활비 차감·부채 상환
- 지급 조건: 최소 출금액·확정 대기·환불 시 회수
- 공개되지 않은 제휴수수료율과 플랫폼 보유 비율은 추정하지 않는다.

## 1. Rakuten Rewards

- 사용자 행동: Rakuten 링크·앱·확장 프로그램을 거쳐 제휴 쇼핑몰에서 구매
- 보상 재원: 판매자가 지급하는 제휴·성과 수수료
- 사용자 환원: 현금 캐시백 또는 제휴 포인트 전환
- 사용자 비용: 기본 가입·이용 무료. 구매대금 외 정기 구독료 없음
- 플랫폼 수익: 제휴 판매가 확정되면 판매자로부터 수수료를 받고 일부를 사용자에게 지급
- 환원 금액: 판매처·기간별 고정액 또는 구매액 비율로 달라짐. 플랫폼이 받은 수수료 중 정확히 몇 %를 보유하는지는 공개 확인 불가
- 지급 조건: 반품·취소 가능 기간이 지난 확정 거래를 기준으로 정기 지급
- 강점: 사용자가 원래 하려던 소비에 보상을 붙여 진입장벽이 낮음
- 적용 힌트: 교육·광고·AI 도구·장비 구매 제휴수수료 일부를 CozyBuilder 성장포인트로 환원
- 근거: https://www.rakuten.com/

## 2. Ibotta

- 사용자 행동: 특정 상품 오퍼를 선택하고 구매·영수증·연동 계정으로 거래 확인
- 보상 재원: 브랜드가 실제 판매 성과가 발생했을 때 지급하는 프로모션 비용
- 사용자 환원: 현금 캐시백
- 사용자 비용: 기본 앱 가입·이용 무료. 오퍼 사용을 위한 월 구독료 없음
- 플랫폼 수익: 브랜드가 노출·클릭이 아니라 실제 판매가 발생했을 때 성과비 지급
- 환원 금액: 상품별 정액 또는 조건부 캐시백. 브랜드 비용과 사용자 지급액의 정확한 차액은 비공개
- 지급 조건: 현금 인출 최소 잔액과 계정·거래 검증 조건이 있으며 최신 금액은 공식 도움말 재확인 필요
- 강점: 노출·클릭이 아니라 검증된 구매에만 브랜드 비용이 발생
- 적용 힌트: 사용자가 성장에 필요한 상품을 실제 구매했을 때만 보상
- 근거: https://ibotta.com/

- 보상 재원: 판매자가 지급한 제휴수수료
- 사용자 환원: 현금·은행이체·기프트카드

- 플랫폼 수익: 제휴수수료, 광고·프로모션, 유료 멤버십
- 환원 금액: 판매처별 비율·정액. 기프트카드로 받을 때 추가 보너스가 붙을 수 있음
- 지급 조건: 판매처가 거래를 승인한 뒤 지급 가능. 취소·반품 거래는 보상 제외
- 강점: 수수료 대부분 또는 전부를 사용자에게 돌려주고 프리미엄·광고·제휴 조건으로 수익화
- 적용 힌트: 핵심 캐시백은 크게 돌려주고 별도 유료 멤버십으로 운영비 확보
- 근거: https://www.topcashback.com/

## 4. Quidco

- 사용자 행동: Quidco를 거쳐 보험·통신·쇼핑·여행 상품 구매
- 보상 재원: 제휴처가 지급한 추천·판매 수수료
- 사용자 환원: 현금 또는 보너스가 붙은 기프트카드
- 사용자 비용: Basic 무료. Premium은 공개 정보 기준 캐시백 잔액에서 월 £1을 차감하는 방식
- 플랫폼 수익: 제휴수수료 일부, Premium 이용료, 프로모션 계약
- 환원 금액: 판매처별 정액·비율. Premium 사용자는 일부 거래에서 높은 캐시백이나 별도 혜택을 받을 수 있음
- 지급 조건: 제휴처 승인 후 지급. 최근 혜택 변경 사례가 있어 현재 Premium 혜택은 가입 전 재확인 필요
- 강점: 일반 쇼핑뿐 아니라 보험·통신 전환처럼 수수료가 큰 거래에서 높은 보상 가능
- 적용 힌트: 단가가 큰 서비스 전환·가입에서 성장기금 재원을 확보
- 근거: https://www.quidco.com/

- 보상 재원: 판매자 제휴수수료와 프로모션 예산
- 사용자 환원: 현금 캐시백·쿠폰·지역별 결제 혜택
- 사용자 비용: 기본 가입·이용 무료. 지역별 결제·금융 부가서비스에는 별도 조건이 있을 수 있음
- 플랫폼 수익: 제휴수수료, 브랜드 프로모션, 결제·금융 부가서비스
- 환원 금액: 제휴처별 비율·정액으로 변동
- 지급 조건: 국가별 최소 인출액·지급수단·승인기간이 다르므로 해당 지역 정책 확인 필요
- 강점: 여러 국가의 쇼핑몰·여행·배달 서비스를 한 보상 지갑으로 묶음
- 적용 힌트: 서로 다른 성장 관련 제휴처를 하나의 CozyBuilder 성장지갑으로 통합
- 근거: https://www.shopback.com/

- 사용자 비용: 무료

- 환원 금액: 판매처·오퍼별로 변동하며 일부 구매는 보상이 없음
- 지급 조건: 거래 확정 후 PayPal Rewards 등으로 적립·교환. 현재 제휴 귀속 방식 관련 분쟁과 정책 변경 이력이 있어 투명성 검토가 필요

- 근거: https://www.airtimerewards.co.uk/

## 9. Sprive

- 사용자 행동: 제휴 브랜드의 디지털 기프트카드를 구매해 소비
- 보상 재원: 기프트카드·제휴 판매 수수료
- 사용자 환원: 캐시백을 주택담보대출 원금 상환에 자동 투입
- 사용자 비용: 앱 기본 이용 무료로 안내됨. 사용자의 주택담보대출 조기상환 한도를 초과하면 대출기관의 중도상환 수수료가 발생할 수 있음
- 플랫폼 수익: 기프트카드·브랜드 제휴수수료, 모기지·브로커 연계 수익 가능
- 환원 금액: 브랜드별 캐시백 비율로 변동. 현금 소비보다 원금 상환에 연결해 장기 이자 절감 효과가 추가됨
- 지급 조건: 캐시백이 모기지 상환 계정으로 연결되며 대출기관별 연간 무수수료 상환 한도 확인 필요
- 강점: 작은 소비 보상을 장기 부채 감소라는 성장 결과로 연결
- 적용 힌트: 캐시백을 현금소비가 아니라 교육비·광고비·사업자금 적립으로 자동 전환
- 근거: https://sprive.com/

## 이 모델에서 얻은 핵심 패턴

1. 외부 제휴수수료를 보상 재원으로 쓰면 회사 자체 구독매출을 직접 깎지 않아도 된다.
2. 현금보다 사용자의 목표에 자동 투입되는 보상이 공동성장 효과가 크다.
3. 단순 캐시백보다 가격비교·쿠폰·비용절감과 결합하면 재사용 이유가 강해진다.
4. 큰 수수료가 발생하는 보험·통신·교육·광고·도구 구매는 성장기금 재원으로 적합하다.
5. 결제 취소·환불 후 보상 회수, 지급 대기기간과 부정거래 방지가 필수다.
6. 무료 서비스라도 플랫폼이 실제 제휴수수료 중 얼마를 사용자에게 나누는지 공개하지 않으면 공동성장 투명성이 약하다.
7. CozyBuilder는 `수익 발생액·환원율·확정 대기액·회수액`을 사용자에게 공개하는 방식이 적합하다.

## CozyBuilder 적용 후보

`성장 관련 제휴 구매 → 제휴수수료 수령 → 일정 비율 성장포인트 지급 → 앱 구독·AI 크레딧·교육·광고·제작비에 자동 사용`

현금화보다 사용자의 다음 성장에 직접 쓰이게 설계하면 회사와 사용자의 목적이 더 강하게 연결된다.
