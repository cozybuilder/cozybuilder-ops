# 공동성장 모델 마지막 — 규칙 기반 자동 지원·무료 이용권 10개

> 적립된 성장기금을 운영자 임의 심사 없이 공개된 자격 조건으로 배분하는 구조를 조사한다. 완전 자동 현금 분배 사례는 드물어, 실제 SaaS에서 널리 쓰이는 `자격 검증 → 유료 기능 무료·할인 제공` 모델을 중심으로 본다. 조사일: 2026-07-14.

## 공통 구조

`유료 고객 매출 → 회사 내부 지원예산 확보 → 공개된 자격 조건 확인 → 무료 플랜·크레딧·할인 자동 또는 반자동 지급`

현금 장학금보다 제품 접근권을 제공하므로 지급·세무·계좌 관리가 단순하다. 다만 학교·비영리·공익단체처럼 자격 검증이 가능한 집단에 가장 잘 맞는다.

## 1. Notion for Education

- 주요 사용자: 개인, 팀, 학생, 교직원, 학생단체
- 사용 흐름: 무료 워크스페이스 생성 → 수업·과제·프로젝트 관리 → 고급 저장·버전·협업 기능 필요 시 유료 전환
- 지원 규칙: 인정된 대학·학교 이메일로 로그인한 학생·교직원은 1인 워크스페이스 Plus 플랜을 무료로 받을 수 있음
- 자동화 수준: 학교 도메인이 등록돼 있으면 제품 안에서 자동 업그레이드, 미등록 도메인은 별도 요청
- 1인기업 적용 힌트: 특정 협회·교육과정·창업지원기관 이메일 도메인에 무료 플랜 자동 부여
- 근거: https://www.notion.com/product/notion-for-education

## 이번 모델의 핵심 발견

1. 완전 자동 현금 분배보다 `유료 기능 무료 제공`이 훨씬 일반적이다.
2. 가장 자동화하기 쉬운 자격은 학교 이메일, 가입기간, 결제이력, 제품 내 성과처럼 시스템이 확인 가능한 정보다.
3. 비영리·공익성 판단처럼 해석이 필요한 조건은 결국 수동 심사가 남는다.
4. 자격 기반 무료 플랜은 사용자 성장에 직접 도움이 되지만, 기존 유료 고객과의 형평성 기준이 필요하다.
5. 지원 규모는 현금이 아니라 기간·기능·크레딧 상한으로 통제하는 편이 안전하다.

## CozyBuilder 적용 후보

### A. 자동 성장지원 좌석

- 월 유료 고객 20명당 지원 좌석 1개 생성
- 지원 좌석은 3개월 무료 또는 AI 크레딧 묶음
- 미사용 좌석은 다음 분기로 최대 1회 이월

### B. 공개 자격 조건

자동 승인 예시:

- 서비스 6개월 이상 정상 사용
- 최근 3개월 결제 연체 없음
- 등록 데이터·백업 등 핵심 온보딩 완료
- 현재 관리 호실 수 또는 사업 초기 단계 기준 충족

수동 승인 제외:

- 사연 심사
- 대표 개인 판단
- 인기투표
- 추첨

### C. 가장 단순한 배분식

`월 유료 결제 20건 → 다음 달 무료 이용권 1개 생성 → 조건 충족 신청자 중 접수 순 자동 지급`

이 방식은 운영자가 매번 누구를 뽑을지 고민하지 않아도 된다.

## 결론

1인기업이 성장기금을 자동 배분하려면 현금 장학금보다 `조건 충족 시 무료기간·크레딧·유료 기능 자동 개방`이 현실적이다. 완전 자동화가 필요하면 사람의 사정을 해석하는 기준을 버리고, 시스템이 이미 가진 계정·결제·사용 데이터를 기준으로 해야 한다.
