# 공동성장 모델 7 — 순매출·이익 일부 자동 환원형 10개

> 추천·게임화·현금 정산 없이도 회사가 번 돈의 일정 비율 또는 판매 1건당 고정 가치를 사용자 공동 목적·공익·성장기금에 자동 배정하는 구조다. 조사일: 2026-07-14.

## 공통 구조

`사용자 결제·이용 → 회사 매출 발생 → 사전에 정한 비율·금액 적립 → 공익·공동기금·사용자 성장지원 집행 → 결과 공개`

이 모델은 한 명씩 현금 정산하지 않아도 된다. 대신 사용자가 체감할 수 있도록 적립 기준, 누적 금액, 집행처, 성과를 공개해야 한다.

## 1. Ecosia

- 어떤 서비스인가: 검색엔진·브라우저. 사용자는 일반 검색처럼 이용하고 광고 클릭이 수익을 만든다.
- 주요 사용자: 검색은 필요하지만 개인정보 보호와 환경 기여를 중시하는 사람.
- 이용 흐름: 검색 → 광고 노출·클릭 → 광고수익 발생 → 운영비 차감 → 기후·식림 프로젝트 투자.
- 사용자 비용: 기본 검색 무료.
- 환원 구조: 이익을 기후 행동에 재투자하고 월별 재무·성과 자료를 공개한다.
- 1인기업 적용성: 중간. 광고사업은 어렵지만 `월 순매출 일정 비율 공개 적립` 방식은 쉽게 차용 가능.
- 적용 힌트: CozyBuilder 월 순매출 3%를 사용자 성장기금으로 자동 적립하고 대시보드 공개.

## 2. Patagonia

- 어떤 서비스인가: 아웃도어 의류·장비 브랜드. 제품 판매와 수선·재사용 프로그램을 함께 운영한다.
- 주요 사용자: 내구성·환경가치·브랜드 철학을 중시하는 소비자.
- 이용 흐름: 제품 탐색·구매 → 사용·수선 → 필요 시 재사용·재판매 → 매출 일부 환경단체 지원.
- 사용자 비용: 제품 구매비.
- 환원 구조: 오랫동안 매출의 1%를 환경단체에 지원해 왔다.
- 1인기업 적용성: 매우 높음. 이익이 아니라 매출 기준이라 계산이 단순하지만 적자여도 지급해야 하는 부담이 있다.
- 적용 힌트: 초기에는 총매출 1%보다 `결제수수료·환불 제외 순매출 1%`가 안전.

## 3. Who Gives A Crap

- 어떤 서비스인가: 재생지·대나무 화장지와 생활용지를 온라인 정기배송·소매로 판매한다.
- 주요 사용자: 반복 생필품을 구매하면서 위생·환경 문제 해결에 기여하고 싶은 가정.
- 이용 흐름: 상품 선택 → 일회성 또는 정기 주문 → 배송 → 운영비·원가 차감 → 이익의 일부를 위생 프로젝트에 기부.
- 사용자 비용: 제품 구매비·정기배송비.
- 환원 구조: 이익의 50%를 깨끗한 물과 위생 프로젝트에 기부.
- 1인기업 적용성: 중간. 50%는 무겁지만 `이익 발생 시에만 일정 비율` 구조는 안정적이다.
- 적용 힌트: 흑자월 순이익의 10%만 성장기금 적립, 적자월은 0원.

## 4. tentree

- 어떤 서비스인가: 지속가능 소재 의류·액세서리를 판매하는 브랜드.
- 주요 사용자: 친환경 소비와 나무심기 성과를 함께 원하는 소비자.
- 이용 흐름: 제품 구매 → 주문 1건 또는 제품 수량 기준으로 나무심기 재원 배정 → 프로젝트 진행 → 영향 공개.
- 사용자 비용: 제품 구매비.
- 환원 구조: 제품 판매와 나무심기를 직접 연결하는 고정 단위형.
- 1인기업 적용성: 매우 높음. 비율 계산 없이 `유료 구독 1건당 500원 적립`처럼 구현 가능.
- 적용 힌트: CozyRent 유료 가입 1건마다 사용자 성장기금 1,000원 적립.

## 5. Bombas

- 어떤 서비스인가: 양말·속옷·의류를 판매하는 D2C 브랜드.
- 주요 사용자: 품질 좋은 기본 의류를 사면서 노숙인 지원에 참여하려는 소비자.
- 이용 흐름: 상품 구매 → 판매 1개 확인 → 기부용 제품 1개 배정 → 협력 보호시설에 전달.
- 사용자 비용: 제품 구매비.
- 환원 구조: 구매 1개당 필요한 의류 1개 기부.
- 1인기업 적용성: 높음. 금액 비율보다 `행동 1건당 고정 지원`이라 투명하다.
- 적용 힌트: 유료 고객 10명 증가할 때마다 사용자 1명에게 한 달 무료 지원.

## 6. Warby Parker

- 어떤 서비스인가: 안경·선글라스·콘택트렌즈 판매와 시력검사를 제공하는 온·오프라인 안경 서비스.
- 주요 사용자: 합리적 가격·디자인·온라인 구매 편의를 원하는 사람.
- 이용 흐름: 프레임 탐색·가상착용·검사 → 구매 → 파트너 단체를 통해 안경 보급 재원 지원.
- 사용자 비용: 안경·검사·렌즈 구매비.
- 환원 구조: 구매 1건과 안경 접근성 지원을 연결.
- 1인기업 적용성: 높음. 직접 물품 기부 대신 기존 유료 사용자 1명을 새 사용자 지원과 연결 가능.
- 적용 힌트: 연간 결제 20건마다 경제적 사정이 어려운 사용자 1명에게 3개월 무료 이용권.

## 7. TOMS

- 어떤 서비스인가: 신발·의류·액세서리 판매 브랜드.
- 주요 사용자: 제품 구매와 사회문제 지원을 함께 고려하는 소비자.
- 이용 흐름: 상품 구매 → 회사 이익 발생 → 비영리 파트너·지원사업에 현금성 기금 배정.
- 사용자 비용: 제품 구매비.
- 환원 구조: 과거 1-for-1에서 현재는 이익 일부를 보조금·파트너십 형태로 지원하는 구조로 전환.
- 1인기업 적용성: 중간~높음. 현물 1:1보다 이익 비율 방식이 운영 유연성이 높다.
- 적용 힌트: 특정 사용자를 직접 선정하지 말고 검증된 지원기관·교육 서비스 비용으로 집행.

## 8. Better World Books

- 어떤 서비스인가: 중고·신간 도서를 판매하고 기부받은 책을 재사용·기부·재활용하는 온라인 서점.
- 주요 사용자: 저렴한 책을 사고 동시에 문해력·책 접근성 개선에 기여하려는 독자.
- 이용 흐름: 기부·매입으로 책 확보 → 온라인 판매 → 책 또는 판매 수익 일부를 문해력 파트너에 지원 → 영향 수치 공개.
- 사용자 비용: 도서 구매비.
- 환원 구조: 판매 1건과 책 기부·문해력 지원을 연결한다.
- 1인기업 적용성: 높음. 사용자가 서비스에서 만든 잉여 자원이나 미사용 권리를 다른 사용자에게 넘기는 방식으로 차용 가능.
- 적용 힌트: 소멸 예정 포인트를 사용자 선택으로 성장기금에 기부하게 하고 회사가 일부 매칭.

## 9. BookKind

- 어떤 서비스인가: 온라인 서점. 사용자가 책을 구매할 때 지원할 자선단체를 선택할 수 있다.
- 주요 사용자: 책 구매와 기부처 선택을 동시에 원하는 독자.
- 이용 흐름: 책 탐색 → 결제 → 8개 안팎의 단체 중 하나 선택 → 판매액의 일정 비율 배정.
- 사용자 비용: 책 구매비.
- 환원 구조: 판매액의 10%를 사용자가 선택한 단체에 기부하는 구조로 출범.
- 1인기업 적용성: 매우 높음. 핵심은 운영자가 수혜처를 혼자 정하지 않고 사용자가 선택하게 하는 것.
- 적용 힌트: 사용자는 포인트를 `내 구독료`, `다른 사용자 지원`, `교육기금` 중 선택.

## 10. Beam Impact

- 어떤 서비스인가: 브랜드 쇼핑몰 결제 과정에 기부 선택 기능과 임팩트 대시보드를 붙여주는 B2B 소프트웨어.
- 주요 사용자: 고객에게 사회적 기여 경험을 제공하려는 온라인 브랜드.
- 이용 흐름: 브랜드가 기부율·단체 설정 → 고객 결제 → 고객이 지원 프로젝트 선택 → 브랜드가 매출 일부 기부 → 고객에게 누적 성과 표시.
- 사용자 비용: 일반 소비자는 추가 결제 없음. 브랜드가 소프트웨어·기부 비용 부담.
- 환원 구조: 결제 시 사용자가 목적지를 선택하고 브랜드가 약속한 비율을 집행.
- 1인기업 적용성: 높음. 자체 개발 없이 단순 선택 UI와 월말 일괄 집행으로도 시작 가능.
- 적용 힌트: CozyBuilder가 월말 순매출 3%를 모아 사용자 투표 1위 성장지원 항목에 배정.

## CozyBuilder 유력안

### 1단계 — 자동 적립만 시작

- 기준: 환불·결제수수료 제외 월 순매출
- 적립률: 3%
- 적립처: 사용자 성장기금
- 공개: 월 매출 기준액, 적립액, 누적액만 공개
- 집행: 분기 1회

### 2단계 — 사용자 선택권 추가

사용자는 자신에게 발생한 성장포인트 일부를 다음 중 선택한다.

1. 본인 구독료 차감
2. 다른 사용자 무료 이용 지원
3. 교육·도구비 공동기금

### 3단계 — 회사 매칭

- 사용자 기부 포인트 1,000점
- 회사 성장기금 1,000점 추가
- 총 2,000점 집행

## 핵심 결론

1. 1인기업에는 `순매출 1~3%` 또는 `유료 결제 1건당 고정액`이 가장 단순하다.
2. 순이익 비율은 안전하지만 사용자 입장에서 계산이 불투명할 수 있다.
3. 환원액보다 적립·집행·잔액을 공개하는 투명성이 더 중요하다.
4. 사용자 개인에게 현금 정산하지 않아도 공동 성장이라는 철학을 구현할 수 있다.
5. 다만 공익 기부만으로 끝나면 사용자의 직접 성장은 약하므로, 본인 혜택·다른 사용자 지원·공동기금 선택권을 결합하는 편이 적합하다.
