# 공동성장 모델 5 — 제품 크레딧·무료기간 환원형 10개

> 현금 정산 없이 기존 서비스의 저장공간·무료기간·사용량·서버 크레딧을 보상하는 구조를 조사한다. 서비스 본체, 사용자 흐름, 유료 전환, 환원 위치, 돈의 흐름을 함께 기록한다. 조사일: 2026-07-13.

## 적용 기준

- 별도 판매자·구매자 시장 불필요
- 외부 광고주·개인정보 판매 불필요
- 현금 송금·세금 정산 최소화
- 보상은 원래 서비스의 디지털 기능·기간·용량
- 사용자 10~100명에서도 작동

## 1. Dropbox

- 어떤 서비스인가: 파일 저장·동기화·공유·백업 서비스
- 주요 사용자: 여러 기기에서 파일을 쓰는 개인·팀
- 이용 흐름: 파일 업로드 → 기기 동기화 → 링크 공유 → 저장공간·복구·협업 한계에서 유료 전환
- 유료 전환: 더 큰 저장공간, 복구기간, 공유·보안·팀 기능
- 환원 구조: 추천 성공 시 Basic 사용자는 500MB, Plus·Family·Professional은 1GB 추가. 신규 가입자도 500MB 추가
- 한도: Basic 최대 16GB, 유료 개인 플랜 최대 32GB
- 돈의 흐름: 현금 지급 없음. 저장공간이라는 디지털 원가가 낮은 보상으로 재사용과 유료 전환을 유도
- 1인기업 적용성: 매우 높음
- 적용 힌트: 추천 성공 시 호실 한도·백업 용량·AI 처리 횟수 증가
- 근거: https://help.dropbox.com/storage-space/earn-space-referring-friends

## 2. Proton

- 어떤 서비스인가: 암호화 이메일·VPN·클라우드 저장소·캘린더·비밀번호 관리자 통합 서비스
- 주요 사용자: 개인정보 보호와 보안을 중시하는 개인·소규모 팀
- 이용 흐름: 무료 이메일·VPN·Drive 사용 → 저장공간·VPN 속도·주소·보안 기능 필요 → 유료 플랜 전환
- 유료 전환: Mail Plus, VPN Plus, Unlimited 등
- 환원 구조: 유료 사용자가 추천 링크를 공유하고 추천받은 사람이 유료 플랜을 결제하면 계정 크레딧 또는 현금성 보상이 발생하는 추천 프로그램
- 정확한 최신 금액: 국가·플랜·프로그램 조건에 따라 달라 공식 추천 화면 재확인 필요
- 돈의 흐름: 실제 유료 결제 후 보상. 계정 크레딧으로 지급하면 현금 유출 없이 갱신 비용에 사용 가능
- 1인기업 적용성: 높음
- 적용 힌트: 앱 결제 잔액으로 우선 지급하고 일정 규모 이후 현금 선택권 추가
- 근거: https://proton.me/support/referral-program

## 3. DigitalOcean

- 어떤 서비스인가: 개발자·스타트업용 서버, 데이터베이스, 스토리지, 앱 배포 클라우드
- 주요 사용자: 개인 개발자·소규모 SaaS·스타트업
- 이용 흐름: 계정 생성 → 서버·앱 배포 → 사용량만큼 월 과금
- 유료 전환: 무료 체험 크레딧 소진 후 실제 인프라 사용료
- 환원 구조: 추천받은 신규 사용자는 일정 기간 사용 가능한 클라우드 크레딧, 추천자는 추천 사용자가 실제 비용 기준을 충족한 뒤 계정 크레딧
- 정확한 최신 금액·조건: 공식 추천 대시보드 재확인 필요
- 돈의 흐름: 서버 원가 범위 안에서 크레딧을 제공하고 신규 고객이 장기 사용하면 이후 사용료가 매출
- 1인기업 적용성: 높음
- 적용 힌트: 신규 고객에게 첫 달 AI·서버 크레딧, 추천자에게 다음 달 사용량 크레딧

## 4. pCloud

- 어떤 서비스인가: 파일 동기화·백업·공유·미디어 재생을 제공하는 클라우드 저장소
- 주요 사용자: 사진·영상·문서를 장기간 보관하려는 개인과 소규모 팀
- 이용 흐름: 무료 저장공간 사용 → 자동 백업·대용량·평생 플랜 필요 → 연간 또는 평생 결제
- 유료 전환: 더 큰 저장공간, 암호화, 장기 파일 이력, 팀 기능
- 환원 구조: 친구 초대·초기 활동으로 무료 저장공간을 늘리는 성장 방식이 사용돼 왔으며 현재 보상량은 계정 화면 재확인 필요
- 돈의 흐름: 현금 대신 저장공간 제공. 일부 사용자는 용량이 커질수록 서비스에 데이터를 더 쌓아 장기 잔존
- 1인기업 적용성: 매우 높음
- 적용 힌트: 사용자 데이터가 늘수록 가치가 커지는 앱에서 기능 한도 보상

## 5. Sync.com

- 어떤 서비스인가: 종단간 암호화 기반 파일 저장·공유·팀 협업 서비스
- 주요 사용자: 보안이 중요한 개인·전문직·소규모 조직
- 이용 흐름: 무료 저장공간 → 파일 동기화·공유 → 더 큰 용량·팀 관리·보안 제어 필요 시 유료 전환
- 환원 구조: 추천 성공 시 무료 저장공간을 추가하는 방식
- 정확한 최신 보상량·상한: 공식 계정 추천 페이지 재확인 필요
- 돈의 흐름: 현금 대신 저장 용량을 지급해 신규 가입과 기존 사용자 잔존을 동시에 유도
- 1인기업 적용성: 매우 높음
- 적용 힌트: 무료 플랜의 핵심 사용량 한도를 추천 보상으로 확장

## 6. MEGA

- 어떤 서비스인가: 암호화 클라우드 저장소·파일 공유·채팅·통화 서비스
- 주요 사용자: 대용량 파일을 보관·전송하고 개인정보 보호를 원하는 사용자
- 이용 흐름: 무료 계정 → 파일 업로드·공유 → 용량·전송량 부족 시 유료 전환
- 환원 구조: 앱 설치·연락처 초대·친구 가입 같은 성과에 보너스 저장공간을 주는 Achievements 구조를 운영해 왔음
- 정확한 최신 보상량·유효기간: 계정별 Achievements 화면 재확인 필요
- 돈의 흐름: 미션형 제품 크레딧으로 사용자가 핵심 기능을 더 경험하게 만든 뒤 유료 전환
- 1인기업 적용성: 매우 높음
- 적용 힌트: 추천 외에도 백업 완료·온보딩 완료 등 제품 가치 체험 행동에 기능 크레딧 지급

## 7. Blomp

- 어떤 서비스인가: 저가형 개인 클라우드 저장·백업 서비스
- 주요 사용자: 대용량 무료·저가 저장공간을 원하는 개인
- 이용 흐름: 무료 저장공간 사용 → 친구 추천으로 용량 확장 → 더 큰 용량 필요 시 월 구독
- 환원 구조: 친구 추천으로 무료 저장공간을 단계적으로 늘릴 수 있으며 공개 정보상 최대 200GB까지 확장 가능
- 유료 구조: 250GB·2TB·10TB 등 월 구독
- 돈의 흐름: 추천 보상으로 초기 확산을 만들고 큰 용량 사용자는 유료 플랜으로 전환
- 1인기업 적용성: 높음
- 적용 힌트: 추천 수에 따라 기능 한도를 누적 확장하되 최대 한도 설정

## 8. Backblaze

- 어떤 서비스인가: 컴퓨터 전체 자동 백업과 기업용 객체 스토리지 서비스
- 주요 사용자: 파일 손실을 막고 싶은 개인·기업
- 이용 흐름: 백업 앱 설치 → 자동 백업 → 장기 복구·대용량 백업에 대해 구독 결제
- 환원 구조: 친구 추천 또는 파트너 링크를 통한 무료기간·계정 크레딧 프로모션이 운영돼 왔으며 최신 프로그램 조건은 공식 페이지 재확인 필요
- 돈의 흐름: 무료기간 동안 실제 백업 데이터를 쌓게 해 전환비용과 서비스 잔존을 높임
- 1인기업 적용성: 높음
- 적용 힌트: 데이터가 쌓일수록 이탈이 줄어드는 서비스에서 무료기간 보상 사용

## 9. NordVPN

- 어떤 서비스인가: 인터넷 연결 암호화, IP 보호, 위협 차단을 제공하는 VPN·보안 구독 서비스
- 주요 사용자: 공공 와이파이·해외 접속·개인정보 보호가 필요한 개인
- 이용 흐름: 구독 구매 → 여러 기기에 앱 설치 → VPN·보안 기능 사용 → 기간 만료 시 갱신
- 환원 구조: 추천한 친구가 구독하면 추천자에게 무료 이용기간을 제공하고 신규 사용자도 장기 플랜에서 추가 무료기간을 받을 수 있는 구조
- 공개 사례: 성공 추천당 추천자 3개월 무료, 신규 사용자는 플랜에 따라 1~3개월 추가 혜택 사례
- 돈의 흐름: 현금 지급 대신 구독 기간을 늘려 이탈을 줄이고 신규 선결제를 확보
- 1인기업 적용성: 매우 높음
- 적용 힌트: 추천 성공 시 다음 갱신일을 자동 연장

## 10. Surfshark

- 어떤 서비스인가: VPN, 악성코드 차단, 개인정보 유출 알림, 대체 ID 등을 묶은 보안 서비스
- 주요 사용자: 여러 기기에서 개인정보 보호와 보안 기능을 원하는 개인·가족
- 이용 흐름: 장기 플랜 선결제 → 무제한 기기 연결 → 보안 기능 사용 → 갱신
- 환원 구조: 친구 추천·프로모션에서 무료 이용개월을 제공하는 방식이 사용되며 정확한 현재 추천 규칙은 계정 화면 재확인 필요
- 돈의 흐름: 장기 선결제 매출을 먼저 받고 무료개월로 사용자 획득비용을 지급
- 1인기업 적용성: 매우 높음
- 적용 힌트: 현금 대신 구독 종료일 연장으로 보상 처리

## 핵심 패턴

1. 보상은 사용자가 이미 원하는 핵심 기능이어야 한다.
2. 현금보다 저장공간·무료기간·사용량은 운영과 세무가 단순하다.
3. 추천받은 사람도 즉시 혜택을 받아야 광고성 추천이 줄어든다.
4. 설치·백업·첫 데이터 등록처럼 제품 가치를 경험한 뒤 보상을 확정해야 한다.
5. 보상 상한을 두면 소수 사용자의 과도한 비용을 막을 수 있다.
6. 데이터·기록이 쌓이는 서비스는 무료기간 보상이 특히 강하다.

## CozyBuilder 적용 후보

- 코지임대: 추천 완료 시 추천자와 신규 사용자 모두 유료기간 14일 연장
- 신규 사용자 조건: 건물 1개와 실제 호실 데이터 등록 완료
- 유료 전환 조건: 첫 결제 후 환불 가능 기간 종료
- 대체 보상 선택: 무료기간 / 호실 한도 / 백업 용량 / AI 크레딧
- 누적 상한: 연간 최대 3개월 또는 일정 포인트

이 방식은 현금 송금·원천징수·출금 시스템 없이 시작할 수 있고, 앱을 계속 사용하는 사람에게만 가치가 있다.
