# 공동성장 모델 6 — 사용·성과 자동 환원형 10개

> 친구 추천이 없어도 사용자가 서비스를 꾸준히 이용하거나 목표를 달성하면 기능·크레딧·할인·공익 성과를 돌려주는 구조를 조사한다. 조사일: 2026-07-14.

## 적용 기준

- 사용자 10명이어도 작동
- 외부 광고주·판매자·추천 네트워크 불필요
- 앱 안의 행동으로 자동 판정
- 현금 정산보다 기능·크레딧·무료기간 우선
- 단순 배지와 실제 경제적 혜택을 구분

## 1. Starbucks Rewards

- 서비스: 커피·음료·푸드 판매와 모바일 주문·결제를 결합한 리테일 서비스
- 이용 흐름: 앱 가입 → 매장·앱 주문 → 결제 시 Stars 적립 → 무료 음료·할인·추가 혜택 사용
- 유료 지점: 상품 구매 자체가 매출
- 환원: 구매·재방문·앱 참여에 따라 Stars와 등급 혜택 제공
- 1인기업 적용성: 높음. 유료 갱신·핵심 기능 사용마다 포인트 지급 가능
- 한계: 소비액 중심이면 많이 쓰는 사용자만 유리
- 근거: https://www.starbucks.com/rewards

## 2. Sephora Beauty Insider

- 서비스: 화장품·스킨케어·향수 등을 판매하는 온·오프라인 뷰티 리테일
- 이용 흐름: 무료 회원 가입 → 상품 구매 → 포인트 적립 → 샘플·제품·할인·생일 혜택 교환 → 연간 구매액에 따라 등급 상승
- 유료 지점: 상품 구매
- 환원: 포인트·등급·무료 배송·우선 구매·이벤트 접근
- 1인기업 적용성: 중간. 등급제는 가능하지만 구매액 중심이라 성장 철학과는 거리가 있음
- 근거: https://www.sephora.com/beauty/beauty-insider

## 3. Google Play Points

- 서비스: Android 앱·게임·디지털 콘텐츠 유통 마켓
- 이용 흐름: 프로그램 가입 → 앱·게임·인앱상품 구매 → 포인트 적립 → Play 크레딧·쿠폰·게임 아이템으로 교환
- 유료 지점: 디지털 구매
- 환원: 현금이 아닌 같은 생태계의 결제 크레딧
- 1인기업 적용성: 높음. 구독료 일부를 내부 크레딧으로 돌려 재사용 유도 가능
- 근거: https://play.google.com/store/points

## 4. Duolingo

- 서비스: 짧은 문제와 반복 학습으로 언어·수학·음악 등을 배우는 교육 앱
- 이용 흐름: 무료 수업 → 일일 학습 → 연속 학습일·리그·퀘스트 진행 → 광고 제거·무제한 기능이 필요하면 구독
- 유료 지점: Super·Max 등 구독
- 환원: streak, gems, 배지, 리그, streak freeze 등 서비스 내부 보상
- 경제성: 대부분 현금 가치보다 학습 지속을 돕는 기능성 보상
- 1인기업 적용성: 높음. 핵심 성장 행동을 연속 달성하면 기능 보호권·크레딧 지급
- 한계: 게임 점수만 쫓아 실제 성과가 왜곡될 수 있음
- 근거: https://www.duolingo.com/

## 5. Habitica

- 서비스: 현실의 할 일·습관·일일 과제를 RPG 퀘스트로 바꾸는 생산성 앱
- 이용 흐름: 할 일 등록 → 완료 체크 → 경험치·골드·아이템 획득 → 캐릭터 성장·파티 퀘스트 → 선택적으로 구독·보석 구매
- 유료 지점: 구독과 인앱 구매
- 환원: 실제 행동 완료를 가상 화폐와 기능으로 보상
- 1인기업 적용성: 높음. 앱의 핵심 업무 완료 시 내부 크레딧 지급 가능
- 한계: 가상 보상이 실제 비용 절감이나 성장 지원으로 이어지지 않을 수 있음
- 근거: https://habitica.com/

## 6. Forest

- 서비스: 정해진 시간 동안 휴대폰 사용을 줄이고 집중하면 가상 나무를 키우는 집중 앱
- 이용 흐름: 집중 시간 설정 → 앱 이탈 없이 완료 → 코인·가상 숲 축적 → 일부 코인으로 실제 나무 심기 지원
- 유료 지점: 앱 구매·인앱 기능
- 환원: 집중 성과를 가상 자산과 공익 성과로 연결
- 1인기업 적용성: 높음. 핵심 행동 완료 시 공동기금에 소액 자동 적립 가능
- 한계: 공익 성과의 집행·검증을 공개해야 함
- 근거: https://www.forestapp.cc/

## 7. Sweatcoin

- 서비스: 스마트폰 걸음 수를 측정해 디지털 포인트로 전환하는 걷기 보상 앱
- 이용 흐름: 걸음 측정 → 검증된 걸음에 포인트 → 앱 내 상품·혜택·기부 등에 사용
- 유료 지점: 제휴·광고·프리미엄 및 생태계 수익
- 환원: 건강 행동을 내부 포인트로 보상
- 1인기업 적용성: 중간. 센서 검증과 부정행위 방지가 필요
- 한계: 외부 제휴 상품이 없으면 포인트 사용 가치가 약함
- 근거: https://sweatco.in/

## 8. StepBet

- 서비스: 사용자가 걸음 목표에 돈을 걸고 성공자들이 상금을 나누는 건강 챌린지
- 이용 흐름: 참가비 납부 → 개인화된 주간 걸음 목표 수행 → 실패자 탈락 → 성공자들이 풀을 분배
- 유료 지점: 참가비와 운영 수수료
- 환원: 목표 달성자에게 참가금 풀을 분배
- 1인기업 적용성: 낮음~중간. 동기부여는 강하지만 결제·환불·분쟁·사행성 오해 위험
- 적용 힌트: 현금 풀 대신 사용자가 낸 구독료 일부를 달성 크레딧으로 환급하는 형태로 단순화
- 근거: https://stepbet.com/

## 9. ClassPass

- 서비스: 월 구독 크레딧으로 여러 헬스장·요가·필라테스·웰니스 서비스를 예약하는 플랫폼
- 이용 흐름: 월 구독 → 크레딧 수령 → 지역별 수업 예약 → 일부 미사용 크레딧 이월 → 다음 달 갱신
- 유료 지점: 월 구독과 추가 크레딧
- 환원·보호: 사용하지 못한 가치 일부를 다음 달로 이월
- 1인기업 적용성: 높음. 보상보다 ‘사용하지 못한 유료 권리 보호’라는 관점이 중요
- 한계: 이월 상한·소멸 규칙이 불투명하면 오히려 신뢰를 잃음
- 근거: https://classpass.com/

## 10. Audible

- 서비스: 오디오북·팟캐스트·독점 오디오 콘텐츠 구독 서비스
- 이용 흐름: 월 구독 → 정기 크레딧 수령 → 오디오북 영구 구매 → 미사용 크레딧 일부 누적 → 해지 전 사용
- 유료 지점: 월·연 구독과 추가 구매
- 환원·보호: 매월 받은 크레딧을 사용자가 원하는 시점에 콘텐츠 자산으로 전환
- 1인기업 적용성: 높음. 구독료를 단순 소멸시키지 않고 사용권 잔액으로 축적 가능
- 한계: 해지 시 크레딧 소멸 등 규칙은 명확히 고지해야 함
- 근거: https://www.audible.com/

## CozyBuilder에 가장 현실적인 해석

단순 출석 포인트보다 아래 세 가지가 유력하다.

1. **미사용 가치 보호**: 결제했지만 사용하지 못한 AI 횟수·기능권 일부를 다음 달로 이월
2. **실제 성과 달성 환원**: 첫 백업, 첫 계약 완료, 3개월 연속 입금관리 등 검증 가능한 행동에 크레딧 지급
3. **공동성장 적립**: 성과 달성 시 회사가 정한 소액을 사용자 성장기금 또는 공익기금에 자동 적립

## 초기 적용안

- 월 제공 AI 크레딧의 최대 30% 이월
- 3개월 연속 핵심 기능 사용 시 다음 달 AI 크레딧 10% 추가
- 첫 데이터 백업 완료 시 백업 용량 또는 무료기간 지급
- 실제 비용절감·수익개선 사례 제출이 검증되면 다음 결제 할인
- 단순 로그인·출석에는 금전성 보상 없음

## 결론

이 모델에서 가장 현실적인 것은 포인트 게임이 아니라 `사용하지 못한 유료 가치의 이월`과 `검증 가능한 실제 성과에 대한 제품 크레딧 환원`이다. 추천인이 없어도 작동하며 별도 현금 정산 없이 구현할 수 있다.
