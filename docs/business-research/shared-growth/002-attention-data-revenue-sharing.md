# 공동성장 모델 2 — 광고 관심·데이터 수익 공유형 10개

> 사용자가 광고를 보거나 검색·설문·기기·위치·건강 데이터를 명시적으로 제공하고, 광고주·리서치사·데이터 구매자에게서 발생한 수익 일부를 포인트·현금·기프트카드·토큰으로 돌려받는 구조다. 조사일: 2026-07-13.

## 공통 구조

`사용자 동의 → 관심·행동·데이터 제공 → 광고·리서치·데이터 매출 발생 → 일부 사용자 환원`

핵심은 사용자를 무료 데이터 원천으로만 보지 않고, 데이터와 관심에서 생긴 경제적 가치의 일부를 참여자에게 되돌리는 것이다.

## 1. Brave Rewards

- 사용자 비용: 브라우저와 Rewards 기본 무료
- 사용자 행동: 광고 수신을 선택하고 Brave 내 광고를 봄
- 플랫폼 수익원: 광고주가 지급하는 Brave Ads 비용
- 사용자 환원: BAT 토큰. 현금·암호화폐 교환, 창작자 후원, 제휴 사용처 이용 가능
- 공개 배분: 공식 페이지 기준 적격 광고에서 사용자 몫은 Brave 몫 이상
- 지급 조건: 지급 계정 연결 필요. 지역에 따라 출금 파트너와 기능 제한
- 위험: BAT 가격 변동, KYC·지갑 연결, iOS 기능 제한
- 근거: https://brave.com/brave-rewards/

## 2. Gener8

- 사용자 비용: 앱·브라우저·확장 프로그램 무료
- 사용자 행동: 온라인 활동·브라우징 데이터를 공유하도록 선택
- 플랫폼 수익원: 동의 기반 데이터·광고·파트너 매출
- 사용자 환원: 포인트를 £5 수준 기프트카드·상품·기부로 전환
- 공개 배분: 플랫폼 수익과 사용자 환원 비율은 미공개
- 지급 조건: 현금 출금보다 리워드 마켓 전환 중심. 국가·재고 제한 가능
- 강점: 데이터 제공을 일상 생활 보상으로 연결
- 근거: https://gener8ads.com/

## 3. Swash

- 사용자 비용: 브라우저 확장 기반 참여는 무료
- 사용자 행동: 동의한 브라우징 데이터를 데이터 유니온에 제공
- 플랫폼 수익원: 집계·익명화된 데이터 상품과 광고·파트너 매출
- 사용자 환원: 토큰·현금성 보상 구조
- 공개 배분: 판매 건별 정확한 배분율은 공개 페이지에서 확인 어려움
- 지급 조건: 지갑·토큰 전환과 최소 지급 조건이 적용될 수 있어 가입 시 재확인 필요
- 위험: 토큰 가치, 블록체인 사용 복잡성, 지역별 가용성
- 근거: https://swashapp.io/

## 4. Google Opinion Rewards

- 사용자 비용: 무료
- 사용자 행동: 짧은 시장조사·제품·상점 만족도 설문 응답
- 플랫폼 수익원: Google과 조사 고객의 리서치·제품 개선 예산
- 사용자 환원: Android는 Google Play 크레딧, iOS 등 일부 시장은 PayPal 크레딧
- 공개 보상: 설문별 금액 변동. 정확한 정액 배분율은 없음
- 지급 조건: 설문 배정은 인구통계·지역·수요에 따라 달라지며 크레딧 만료 가능
- 강점: 질문에 답한 순간 바로 소액 가치를 돌려줌
- 근거: https://surveys.google.com/google-opinion-rewards/

## 5. Microsoft Rewards

- 사용자 비용: Microsoft 계정 가입 무료
- 사용자 행동: Bing 검색, Edge 사용, 퀴즈, 게임, Microsoft Store 구매
- 플랫폼 수익원: 검색광고·브라우저 이용·스토어 판매·생태계 유지 가치
- 사용자 환원: 포인트를 기프트카드·경품·기부로 전환
- 공개 수치: 검색당 3포인트, 시장·등급별 일일 한도. 일부 보상은 200·1,000·1,600·5,000포인트부터
- 지급 조건: 국가별 적립·전환 항목과 한도 차이
- 강점: 광고수익뿐 아니라 생태계 이용 가치를 포인트로 환원
- 근거: https://rewards.bing.com/welcome

## 6. Nielsen Computer & Mobile Panel

- 사용자 비용: 무료
- 사용자 행동: 컴퓨터·휴대전화 사용 측정 소프트웨어 설치와 사용 데이터 제공
- 플랫폼 수익원: Nielsen의 미디어·시장 측정 데이터 판매
- 사용자 환원: 참여 유지에 따른 리워드·경품·포인트. 국가별 방식 상이
- 공개 배분: 데이터 매출 대비 사용자 환원 비율 미공개
- 지급 조건: 기기 유지, 패널 조건 충족, 국가별 초대·정원 제한
- 위험: 장기간 측정 소프트웨어 설치에 대한 개인정보 우려
- 근거: https://computermobilepanel.nielsen.com/

## 7. SavvyConnect

- 사용자 비용: 무료
- 사용자 행동: PC·모바일 기기에 측정 앱을 설치해 인터넷 사용 데이터를 제공
- 플랫폼 수익원: 시장조사 고객에게 패널 데이터와 인사이트 판매
- 사용자 환원: 기기당 월 정액 리워드 구조가 알려져 있으나 최신 국가별 금액은 가입 화면 재확인 필요
- 지급 조건: 앱이 정상 작동하고 기기 사용 기준을 충족해야 함
- 공개 배분: 고객 매출 대비 사용자 몫 미공개
- 강점: 광고 클릭이 아닌 지속적인 측정 참여에 월 반복 보상
- 근거: https://www.surveysavvy.com/

## 8. Mobile Performance Meter

## 이 모델에서 얻은 핵심 패턴

1. 사용자는 대부분 가입비를 내지 않고, 광고주·리서치사·데이터 구매자가 재원을 낸다.
2. 현금보다 기프트카드·포인트·토큰을 쓰면 출금 비용은 낮지만 사용자의 체감 가치는 떨어질 수 있다.
3. 가장 큰 약점은 플랫폼이 데이터를 얼마에 팔고 사용자에게 얼마를 주는지 공개하지 않는다는 점이다.
4. 광고 보기보다 검색·설문·기기·건강·위치처럼 가치가 명확한 데이터가 높은 보상 재원이 될 수 있다.
5. 위치·건강·브라우징 데이터는 민감하므로 사용처·보관기간·철회·삭제 권한이 보상만큼 중요하다.
6. CozyBuilder는 광고 관심보다 사용자의 성장 과정에서 생성된 익명화된 데이터·설문·검증 피드백을 선택적으로 보상하는 방식이 더 적합하다.

## CozyBuilder 적용 후보

`사용자 명시 동의 → 성장 관련 설문·검증·익명 통계 제공 → 외부 리서치·파트너 매출 → 사용자 성장포인트 + 공동 성장기금으로 투명 배분`

권장 원칙:

- 데이터 제공은 기본 비활성화·명시적 선택
- 판매·사용 목적과 보관기간 공개
- 사용자가 언제든 철회·삭제 가능
- 실제 매출 발생 후 배분
- 플랫폼 몫·개인 보상·공동기금 비율 공개
- 현금보다 교육·도구·광고·AI 크레딧으로 재투자 가능
