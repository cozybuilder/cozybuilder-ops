# 건축·인테리어 현장 음성 AI 검증 계획

> 상태: 사전 아이디어 정리 완료, 검증 대기  
> 기준일: 2026-07-14  
> 목적: 음성 AI 자체를 먼저 만들지 않고, 건축·인테리어 현장에서 실제로 반복되는 분쟁·협의·서류업무를 확인해 가장 강한 유료 문제와 음성 활용처를 결정한다.

## 1. 현재까지 확인한 핵심 판단

### 1.1 작업 중 상시 음성기록 가설은 약함

현장 작업자가 작업 중 매번 음성을 남기는 행동은 번거롭고 누락 가능성이 높다. 따라서 `말만 하면 매일 작업일보가 완성되는 앱`만으로 정의하면 실제 사용 습관이 만들어지지 않을 수 있다.

음성기록이 자연스럽게 발생하는 순간은 다음과 같다.

- 건축주·원청·하청 간 현장 협의
- 공정회의·주간회의
- 추가공사·설계변경 협의
- 하자 원인·보수 범위·책임 협의
- 전화로 작업 범위·금액·일정을 결정할 때
- 공사 완료·검수·보수 범위를 확인할 때

### 1.2 사용자는 평소 녹음을 다시 듣지 않음

대부분은 문제가 생기기 전에는 녹음파일을 다시 확인하지 않는다. 분쟁이나 책임 문제가 발생한 뒤에야 `누가 언제 무엇을 말했는지` 찾는다.

따라서 단순 녹음 보관이나 요약만으로는 반복 사용 동기가 약하다. 회의 직후 바로 쓸 수 있는 문서와 후속 업무를 만들어줘야 녹음이 쌓인다.

### 1.3 작업일보는 결과물 중 하나

음성파일로 만들 수 있는 결과를 작업일보에 한정하지 않는다. 우선 검증할 결과물은 다음과 같다.

- 현장회의록
- 결정사항 목록
- 담당자별 할 일
- 일정 변경 내역
- 자재·사양 변경 내역
- 추가공사 후보 및 확인서 초안
- 비용 협의 및 미확정 항목
- 하자·책임 관련 발언 정리
- 건축주·원청에 보낼 당일 확인 메시지
- 작업일보 반영 초안
- 나중에 질문으로 찾을 수 있는 발언·원음 타임스탬프

## 2. 현재 제품 가설

### 임시 제품 정의

> 건축·인테리어 협의와 회의를 기록하고, 결정사항·책임·변경사항을 자동으로 문서화해 나중에 바로 찾을 수 있게 하는 AI 현장기록 시스템

### 핵심 사용 흐름

```text
협의·회의 녹음 또는 기존 음성파일 업로드
→ 현장용어 기반 전사
→ 결정·책임·금액·일정·변경·미확정 사항 추출
→ 회의록·확인 메시지·후속 업무 생성
→ 각 결과를 원음 타임스탬프와 연결
→ 현장별 누적
→ 문제가 생기면 질문으로 관련 발언 검색
```

### 즉시 가치와 장기 가치

- 오늘의 가치: 회의록·확인 메시지·후속 할 일을 자동 생성해 반복 서류업무를 줄인다.
- 나중의 가치: 분쟁 발생 시 관련 발언, 당시 결정 과정, 미확정 상태를 원음과 함께 빠르게 찾는다.

법적 증거능력이나 책임 판정을 보장하는 제품으로 표현하지 않는다. 원본 음성·시간·전사·AI 초안·사용자 확정본을 연결해 사실확인을 돕는 기록 보조 도구로 정의한다.

## 3. 핵심 기술 자산 가설

### 3.1 출시 전 기본 현장언어 구축

범용 AI에만 의존하지 않고 공개적으로 확보 가능한 자료를 최대한 수집해 기본 현장언어 지식베이스를 구축한다.

- 건축·건설 용어사전
- 공종별 현장용어집
- 일본식 현장용어·순화자료
- 표준시방서·교육자료·자격시험 자료
- 자재·공구·장비·규격 명칭
- 제조사 카탈로그·시공 매뉴얼
- 공개 영상 자막·블로그·커뮤니티 용례
- 동의어·축약어·발음 변형·음성인식 오인식 후보

용어는 하나의 고정 뜻으로만 저장하지 않고 `공종·문맥·용례·표준 문서 표현·출처·신뢰도`를 함께 관리한다.

예: 금속 현장에서 `데빠`는 사각 프레임의 대각 또는 대각 치수 확인 의미로 사용된다.

### 3.2 출시 후 현장 학습

AI가 모르는 표현이나 확신이 낮은 표현은 담당자가 뜻을 선택하거나 입력한다.

수정값 적용 범위:

1. 작업자 개인 표현
2. 해당 회사 표현
3. 같은 공종에서 반복 검증된 후보
4. 운영 검수 후 공통 사전 반영

사용자가 고친 내용을 모델이 매번 즉시 재훈련하는 것이 아니라, 우선 회사별 지식베이스와 검색 우선순위에 즉시 반영하고 충분한 검증 데이터가 쌓인 뒤 모델 개선에 활용한다.

### 3.3 음성 처리 목표

일반 문장 정확도만 보지 않는다. 다음 핵심 정보의 정확도를 별도로 평가한다.

- 현장용어
- 자재명·공구명
- 숫자·치수·규격·단위
- 사람·업체·장소
- 긍정·부정 표현
- 확정·요청·예상·이견·미확정 구분
- 화자 구분
- 원음 타임스탬프 연결

## 4. 검증해야 할 핵심 질문

### 고객·행동 검증

1. 누가 실제 녹음 담당자인가: 대표, 현장소장, 공무, 반장, 인테리어 실장 중 누구인가?
2. 어떤 상황에서 녹음을 켜는가?
3. 현재 음성은 휴대전화 녹음, 통화녹음, 카카오톡 파일 중 어디에 쌓이는가?
4. 녹음 후 실제로 다시 듣는 빈도와 계기는 무엇인가?
5. 녹음·회의 내용을 누가 어떤 문서로 옮기는가?
6. 회의 직후 자동으로 만들어주면 가장 먼저 쓰는 결과물은 무엇인가?
7. 원음 타임스탬프 검색이 실제 분쟁·책임 확인에 가치가 있는가?
8. 녹음 사실 고지와 사용에 대한 현장 저항은 어느 정도인가?

### 문제 검증

1. 가장 자주 반복되는 서류업무는 무엇인가?
2. 가장 많은 시간을 빼앗는 문서는 무엇인가?
3. 가장 큰 금전 손실을 만드는 기록 누락은 무엇인가?
4. 추가공사·설계변경·하자·공기지연 중 어느 문제가 가장 빈번한가?
5. 카카오톡·전화·녹음·사진·도면이 흩어져 생기는 실제 손실은 무엇인가?
6. 현재 사용 중인 현장관리 프로그램이 해결하지 못하는 문제는 무엇인가?

### 지불의사 검증

1. 시간 절약과 분쟁 방지 중 어느 가치에 더 돈을 내는가?
2. 개인 월 구독, 회사별 월 구독, 현장별 결제 중 선호 방식은 무엇인가?
3. 작업일보 자동생성만으로 결제하는가?
4. 회의록·추가공사 확인서·원음 검색까지 있어야 결제하는가?
5. 실제로 돈을 내게 만드는 한 가지 결과물은 무엇인가?

### 기술 검증

1. 기존 범용 음성인식이 실제 건축·인테리어 회의를 얼마나 정확히 전사하는가?
2. 현장용어 사전 주입 전후 정확도 차이는 얼마인가?
3. 여러 사람이 겹쳐 말하고 현장 소음이 있을 때 화자와 핵심어를 구분할 수 있는가?
4. 숫자·단위·금액·날짜·부정 표현 오류율은 어느 정도인가?
5. 원음 구간과 추출된 결정사항을 신뢰성 있게 연결할 수 있는가?
6. 긴 회의에서 결정·의견·미확정을 구분할 수 있는가?

## 5. 커뮤니티·실무 조사 범위

제품 기능을 먼저 확정하지 않고, 실제 사람들이 반복해서 호소하는 문제를 조사한다.

### 조사 대상

- 건축·건설 현장소장·공무 커뮤니티
- 인테리어 업체·실장·시공자 커뮤니티
- 셀프 인테리어·건축주 커뮤니티
- 금속·목공·타일·전기·설비·도장·방수 등 공종별 커뮤니티
- 네이버 지식인·블로그·카페
- 유튜브 현장 실무 영상과 댓글
- 인테리어 중개·견적 플랫폼 후기
- 소비자 분쟁·법률상담·하자분쟁 사례
- 기존 현장관리·회의록·작업일보 제품 후기

### 조사 키워드 예시

- 추가공사비 못 받았다
- 건축주 말 바꿨다
- 공사 범위 분쟁
- 인테리어 구두 약속
- 하자 책임 떠넘기기
- 공기 지연 책임
- 현장 회의록 작성
- 작업일보 귀찮다
- 공사 사진 정리 힘들다
- 설계 변경 기록 누락
- 녹음파일 찾기
- 현장관리 프로그램 불편

### 수집 항목

- 원문 불편 표현
- 사용자 역할
- 상황과 공종
- 현재 해결 방식
- 반복 빈도
- 소요 시간
- 금전 손실 또는 분쟁 위험
- 기존 도구의 한계
- 원하는 결과물
- AI 해결 가능성
- 음성 입력이 자연스러운지
- 출처와 날짜

## 6. 검증 우선순위

각 문제를 아래 기준으로 점수화한다.

| 기준 | 질문 |
|---|---|
| 반복 빈도 | 매일·매주 반복되는가? |
| 금전 손실 | 누락 시 돈을 잃거나 대금회수가 어려워지는가? |
| 시간 절약 | 문서 작성·검색 시간을 크게 줄이는가? |
| 음성 적합성 | 원본 정보가 실제 협의·전화·회의 음성에 존재하는가? |
| 즉시 가치 | 녹음 직후 쓸 결과물이 나오는가? |
| 장기 가치 | 분쟁 발생 후 다시 찾을 이유가 있는가? |
| AI 필수성 | 단순 폼보다 AI 전사·추출·검색이 핵심인가? |
| 셀프서브 | 사람 운영 없이 자동 제공 가능한가? |
| 초기 구축성 | 좁은 범위 MVP를 빠르게 만들 수 있는가? |

## 7. 우선 검증할 제품 후보

아래 순서는 확정이 아니라 조사로 검증할 가설이다.

### 후보 A — 추가공사·변경·승인 기록 비서

- 회의·통화에서 추가공사, 변경 요청, 금액, 승인, 미확정 항목 추출
- 당일 확인 메시지와 추가공사 확인서 초안 생성
- 원음 구간 연결
- 금전 손실과 직접 연결될 가능성이 가장 높음

### 후보 B — AI 현장회의록 및 후속업무

- 결정사항, 담당자, 기한, 미결사항 자동 추출
- 관계자별 전달문 생성
- 반복 사용 습관을 만들기 쉬울 가능성

### 후보 C — 하자·책임 협의 기록 검색

- 하자 원인, 책임 주장, 조치 약속, 완료 여부를 시간순으로 정리
- 분쟁 발생 후 높은 가치가 있으나 평상시 사용 빈도가 낮을 수 있음

### 후보 D — 작업일보 자동생성

- 회의·현장보고 음성에서 작업내용·인원·자재·다음 작업 추출
- 반복 업무 절약은 명확하지만 단독 유료가치는 검증 필요

## 8. 다음 검증 작업

### 1차 — 온라인 증거 수집

- 커뮤니티·후기·분쟁 사례에서 불편 사례를 최소 100건 수집한다.
- 반복되는 문제와 서류업무를 분류한다.
- 문제별 빈도·손실·음성 적합성을 점수화한다.
- 사용자 추측이 아니라 실제 원문 표현과 출처를 남긴다.

### 2차 — 실무자 인터뷰

최소 대상:

- 인테리어 대표·실장
- 현장소장·공무
- 전문건설업체 대표·반장
- 건축주 또는 발주자

질문은 아이디어를 설명하고 칭찬받는 방식이 아니라 최근 실제 사례를 묻는다.

- 최근 말이 바뀌어 손해 본 일이 있었는가?
- 마지막 회의록을 누가 언제 작성했는가?
- 최근 추가공사비를 청구할 때 어떤 자료를 찾았는가?
- 녹음파일을 마지막으로 다시 들은 이유는 무엇인가?
- 가장 작성하기 싫은 서류는 무엇인가?
- 지금 당장 자동으로 만들어주면 돈을 낼 문서는 무엇인가?

### 3차 — 음성 기술 실험

실제 또는 익명화된 회의·협의 음성으로 비교한다.

- 기본 전사
- 현장용어 사전 적용 전사
- 문맥 교정 후 전사
- 결정·금액·일정·책임·미확정 추출
- 원음 타임스탬프 연결

### 4차 — 수동형 콘시어지 검증

앱을 먼저 만들지 않고 사용자가 제공한 음성파일을 수동·반자동 처리해 다음 결과를 전달한다.

- 회의록
- 결정사항
- 담당자별 할 일
- 추가공사·변경·승인 후보
- 확인 메시지
- 관련 원음 타임스탬프

사용자가 실제로 어떤 결과를 수정·전달·보관하는지 확인한 뒤 MVP 범위를 확정한다.

## 9. 현재 중단한 가정

검증 전에는 다음을 확정 사실로 취급하지 않는다.

- 작업자가 매일 음성을 남길 것이다.
- 작업일보가 가장 강한 유료 기능이다.
- 음성 정확도만 높이면 제품이 성공한다.
- 녹음 자체가 분쟁을 예방한다.
- 사용자가 회사 전체의 모든 회의를 앱에서 녹음할 것이다.
- AI가 음성만으로 실제 책임·승인·완료 여부를 판정할 수 있다.

## 10. 현재 단계 결론

사전 아이디어 조사는 충분하다. 다음 단계는 기능 설계가 아니라 실제 문제 검증이다.

> 건축·인테리어 현장에서 반복되는 서류업무와 금전 손실 문제를 먼저 확인하고, 그 문제를 해결하는 데 음성 기록이 어떤 입력 자산으로 쓰일 수 있는지 결정한다.

검증 결과에 따라 작업일보, 회의록, 추가공사 확인, 변경관리, 하자책임 검색 중 첫 번째 유료 기능을 선택한다.
