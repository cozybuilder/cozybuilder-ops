# 사용자와 함께 성장하는 수익 환원 모델

> 회사가 성장할수록 사용자도 돈·포인트·지분·수익·기회·공익으로 함께 보상받는 서비스 구조를 조사한다. 단순 출석 포인트나 일회성 추천 보상보다 회사와 사용자의 이해관계가 실제로 같이 커지는 모델을 우선한다.

## 수집 목표

- 6개 모델별 실제 운영 사례 **10개씩, 총 60개**를 수집한다.
- 현재 수집: **30 / 60**
- 1차 완료: [거래 수익 공유형 10개](shared-growth/001-transaction-revenue-sharing.md)
- 2차 완료: [광고 관심·데이터 수익 공유형 10개](shared-growth/002-attention-data-revenue-sharing.md)
- 3차 완료: [기여자 수익 배분형 10개](shared-growth/003-contributor-revenue-sharing.md)
- 남은 모델: 공동소유·배당형, 사용자 선택 공익 환원형, 성장기금·기회 환원형

## 조사 기준

- 보상의 재원이 실제 매출·광고비·제휴수수료·이익에서 나오는가
- 사용자의 소비·기여·데이터·창작·노동·성장이 보상과 연결되는가
- 보상 규칙이 투명하고 자동 계산 가능한가
- 현금·포인트·지분·배당·교육기회·공익기금 중 어떤 방식으로 환원되는가
- 신규 사용자 유입만 요구하는 다단계·추천인 중심 구조는 제외한다
- 회사 수익성이 악화돼도 유지 가능한 구조인지 본다
- 사용자 가입비·구독료·결제비, 플랫폼 수익원, 사용자 환원액·비율, 지급·출금 조건을 함께 기록한다

## 모델 유형

### 1. 거래 수익 공유형

회사가 제휴처에서 받은 수수료 일부를 실제 구매 사용자에게 돌려준다.

- 대표 사례: Rakuten Rewards, Ibotta, TopCashback
- 구조: 사용자가 제휴 링크·오퍼로 구매 → 브랜드가 성과 수수료 지급 → 플랫폼이 일부를 사용자에게 캐시백
- 장점: 보상 재원이 외부 광고·마케팅 예산이라 서비스 자체 매출을 전부 깎지 않아도 됨
- 위험: 사용자의 불필요한 소비를 유도할 수 있음
- 상세 사례: [shared-growth/001-transaction-revenue-sharing.md](shared-growth/001-transaction-revenue-sharing.md)

### 2. 광고 관심·데이터 수익 공유형

사용자가 광고를 보거나 검색·설문·기기·위치·건강 데이터를 명시적으로 제공한 대가로 광고·리서치·데이터 수익 일부를 돌려준다.

- 대표 사례: Brave Rewards, Gener8, Google Opinion Rewards, Evidation
- 구조: 사용자 동의 → 관심·데이터 제공 → 광고·리서치·데이터 매출 발생 → 사용자에게 포인트·현금·토큰·기프트카드 배분
- 장점: 사용자를 광고 대상·무료 데이터 원천이 아니라 가치 참여자로 취급
- 위험: 개인정보, 토큰 가격, 출금 복잡성, 정확한 배분율 비공개
- 상세 사례: [shared-growth/002-attention-data-revenue-sharing.md](shared-growth/002-attention-data-revenue-sharing.md)

### 3. 기여자 수익 배분형

사용자가 만든 콘텐츠·데이터·노동이 실제 매출을 만들면 해당 기여자에게 비율로 나눈다.

- 대표 사례: Gumroad, Patreon, Udemy, YouTube, Adobe Stock
- 구조: 사용자가 결과물 제작 → 다른 사용자가 구매·이용 → 플랫폼 수수료 제외 후 제작자에게 배분
- 장점: 사용자 성장이 곧 플랫폼 공급과 매출 성장으로 연결
- 위험: 상위 기여자 편중, 품질관리, 정산·세금 복잡성
- 상세 사례: [shared-growth/003-contributor-revenue-sharing.md](shared-growth/003-contributor-revenue-sharing.md)

### 4. 공동소유·배당형

사용자나 작업자가 회사의 회원·소유자가 되고, 이익 일부를 배당과 의결권으로 돌려받는다.

- 대표 사례: The Drivers Cooperative
- 구조: 작업자가 조합원 가입 → 거래 참여 → 운영비 차감 → 잉여이익을 배당하고 1인 1표로 주요 결정 참여
- 장점: 회사와 핵심 사용자 이해관계가 가장 강하게 일치
- 위험: 투자 유치와 빠른 의사결정이 어려울 수 있음

### 5. 사용자 선택 공익 환원형

수익 일부를 사용자 개인에게 현금으로 주지 않고 사용자가 중요하게 생각하는 사회적 목표에 쓴다.

- 대표 사례: Ecosia
- 구조: 사용자가 서비스를 이용 → 광고수익 발생 → 운영비 제외 이익을 기후·식림 프로젝트에 투자 → 재무·성과 공개
- 장점: 사용자가 일상 행동만으로 공동 성과에 참여
- 위험: 개인적 체감 보상이 약하고 효과 검증이 필요

### 6. 성장기금·기회 환원형

수익 일부를 사용자 교육, 장비, 크레딧, 장학금, 사업기회처럼 사용자의 다음 성장을 만드는 데 사용한다.

- 현재 직접 대응하는 대표 사례는 추가 조사 필요
- 가능한 구조: 구독료 일정 비율 적립 → 활동·성과·필요 기준으로 사용자 성장 크레딧 지급 → 교육·도구·광고·제작비에만 사용
- 장점: 현금 보상보다 서비스 목적과 사용자 성장에 다시 연결 가능
- 위험: 선정 기준의 공정성, 부정 수급, 운영비 증가

## CozyBuilder에 맞는 유력 구조

### 사용자 성장기금

1. 월 매출에서 환불·결제수수료·직접 서비스 원가를 제외한다.
2. 남은 금액 중 고정 비율을 사용자 성장기금으로 적립한다.
3. 사용자는 활동·성과·필요에 따라 성장 포인트를 받는다.
4. 포인트는 현금화보다 교육·도구·광고·제작·프로젝트 지원에 사용한다.
5. 적립액·지급 기준·사용처·잔액을 공개한다.

### 참여 보상

- 유용한 데이터 제공
- 다른 사용자의 문제 해결
- 검증된 템플릿·콘텐츠 제작
- 서비스 개선에 반영된 제안
- 신규 사용자의 실제 성공 지원

### 금지할 구조

- 신규 회원 모집만으로 보상
- 회사 매출보다 보상 약속이 큰 구조
- 토큰 가격 상승을 전제로 한 보상
- 기준이 공개되지 않은 임의 지급
- 사용자가 불필요한 소비를 해야만 보상받는 구조
