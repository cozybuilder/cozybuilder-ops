# 사용자와 함께 성장하는 수익 환원 모델

> 회사가 성장할수록 사용자도 돈·포인트·지분·수익·기회·공익으로 함께 보상받는 서비스 구조를 조사한다. 단순 출석 포인트나 일회성 추천 보상보다 회사와 사용자의 이해관계가 실제로 같이 커지는 모델을 우선한다.

## 조사 방향 보정

기존 6개 모델 60개 수집은 참고 자료로 유지한다. 다만 CozyBuilder의 실제 적용 후보는 아래 조건을 우선한다.

- 1인기업이 운영 가능
- 초기 사용자 100명 이하에서도 작동
- 별도 마켓플레이스·광고주·데이터 판매 불필요
- 지분·배당·조합 법무 불필요
- 실제 결제가 생긴 뒤에만 보상
- 자동 계산·환불 회수·정산 가능
- 현금 외에 구독 할인·무료 기간·AI 크레딧 허용
- 각 사례는 서비스 본체·사용자·이용 흐름·유료 전환·환원 위치·돈의 흐름을 함께 분석

## 기존 모델 평가

### 1. 거래 수익 공유형

- 예: Rakuten Rewards, Ibotta, TopCashback
- 장점: 외부 제휴수수료가 보상 재원
- 한계: 제휴처 확보 필요
- 1인기업 적합도: 중간

### 2. 광고 관심·데이터 수익 공유형

- 예: Brave Rewards, Gener8, Evidation
- 장점: 사용자를 광고·데이터 가치 참여자로 취급
- 한계: 개인정보·토큰·광고주·규제 부담
- 1인기업 적합도: 낮음

### 3. 기여자 수익 배분형

- 예: Gumroad, Patreon, Udemy
- 장점: 실제 판매 후 배분
- 한계: 판매자·구매자 시장과 검수·분쟁·정산 필요
- 1인기업 적합도: 낮음

### 4. 공동소유·배당형

- 예: The Drivers Cooperative
- 장점: 회사와 사용자의 이해관계가 강하게 일치
- 한계: 법인·조합·배당·의결권 구조가 무거움
- 1인기업 적합도: 매우 낮음

### 5. 사용자 선택 공익 환원형

- 예: Ecosia
- 장점: 매출 일부를 정해진 목적에 투입하고 공개 가능
- 한계: 사용자의 개인 성장 체감이 약할 수 있음
- 1인기업 적합도: 높음

### 6. 성장기금·기회 환원형

- 구조: 구독 순매출 일부를 교육·도구·광고·제작비 지원에 사용
- 장점: 서비스 목적과 사용자 성장에 직접 연결
- 한계: 선정 기준과 수동 운영 부담
- 1인기업 적합도: 중간~높음

## 현재 가장 유력한 구조

### 제품 크레딧·무료기간 자동 환원형

1. 사용자가 본래 서비스를 충분히 사용해 가치를 경험한다.
2. 기존 사용자에게 추천 링크를 자동 발급한다.
3. 신규 사용자가 실제 사용 조건과 결제 조건을 충족한다.
4. 양쪽에 현금 대신 무료기간·사용량·용량·AI 크레딧을 지급한다.
5. 환불·취소 시 보상도 자동 회수한다.
6. 연간 누적 상한을 설정한다.

### 이 구조가 유력한 이유

- 현금 송금·출금·원천징수 시스템이 필요 없다.
- 보상이 서비스 내부에서만 가치가 있어 실제 사용자에게 집중된다.
- 표시 가치보다 실제 한계비용이 낮을 수 있다.
- 사용자가 앱을 계속 쓰는 동안에만 보상 가치가 유지된다.
- 사용자 10명일 때도 작동한다.

### CozyRent 초기 권장안

- 추천받은 사람: 첫 유료기간 14일 추가
- 추천한 사람: 추천 고객 결제 확정 후 유료기간 14일 추가
- 보상 선택지: 무료기간 / 호실 한도 / 백업 용량 / AI 크레딧
- 신규 사용자 인정 조건: 건물 1개와 실제 호실 데이터 등록
- 결제 인정 조건: 환불 가능 기간 종료
- 누적 상한: 연간 최대 3개월
- 현금 지급: 초기에는 하지 않음

## 금지할 구조

- 신규 회원 모집만으로 보상
- 회사 매출보다 보상 약속이 큰 구조
- 토큰 가격 상승을 전제로 한 보상
- 기준이 공개되지 않은 임의 지급
- 사용자가 불필요한 소비를 해야만 보상받는 구조
- 운영자가 매번 수동 심사해야 하는 구조
- 서비스 본체보다 보상 홍보가 앞서는 구조
