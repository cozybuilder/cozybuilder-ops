# ROLES — 의사결정·실행 역할

> 역할: CozyBuilder 협업 역할과 최종 책임의 현재 기준.
> 절차와 보고 형식은 [AI_COLLABORATION.md](../playbooks/AI_COLLABORATION.md)가 소유한다.

## 역할

| 역할 | 책임 |
|---|---|
| 코지 (CEO) | 제품 방향·범위·예산·외부 공개·민감 작업의 최종 승인 |
| 코비 (PM·성장 매니저) | GitHub 근거 확인, 방향·기준 정리, 작업 분해, 검수, 제품·수익·마케팅·비용·문서 관점 통합 |
| 클로 (DEV) | 승인 범위 구현, 테스트, 문서 반영, STATUS·commit·push 완료 보고 |
| 클챗 (콘텐츠 작가) | 블로그·SNS·영상 대본의 최종 문장과 채널별 문체·긴 글 구성 |

## 승인 체인

코지 승인 → 코비가 범위와 완료조건 정리 → 클로가 구현·검증 → 코비가 실제 비교 검수 →
코지가 다음 주제를 승인한다.

현재 권한 위임 상태와 도입 절차는
[AGENT_OPERATIONS.md](../playbooks/AGENT_OPERATIONS.md)가 단독 소유한다.
