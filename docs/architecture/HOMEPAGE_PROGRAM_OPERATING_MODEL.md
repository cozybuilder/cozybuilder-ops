# HOMEPAGE PROGRAM OPERATING MODEL — CozyBuilder 공통 기준

## 최상위 원칙

CozyBuilder 홈페이지는 브랜드 허브이자 공통 계정·마이페이지·프로그램 탐색 플랫폼으로 운영한다.

무료 프로그램은 홈페이지에 귀속해 회원 유입과 재방문, 유료 프로그램 교차 노출에 사용한다. 유료·대형 서비스는 독립 프로젝트로 운영하되 공통 로그인과 마이페이지를 통해 CozyBuilder 생태계에 연결한다.

홈페이지 자체의 일괄 구독을 기본 수익모델로 삼지 않는다. 사용자는 필요한 유료 프로그램에만 개별 결제한다.

## 운영 모델 A — 홈페이지 귀속형

대상:

- 무료 프로그램
- 작고 단순한 도구
- 별도 운영비와 고비용 API가 거의 없는 기능
- 회원 유입·재방문·교차 노출을 목적으로 하는 프로그램
- 독립 브랜드와 별도 배포가 필요하지 않은 프로그램

운영:

- 홈페이지 저장소 또는 홈페이지 관리 범위 안에서 제공
- 홈페이지 인증·세션 사용
- 홈페이지 내부 URL 사용
- 마이페이지 `내 프로그램`에 표시
- 상태는 `무료 이용 중`으로 관리
- 홈페이지 분석·권한 체계 사용

## 운영 모델 B — 독립 서비스형

대상:

- 유료 SaaS
- 자체 결제·구독·AI API·파일 처리·민감 데이터가 있는 서비스
- 별도 배포와 독립적 개발주기가 필요한 서비스
- 독립 브랜드·도메인·성장·매각 가능성이 있는 서비스

운영:

- 별도 GitHub 저장소
- 별도 배포
- 서브도메인 또는 독립 도메인
- CozyBuilder 공통 계정과 사용자 ID 재사용
- 서비스 업무 데이터는 분리
- 마이페이지에서 이용 상태·구독 상태·실행 링크 제공
- 프로그램별 개별 결제·구독

## 마이페이지 공통 상태

상위 메뉴명은 `내 프로그램`으로 한다.

- 무료 이용 중
- 무료 체험 중
- 구독 중
- 구매 완료
- 이용 종료

A형과 B형을 한 화면에서 통합 조회한다.

## 신규 프로젝트 판정

정식 개발 전 아래를 판단한다.

1. 무료 유입 상품인가, 독립 유료 상품인가?
2. 별도 운영비·API 비용·결제·민감 데이터가 있는가?
3. 별도 배포와 빈번한 업데이트가 필요한가?
4. 독립 브랜드와 URL이 유리한가?
5. 홈페이지 저장소에 포함하면 복잡도와 장애 영향이 커지는가?

결론:

- 무료·소형·유입 목적이면 A형
- 유료·대형·독립 운영이면 B형
- 애매한 경우 분리 비용이 낮으면 A형 MVP로 시작할 수 있으나, 향후 분리가 명확하면 처음부터 B형으로 한다.

## 현재 적용 기준

A형 유지 후보:

- 전자책 만들기
- ClipMiner 웹 기능
- 향후 무료 소형 도구

B형 적용 후보:

- 코지임대
- 평생사진관
- AI Promotion
- 향후 유료 SaaS

기존 프로그램은 즉시 이전·철거하지 않는다. 신규 프로그램부터 이 기준을 적용하고, 기존 프로그램은 실제 반응과 유지비를 기준으로 점진적으로 정리한다.
